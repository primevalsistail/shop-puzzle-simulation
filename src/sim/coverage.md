# 測る道具が見ているもの・見ていないもの

⚠ **数字を出す前と、出した数字で何かを決める前に、この表を上から読む。**
**ここに `❌` があるまま出した到達日は、その仕組みが無い世界の到達日である。**

**なぜ要るか**: 2026-09-15、`深い品を作る` が 232〜236日で帯に入らず、
**材料が揃わないのが原因**だと報告した。**原因は道具の側だった** ——
**行商人**（島で採れない品を割高で運ぶ。まさにこの問題のために作った仕組み・#34）を、
**方針が一度も使っていなかった。**`SimWorld` は毎日積荷を作っていたので、
**「載っている」だけ見て済ませると気づけない。**

---

## ⚠ 落とし穴は「載っているか」ではなく「方針が触れるか」

**列が2つあるのはそのため。**`SimWorld` に仕組みがあっても、
**`SimContext` に窓が無ければ、方針はそれが存在しないものとして振る舞う。**

| | 載 | 触 |
|---|---|---|
| **載** | `SimWorld` がその仕組みを動かしているか | |
| **触** | | **方針（`policies.ts`）がそれを見て・使って判断できるか**。⚠ **自動で起きるだけのものは `自動` と書く** |

## お金に効かないもの（載せなくてよい。**理由も書く**）

| 仕組み | なぜ載せないか |
|---|---|
| **型（`ShelfPresets`）** | 並べ直す手間を減らすだけ。**同じ盤面に行き着く** |
| **できごと（`StoryEvents`）** | **金も物も動かさない**（副作用を持たないことを確認済み 2026-09-15） |
| **セーブ・ロード** | 遊びの結果を変えない |
| **自由航行** | **エンディング後**。帯（160〜200日）の外 |
| **画面まわり全部** | HUD・メニュー・絵・音 |

## 足すときの決まり

- ⚠ **仕組みを足したら、この表に1行足す。**`load` と `save` に足し忘れると静かに消えるのと同じで、
  **ここに書き忘れると静かに測り落とす**
- ⚠ **`触` を `自動` にしてよいのは、プレイヤーが選べないものだけ。**
  **選べるのに自動にすると、「その選択が下手な人」を測ることになる**
- ⚠ **`❌` を直さずに数字を出さない。**出すなら**何が無い世界の数字か**を必ず添える
