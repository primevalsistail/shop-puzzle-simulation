## 見つかったこと（判定セッションの報告）

### 1. ハルヴェラに固有の素材が残らない — 無条件で残ったのは**樫ひとつ**

> 「温暖」が**条件の不在**として定義されている。暑すぎない・寒すぎないは「何かが要らない」という話で、
> 「何かが要る」という話ではない。素材が島に固有になるのは、その気候でなければ**足りないものがある**とき
> だけ。**温暖であることは何も要求しないので、何も囲い込めない。**

8品中6品が他島と重複したのは偶然ではなかった。

### 2. ノアキータだけ、他の四つと違う軸に乗っている

> 他の四つは**原因**（温度・日照・雪）を述べているのに、ノアキータだけが**結果**（収穫量）を述べている。
> だから排他条件を持たない。「暑いから穫れない」は言えるが「実りが絶えないから穫れない」は言えない。
> **だから何でも吸える。**

10品のうち島の定義から理由が言えるのは**卵・豚肉・はちみつの3つだけ**で、
その根拠も気候ではなく「餌と花が絶えないこと」。作物4品（じゃがいも・とうもろこし・大豆・玉ねぎ）は
この島にある理由が1つも言えない。**今のノアキータは気候の島ではなく、ただの農場。**

### 3. 四島＋海の5つが、体感では3つに縮んでいる

| | |
|---|---|
| リナツィア（暑い） | **唯一きちんと立っている。**果物・種・繊維で系統が揃っている |
| ハルヴェラ ／ ノアキータ | どちらも「穀物と家畜の農場」。気候の違いが品目に出ていない |
| ミフユリア ／ 海 | どちらも「魚介」。ミフユリアは11品中5品が海産物 |

### 4. 四季がない前提と正面からぶつかる素材が3つ

| 素材 | 衝突 |
|---|---|
| オリーブ | 花芽をつけるのに**低温期**が要る。常に暑いだけの土地では実らない |
| ぶどう | **休む時期**が要る（乾季で代替は可能） |
| 鮭 | **遡上は季節現象そのもの**。時期が来ない世界では起こらない |

## AI が付け加えた指摘 — **同じ欠陥が `向く土地` にもある**

[Phase 2 §4-E](inception/application-design/cycle4-phase2-axes.md) で確定した `向く土地` の5値:

| 値 | 定義 | 切り方 |
|---|---|---|
| `寒い土地` | 寒さを**しのぐ**のに役立つもの | **機能** |
| `暑い土地` | 暑さを**しのぐ**のに役立つもの | **機能** |
| `温暖な土地` | 穏やかな気候の**暮らしで使われる**もの | ← 別の切り方 |
| `実りの土地` | 実りの多い土地の**暮らしで使われる**もの | ← 別の切り方 |
| `どこでも` | 土地を選ばないもの | （既定値） |

**気候の定義で問題になっているのと同じ2つ**（温暖・実り）が、ここでも他の値と切り方が違う。
これは [Phase 0 の INV-2b](inception/requirements/cycle4-phase0-invariants.md)
「1つの軸の値は**すべて**、その同じ問いへの答えになっている」に触れる可能性がある。

**判定セッションは `向く土地` の存在を知らされていない。**世界観側だけを見て独立に同じ形の欠陥を
見つけたので、偶然の一致ではないと考えている。

**Phase 0 が想定していた「破れたら Phase 1 に戻る」に当たる可能性がある。**

## Question 1
**world.md §1 の四島の気候の定義**をどうしますか？

A) **気候の定義を直す（推奨）** — ハルヴェラに**積極的な条件**を足し、ノアキータを**原因の側**で書き直す。
   判定セッションの案は「ハルヴェラ＝海風が通り、涼しめで雨が適度」「ノアキータ＝暖かく、雨が多く、霜が降りない」。
   こうすると**暑さの軸に加えて乾湿の軸**ができ、四島が2軸で区別できるようになる。
   **Cycle 3 の確定事項に手を入れることになる**
B) **ノアキータだけ直す** — 「結果で定義されている」のは明確な欠陥なのでここだけ直し、
   ハルヴェラは「中間の島」のままにする。ただし**ハルヴェラの固有素材は樫のみのまま**
C) **気候は変えない** — 世界観は確定済みとして触らず、素材の重複だけを個別に裁く。
   ただし判定セッションいわく「ノアキータの定義が直るまで、ハルヴェラの品はいつでも持っていかれる状態」
D) Other (please describe after [Answer]: tag below)

## Question 2
**`向く土地` の5値**（Phase 2 で確定）をどうしますか？

A) **気候の定義に合わせて揃え直す（推奨）** — Q1 で気候を直すなら、`向く土地` も同じ切り方
   （「その気候を**しのぐ／活かす**のに役立つ」）で5値を揃え直す。**Phase 2 に戻ることになる**
B) **`向く土地` だけ先に揃え直す** — 気候（Q1）は触らず、軸の値だけ INV-2b を満たす形に直す
C) **触らない** — `実りの土地` が0品になりやすいのは承知のうえで、このまま進める
D) Other (please describe after [Answer]: tag below)

## Question 3
**四季がない前提とぶつかる素材3つ**（オリーブ・ぶどう・鮭）をどうしますか？

A) **リナツィアに「夜は冷える」または「乾いて休む時期がある」を足して、オリーブとぶどうを救う。
   鮭は落とす（推奨）** — 判定セッションの案。鮭は救う理由が薄く、かつ海の区分と重なる

   （world.md §2「前提を崩す要素を足さない」の方針）
C) **3つとも残す** — 現実の細かい生育条件はゲームに持ち込まないので、気にしない
D) Other (please describe after [Answer]: tag below)

## Question 4
**ミフユリアと海の魚介の重なり**をどうしますか？

A) **ミフユリアの海産物を「冷たさが直接の条件になるもの」だけに絞り、陸の品を島の顔にする（推奨）** —
   昆布・ほたて・かに・たらを残し、鮭を落とす。**氷・羽毛・松（または白樺）を前に出す。**
   判定セッションは**氷を候補全体でもっとも強い素材**としている（島の定義そのものが商品になっている）
B) **海の側を絞る** — いわし・さば・あじは「群れで回遊する青い魚」で区別がつかないので1〜2品に減らし、
   たこは（回遊せず岩場に居着くので）産地なしの理屈に合わないため落とす
C) **A と B の両方をやる**
D) 触らない
E) Other (please describe after [Answer]: tag below)
