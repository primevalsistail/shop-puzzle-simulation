# 8. #1 —— 通貨を `レン` にする（**削除が終わってから**）

**目的**: `¥` を世界観の通貨 `レン` に置き換える。**表示だけ。ゲームロジックには影響しない**（出典: #1 本文）。

## 決定

| 決めること | 決定 | 出典・理由 |
|---|---|---|
| 書き方 | **`1,234レン`**（数のうしろ） | PO 承認済み。日本語の語順 |
| 桁区切り | ⚠ **全部つける** | いまは `unitCost` と `revenue` だけ付いていない。**同じ通貨が2つの書き方で出ている** |
| まとめ方 | **`src/ui/money.ts` に `money(n: number): string` を1本置き、全箇所そこを通す** | **いま16箇所に手書きで散っている。**次に通貨を触るとき、また16箇所を探すことになる |
| 符号 | `+` `−` は**呼び出し側に残す**（`+${money(n)}`） | 売れた知らせと工房の3ルートで意味が違う |
