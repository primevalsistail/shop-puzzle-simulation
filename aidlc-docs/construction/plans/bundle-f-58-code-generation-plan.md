# #58 実装計画 — 仕入れ・強化・クラフトを「行く場所」にする

**束F の1件目** ／ 上位計画: [bundle-f-places-plan.md](bundle-f-places-plan.md) ／ **作成**: 2026-09-12 ／ main

## 目的（再掲）

小さなダイアログが**棚に重なる**のをやめ、`店 ⇄ 商人のところ ／ 工房 ／ 改装` の
**場所の移動**にする。**棚を覆わない**ことがこの issue の全部である。

- **`||` の連鎖7箇所 → `isShelfBlocked()` 1つ。**
