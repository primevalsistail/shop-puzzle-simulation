## ⚠ 先に報告

**私が出した「倍率を一律で少し上げる」案は、算数として問題を解けていませんでした。**

```
温暖な土地の品（平均売値 129）× 1.4 = 180
寒い土地の品  （平均売値 259）× 1.0 = 259   ← まだ勝てない
```

2人が独立に同じ計算をしました。**「合わない品を下げない」と「極端な数値調整を避ける」を
両方守る限り、倍率をいじる路線では解けません。**却下した `1.15/1.40/1.75/1.45` が、
倍率で解く唯一の形でした。

## Q. どうしますか

| | やること | 代償 |
|---|---|---|
| **A. 倍率をやめ、仕入れ値と売値に傾斜を付ける**【推奨】 | その島に向く品は**その島では高く売れる**（売値）／**産地の島では安く買える**（仕入れ値）。⚠ **安くなるのは素材だけ**にして、加工が食われないようにする | 新しい仕組みが1つ（島ごとの値段）。⚠ **在庫か資金に上限を入れないと、転売が指数関数的に増えて加工が死ぬ**（実測で確かめます） |
| **B. 極端な数値調整を受け入れる** | 4行を `1.15 / 1.40 / 1.75 / 1.45` にする | 前に避けたいと言われたもの。**`温暖な土地` だけ 1.75** になる |
| **C. 合わない品を下げる案に戻す** | 合う 1.25〜1.90 ＋ 合わない一律 0.8 | 前に「消極的な案を取らせたくない」と却下されたもの |
| **D. 段4 では直さず、段6 の測り直しに送る** | 何もしない | **方針6 が1島で逆を向いたまま**（前の島の棚を持ち込むほうが 6〜7% 得）で段5 へ進む |

**推奨は A。**理由は、4人のうち3人が独立に同じ組み合わせ（仕入れ値＋売値）に着地したこと、
そして**倍率路線が算数で負けている**ことです。

[Answer]:A。在庫の最大値は999にしてほしいです。

## ⚠ 4人が繰り返し指摘した、案の選択とは別の穴（いずれも段4 の外）

回答は要りません。**issue にするかどうかだけ、あとでまとめて出します。**

1. **着いてから分かるのでは往復にならない**（3人）— 次の島の情報を、いまの島で見せる必要がある
2. **棚の入れ替えコストが決まっていない**（2人）— 無料なら毎回全部入れ替えるだけで判断にならない
3. **2周目が1周目と違う理由がない**（3人）— 到着前に分からない情報が1つも無く、1周で表が完成する
4. **必要なのは「罰」ではなく「不足」**（経営シム好き）—
   「消極的な案を取らせたくない」は正しいが、**升目・現金・日数のどれかが足りなければ、
   罰が無くても人は捨てる」**。方針6 の「取捨選択」はここで成立する
