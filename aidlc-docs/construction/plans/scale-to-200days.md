## 0. 先に結論

### A. 200日にする配合 → **案C: 目標 700万 ＋ 強化費を一律3倍**

```
GOAL_AMOUNT  100万 → 700万        強化費  一律 ×3（総額 ¥559,000 → ¥1,677,000）
倍率・来店率・買値率・床・集客上限は第4版のまま（触らない）
```

**実測 185日**（ぴったり200日にしたいなら目標800万で +10日）。**20段すべてが買われる。**

| 配合 | 到達 | 買われた段 | 強化が起きない尻尾 | 全開放の手応え |
|---|---|---|---|---|
| いま（100万・×1） | 50日 | 18/20 | — | 65倍 |
| 案A 目標1500万だけ | 195日 | 20/20 | **152日（78%）** ✕ | 65倍 |
| 案B 500万・費用×2.5 | 153日 | 20/20 | 52日（34%） | 65倍 |
| **案C 700万・費用×3**【推奨】 | **185日** | **20/20** | **70日（38%）** | **65倍** |
| 案D 400万・費用×2・倍率↓ | 203日 | 20/20 | 90日（44%） | **29倍** ✕ |

**main の見立ては当たっていた**（§1）。目標額だけでは 1500万必要で、しかも**増えた152日が全部
「最大装備で同じ日を繰り返す」時間になる**。強化費だけを上げると**強化が割に合わなくなる**
（費用×6 で **835日・1/20段しか買われない**）。**両方を上げるしかない。**

### B. 200日にすると何が痛むか → **値では直らないものが3つ**

| 痛み | 63日版 | **200日版（案C）** |
|---|---|---|
| **選べるものが増えない期間** | 23日（37%） | **160日（80%）** |
| **補充操作の回数** | 約3,000回 | **約8,700回** |
| **強化が起きない尻尾** | 17% | **38%** |

**「200日にする」という決定は、実質「#48（周回ごとの解禁）と #27（マイセット）をやる」という決定と同じ**（§4）。
この2つが無いまま200日にすると、**160日ぶん「同じ122品から選び、同じ47品を補充する日」**が生まれる。

## 1. まず「63日の正体」— main の見立ての検証

**main の見立て**: 63日の正体は「序盤と終盤の日商が57倍違い、後半で一気に回収する」こと。
**→ 正しい。ただし『後半で一気に』の意味は、想像より極端だった。**

### 1-1. 日商の開き（航海日を廃止した後の実測）

| | 日商 |
|---|---|
| 無強化（6×5・S10・ハルヴェラ初日） | **¥1,572** |
| 全機能最大開放 | **¥102,014** |
| **開き** | **65倍** |

### 1-2. 目標額だけを上げても 200日には届かない（実測）

| 目標額 | 到達日数 | 強化費 | **買われた段** |
|---|---|---|---|
| **100万（いま）** | **50日** | ¥414,000（74%） | **18/20** |
| 300万 | 72日 | ¥559,000（100%） | **20/20** |
| 500万 | 92日 | ¥559,000（100%） | 20/20 |
| 1000万 | **144日** | ¥559,000（100%） | 20/20 |

**目標を100万増やすごとに、増える日数は約10日**（＝終盤の日商 ¥102,014 で割った値そのもの）。
**200日にするには目標 1500万前後が要る。**

> **main の見立ては当たっている。**ただし「届かない」のではなく
> **「届くが、増えたぶんが全部『最大装備で同じ日を繰り返す』時間になる」**のが問題。
> 1000万の144日のうち、**後半およそ100日は日商がほぼ ¥102,014 で平ら**（§3-2）。
> **これは B の「うんざり」に直撃する。**

### 1-3. 強化費だけを上げると「強化が割に合わない」に突き当たる（実測）

| 強化費 | 総額 | 目標に対する比 | 到達日数 | **買われた段** |
|---|---|---|---|---|
| ×1（いま） | ¥559,000 | 56% | 50日 | 18/20 |
| **×3** | ¥1,677,000 | **168%** | **115日** | **15/20（55%）** |
| **×6** | ¥3,354,000 | **335%** | **835日** | **1/20（1%）** |

**×6 は完全に壊れる。**強化の元が取れないので**誰も何も買わず**、
無強化の日商 ¥1,572 で 835日かけて 100万を貯めるだけのゲームになる。
**PO の言う「強化が割に合わない」が、そのまま数字で出た。**

→ **効くのは「強化費の絶対額」ではなく「目標額に対する比」。**
比が 100% を超えると、買っても目標が遠のく段が出てくる。**目標と費用は一緒に上げるしかない。**

## 2. A. 200日への配合案（実測）

つまみは3つ（目標額 ／ 強化費 ／ 強化の倍率）。**単独では §1 のとおりどれも破綻するので、配合で出した。**

| | 目標額 | 強化費 | 倍率 | **到達** | 買われた段 | 強化費／目標 |
|---|---|---|---|---|---|---|
| いま | 100万 | ×1（¥559,000） | 65倍 | **50日** | 18/20 | 56% |
| **案A** | **1500万** | ×1（¥559,000） | 65倍 | **195日** | 20/20 | **4%** |
| **案B** | **500万** | **×2.5（¥1,398,000）** | 65倍 | **153日** | 20/20 | 28% |
| **案C【推奨】** | **700万** | **×3（¥1,677,000）** | 65倍 | **185日** | 20/20 | **24%** |
| 案D | 400万 | ×2 | **倍率↓** | （§2-4） | | |

### 2-1. 案A（目標額だけ 1500万）— **数字は合うが、体験が壊れる**

195日で目標どおり。**だが中身が最悪だった。**

| | 実測 |
|---|---|
| 最後に強化を買う日 | **Day43** |
| **強化が1つも起きない期間** | **152日（全体の78%）** |
| 前半97日 / 後半97日 の購入数 | **20段 / 0段** |
| 日商 | D40 ¥26,425 → **D60 ¥96,828 → D195 まで平ら** |
| 1日の操作量 | **D48 以降ずっと同じ**（区画58・補充47品・加工480分） |

**「195日のうち152日は、まったく同じ日を繰り返して金を貯めるだけ」。**
PO の言う「時間がかかりすぎてうんざりする」の典型。**採ってはいけない。**

### 2-2. 案B（目標500万・費用×2.5）— 153日。200日には届かない

| | 実測 |
|---|---|
| 最後に強化を買う日 | Day101 |
| 強化が起きない期間 | 52日（34%） |
| 前半76日 / 後半 | 12段 / 8段 |
| 日商 | D1 ¥1,572 → D20 ¥5,415 → **D40 ¥1,472** → D80 ¥23,436 → D100 ¥87,867 |

⚠ **D40 で日商が ¥1,472 に落ちている（開始時より低い）。**
その日の操作量は **補充2品・加工0分** ——**高い強化を買った直後に、棚を埋める金が無くなっている。**
**費用を上げると必ずこれが起きる**（§3-5）。

### 2-3. 案C（目標700万・費用×3）— **185日。曲線がいちばん素直**【推奨】

| | 実測 |
|---|---|
| 到達 | **185日** |
| 買われた段 | **20/20（¥1,677,000 全額）** |
| 最後に強化を買う日 | Day115 |
| 強化が起きない期間 | **70日（38%）** |
| 前半92日 / 後半 | 13段 / **7段** |
| 購入の間隔 | 平均9.3日 / 中央6日 / **最長10日** |
| 日商 | D1 ¥1,572 → D20 ¥3,409 → D40 ¥4,870 → D60 ¥7,231 → D80 ¥18,497 → D100 ¥33,086 → D140 ¥96,828 → 平ら |

**案A・案B と比べて優れている点:**

- **購入の最長間隔が10日**（案B は14日）。**「10日＝1つの島にいる間に必ず1回は強化が買える」**
  ので、島を移るたびに手応えがある
- **日商が段階的に伸びる。**案A は D60 で天井に張り付くが、案C は **D140 まで伸び続ける**
- **買った直後の資金ショートが出ない**（D46 の操作量は 補充22品＝棚が埋まっている）

**⚠ 残る欠点: 最後の70日（38%）は強化が起きず、日商 ¥96,828 で平ら。**
**200日にすると、どの配合でもこの「平らな尻尾」が残る**（§3-2）。

### 2-4. 案D（目標400万・費用×2・**倍率を下げる**）— 203日。**ぴったりだが代償が2つ**

倍率を下げた版（来客/利益率 最大 3.0→2.0、作業効率 S30→S25）。

| | 実測 |
|---|---|
| 到達 | **203日**（目標どおり） |
| **全開放の日商** | **¥45,900（29倍）** ← 案A〜C は ¥102,014（65倍） |
| 最後に強化を買う日 | Day113 → **90日（44%）は強化なし** |
| 前半101日 / 後半 | **17段 / 3段** |

**代償1: 全開放の手応えが半分になる**（65倍 → 29倍）。PO が懸念したとおり。
**代償2: 強化が起きない尻尾が案Cより長い**（90日 vs 70日）。

→ **203日という数字は出るが、案C より体験が悪い。推さない。**

### 2-5. ⚠ 推奨 — **案C（目標700万・強化費×3）**

| | 理由 |
|---|---|
| **185日** | PO の「200日くらい」に最も近い。ぴったり200日にしたいなら**目標を800万**にすれば +10日 |
| **20段すべて買われる** | 強化費／目標 = 24%。§1-3 のとおり**この比が100%を超えると強化が割に合わなくなる**ので、24% は安全圏 |
| **購入の最長間隔が10日** | **島1つの滞在（10日）に必ず1回は強化が買える。**周期と噛み合う |
| **全開放の手応えを保つ** | 65倍のまま。倍率を触らないので `economy-rebalance-result-2.md` 第4版の値をそのまま使える |
| **資金ショートが出ない** | 案B（費用×2.5・目標500万）で出た「買った直後に棚が空」（D40 日商 ¥1,472）が案Cでは出ない |

**変更は2つの数だけ**: `GOAL_AMOUNT` 100万 → **700万** ／ 強化費を**一律3倍**。
倍率・来店率・買値率・床・集客上限はすべて第4版のまま。

## 3. B. 200日にすると何が痛むか（数字）

### 3-1. 強化を買える間隔 — **案Cは前半に偏る。最後の70日は何も起きない**

| | 案A（1500万） | 案B（500万・×2.5） | **案C（700万・×3）** | 案D（倍率↓） |
|---|---|---|---|---|
| 平均間隔 | 9.8日 | 7.7日 | **9.3日** | 10.2日 |
| 最長間隔 | 5日 | **14日** | **10日** | 11日 |
| 最後の購入 | **Day43** | Day101 | **Day115** | Day113 |
| **強化なしの期間** | **152日（78%）** | 52日（34%） | **70日（38%）** | 90日（44%） |
| 前半／後半の段数 | **20 / 0** | 12 / 8 | **13 / 7** | 17 / 3 |

**どの配合でも「後半は強化が止まる」。**目標額を上げるほど尻尾が伸びる（案A が極端）。
**案Cの70日が、実用上いちばんマシな尻尾。**

⚠ **63日版では尻尾は Day52/63 ＝ 17% しかなかった。200日にすると必ず 34〜78% に伸びる。**
**これが「63日なら我慢できるが200日だと破綻する」筆頭項目。**

### 3-2. 日商の曲線 — **案Cは D140 まで伸び、そこから平ら**

| | D1 | D20 | D40 | D60 | D80 | D100 | D140 | D180 |
|---|---|---|---|---|---|---|---|---|
| 案A | ¥1,942 | ¥12,619 | ¥26,425 | **¥96,828** | ¥97,650 | ¥96,828 | ¥96,828 | ¥96,828 |
| 案B | ¥1,572 | ¥5,415 | **¥1,472** ⚠ | ¥11,401 | ¥23,436 | ¥87,867 | ¥96,828 | — |
| **案C** | ¥1,572 | ¥3,409 | ¥4,870 | ¥7,231 | ¥18,497 | ¥33,086 | **¥96,828** | ¥96,828 |
| 案D | ¥1,572 | ¥3,326 | ¥4,261 | ¥8,209 | ¥12,149 | ¥22,760 | ¥44,155 | ¥44,155 |

- **中だるみの位置**: 案A は **D60 で天井**（以後135日が平ら）。案C は **D140 で天井**（以後45日）
- ⚠ **案B の D40 ¥1,472 は「買った直後の資金ショート」**。その日の補充は**2品だけ**（§3-5）

### 3-3. 1日あたりの操作量 — **200日ずっと「47品を補充し続ける」**

| | D1 | 中盤 | 終盤（D140以降） |
|---|---|---|---|
| 棚の区画 | 17 | 22〜36 | **58** |
| **1日に補充する品** | 17品 | 22〜36品 | **47品** |
| 加工 | 480分 | 0〜480分 | 480分 |

**終盤は毎日47品を仕入れて補充する。**これが **185日 × 47品 ≒ 8,700回**の操作になる。
**63日版なら 約3,000回。200日にすると3倍。**

> ⚠ **これが2番目の破綻項目。**同じ47品を毎日買い直す操作は、
> **盤面の判断が変わらないので「作業」でしかない。**
> issue #27（マイセット）は 63日なら「あると便利」だが、**200日では必須**になる。

### 3-4. 周回ごとの変化 — ⚠ **選択肢は Day40 で打ち止め。以後160日は増えない**

| 訪れた島 | 日 | 仕入れられる品 | 作れる品 | **選べるものの合計** |
|---|---|---|---|---|
| 1島目（ハルヴェラ） | Day1-10 | 18 | 5 | **23** |
| 2島目（リナツィア） | Day11-20 | 27 | 11 | **38** |
| 3島目（ノアキータ） | Day21-30 | 39 | 38 | **77** |
| 4島目（ミフユリア） | Day31-40 | 50 | 72 | **122** |
| **5島目（2周目の1島目）** | Day41-50 | 122 | 72 | **122（打ち止め）** |
| 6島目以降 | Day51〜 | 122 | 72 | **122（変わらない）** |

**「できること」が増えるのは最初の40日（1周目）だけ。**
U2 の解禁（仕入れ 50 → 122）は Day41 に起きるが、
**増えるのは tier2以上の加工品で、買うと赤字になる品**（第4版 §2 で実測）。**実質は増えていない。**

> ⚠ **これが最大の破綻項目。**
> **200日 ≒ 5周のうち、変化があるのは1周目だけ。残り4周（160日・全体の80%）は
> 「同じ122品から選び続ける」。**
> 63日版なら「変化が無いのは最後の23日（37%）」で済んでいた。
> **issue #48（周回ごとの解禁）は、200日にするなら前提条件になる。**

### 3-5. ⚠ 費用を上げると出る新しい痛み — 「買った直後に棚が空になる」

案B（費用×2.5）の **D38: 区画22・補充2品・加工0分・日商 ¥1,472**。
高い強化を買って所持金がほぼゼロになり、**翌日から数日、棚を埋める金が無い。**

- **案Cでは出なかった**（D46 は 補充22品＝満杯）。費用×3 でも目標700万なら日商の伸びが追いつく
- ただし**費用を上げる配合では常に起こりうる**ので、実装時は
  **「強化を買うと明日の仕入れができなくなる」ことを買う前に見せる**必要がある（束F と重なる）

## 4. C. 苦痛を減らす案（数字を見たうえで）

**§3 で出た痛みは4つ。効く手を痛みごとに並べる。**

| # | 痛み | 実測 | 効く手 | 重なる issue |
|---|---|---|---|---|
| 1 | **選択肢が Day40 で打ち止め**。以後160日（80%）は同じ122品 | §3-4 | **周回ごとの解禁**（必須） | **#48** |
| 2 | **毎日47品の補充**を185日繰り返す（約8,700回） | §3-3 | **マイセット**（必須） | **#27** |
| 3 | **最後の70日（38%）は強化が1つも起きない** | §3-1 | **強化の段数を増やす** | — |
| 4 | 高い強化を買うと**翌日の仕入れができない** | §3-5 | 買う前に見せる | 束F |

### 4-1. ⚠ 「63日なら我慢できるが、200日だと破綻する」もの（依頼の指摘事項）

**3つある。どれも 63日版では見えていなかった。**

1. **周回ごとの解禁が無いこと（#48）。**
   63日版: 変化が無いのは最後の23日（37%）。**200日版: 160日（80%）。**
   **2周目以降に新しく選べるものが1つも増えない**ので、**同じことを4回繰り返す**ことになる。
   → **200日にするなら #48 は「あると良い」ではなく前提条件。**
2. **マイセット（#27）。**
   63日版: 約3,000回の補充操作。**200日版: 約8,700回。**
   しかも**終盤の47品は毎日同じ顔ぶれ**（盤面が変わらないので）。
   → **判断の無い操作が3倍に増える。**
3. **強化の尻尾。**
   63日版: 最後の購入が Day52（尻尾17%）。**200日版（案C）: Day115（尻尾38%）。**
   → 下記 4-2。

### 4-2. 強化の段数を増やす（20段 → 30段）— **尻尾に効く**

いまは 4系統×5段＝20段。案Cで平均9.3日に1回。
**同じ総額・同じ最終倍率のまま、段を細かく割る**と:

| | 20段（いま） | **30段（4系統×7〜8段）** |
|---|---|---|
| 平均間隔（案C・185日） | 9.3日 | **約6.2日** |
| 1段あたりの倍率 | 大きい（手応えあり） | 小さい（薄くなる） |
| 尻尾 | 70日 | **短くなる**（最後の段が後ろにずれるため） |

⚠ **1段の手応えは薄くなる。**`shelf-and-set-design.md` が13段案を捨てた理由
（「1段が ×1.10〜1.20 にしかならず、買っても変化が分からない」）と同じ罠がある。
**棚は5段のまま、来客・利益率・作業効率だけを8段にする**のが折衷案
（棚は1段の差が大きく、他3系統は倍率なので細かく割れる）。**未実測。**

### 4-3. サブからの推奨

**200日にするなら、値だけでは足りない。**

```
値（このファイルの結論）      : 案C — 目標700万 ＋ 強化費×3
仕組み（値と同時に要るもの）   : #48（周回ごとの解禁）＋ #27（マイセット）
```

**#48 と #27 が入らないまま200日にすると、§3-3 と §3-4 がそのまま「うんざり」になる。**
逆に言えば、**63日のままならこの2つは後回しにできる。**
