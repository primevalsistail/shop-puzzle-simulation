## Q1. 「終盤も加工を主役に」（前回 Q2=B）が **20% 止まり**です

手際を4系統目に入れたことで **6% → 20%** まで戻りましたが、**主役（50%超）には届きません。**

**理由は資源の種類が違うから:**

```
加工の上限 ＝ 作業時間480分 × 16.0円/分 × 利益率3.0 ＝ 約 ¥23,000/日  ← 時間で頭打ち
売り場      ＝ 13×10 で 1日1,500個                                    ← 升目と集客で伸びる
```

**升目と集客はいくらでも買えるが、作業時間だけは買えない。**だから終盤ほど生売りに傾きます。

| | やること | 代償 |
|---|---|---|
| **A. 20% で手を打つ**【推奨】 | 何もしない | 「序盤は加工が6割、終盤は2割」。**加工は最後まで無くならない**が、主役ではない |
| **B. 加工の利益を上げる**（`PROFIT_SCALE` 5.6 → 12〜15） | `derive.ts` の1行 | 終盤 **30〜35%** に。72品の売値が上がるが**比は動かない**ので順位は無傷 |
| **C. 作業時間を買えるようにする**（5系統目） | 時間モデルに触る | 天井が直接動く。⚠ **「加工に使える時間は増やせない」という前提を変える** |

**推奨は A。**理由は、B でも 35% で主役にはならず、C は資源の性質そのもの
（時間は買えない）を変えることになるからです。
**ただし「終盤も何を仕込むか考え続けたい」なら B。**C は構造が変わるので、やるなら別に相談させてください。

[Answer]: うーん…升目はUI的に上限があるはず。集客も上限を設ければいい。作業時間もいわゆる作業効率(一回の作業時間か制作工数)みたいなのを買えればいい気もしている。
廃棄されたかもしれない案だけど、再検討して

## Q2. 「全機能最大開放」が、**1周目では69%までしか買われません**

強化の総額 ¥531,000 に対し、通しで実際に買われるのは **¥366,000（69%）**。
**棚の最終段（13×10）と手際の後半3段が買われない。**

理由は単純で、**終盤に高い買い物をすると回収が間に合わず、目標が遠のく**から。
Day50 に 11×9 を買った時点で残り17日しかなく、13×10 の元が取れません。

あなたは「**100万は全機能最大開放で10〜20日**」と言っていました。
**全開放なら12日**なので条件は満たしますが、**その「全開放」に1周目では到達しません。**

| | やること | 影響 |
|---|---|---|
| **A. 最終段を安くする**（棚 ¥100,000 → ¥60,000 など） | 費用表だけ | 1周目で全部開放できる。⚠ **終盤の強化が「安いから買うだけ」になる** |
| **B. 最後の1段は2周目・エンドレス用と位置づける**【推奨】 | 何もしない | **終盤に高い買い物をすると損なのは経済として正しい。**「全部開放してから100万」ではなく「100万に届く道を選ぶ」ゲームになる |
| **C. 目標額を上げる**（100万 → 150万など） | 目標だけ | 全開放する余裕が生まれる。⚠ **日数が伸びる** |

**推奨は B。**「買うか我慢するか」がこのゲームの判断そのもので、
**終盤に全部買えてしまうと、その判断が消える**からです。

[Answer]: B：エンディング後はエンドレス方針。ユーザが「高くて後でいいな」っていう判断につくのも正着だと思っています。
