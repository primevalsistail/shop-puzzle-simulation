# 商人タブの指摘7件（PO 指示 2026-09-13・画面への赤入れ）

## 目的

**取引 ＞ 商人タブの画面に、PO が赤で7箇所の指摘を入れた。**そのとおりに直す。
指摘は3種類に分かれる —— **①見出しの下の1行を丸ごと落とす ②産地を字ではなく色で出す
③「総額」と「買う」を1つのボタンに詰めるのをやめる。**

## 決定済みの前提（議論の対象ではない）

- 原文は PO の赤入れ（2026-09-13）。**言い回しではなく「出す／出さない」の指示**なので、
  #79（文言は PO の領分）には当たらない
- **`所持金` は右パネルの HUD が常に出している**（`HUD_MONEY_FONT_PX` 20px）。
  **`あと10日` も HUD が出している**（`HUD.ts:130`）。**重複を落とす、という指摘である**
- ⚠ **寸法は `src/ui/layout.ts` だけが持つ**（CLAUDE.md／`layout.ts` 冒頭）。
  **`layout.test.ts` が列の並びを同じ式で追い直している箇所があるので、そこは写しを消す**

## 今回決めないこと

- **改装タブの `所持金`**（`UpgradeMenu.ts:85`）。赤入れは商人タブにしか無い。
  ⚠ **あちらは「払えば目標が遠のく」と並べて見せる理由がコメントに書いてある。**
  → **#100**（PO 判断。3タブとも落とすか／改装だけ残すか）
- **行商人バレンの `所持金`**（`peddlerSubtitleText`）。同上。→ **#100** に同居
- **色分けの意味をどこで知らせるか。**字を落とすと「安い理由」が画面から消える。
  → **#101**（PO 判断）。**確認の観点は #47 にも1行入れた**
- 文言そのもの（`足りない` などの語）

## やること

| | 指摘（原文） | 直し |
|---|---|---|
| 1 | `所持金 5,000レン` → **不要** | 商人タブの見出し下の1行から落とす |
| 2 | `あと10日でこの島を出る（次に戻るのは40日後）` → **不要** | 同上。**行ごと消える** |
| 3 | `まだ作れるものが無い` → **不要** | 見出し下の右の注記を落とす |
| 4 | `この島の産` → **不要。色による出し分けがいい** | 字を消し、**行の背景色**で出し分ける |
| 5 | `まぐろ` → **これは全島で買える？特産品と背景色を変える** | 4と同じ直し。`まぐろ` は `origin: なし` で全島 |
| 6 | `90レン 買う` → **「総額」部分と「買う」部分は分ける** | 総額を**ボタンの外**の文字にし、ボタンは `買う` だけ |

⚠ **1〜3 で行が空になるが、一覧の上端（`ROWS_TOP`）は動かさない。**
**取引は3タブが同じ枠を使う**ので、商人だけ上げると**タブを切り替えるたびに一覧が跳ねる。**
**納品タブは既にこの帯を使っていない**（`DeliveryTab.ts`）。**帯はタブごとに使う／使わないが分かれる場所である。**

## 受入条件

1. **商人タブの見出しの下に文字が出ない**（行商人バレンのところは今までどおり出る）
2. **`この島の産` の字が出ない。**産地の島の行と、そうでない行の**背景色が違う**
3. **総額とボタンが別の部品**である。**ボタンの字は `買う`**（買えないときだけ理由に変わる）
4. `tsc --noEmit` ／ `npm run build` ／ **全テストが通る**
5. **列の並びの式が `layout.ts` の1箇所だけになっている**（`layout.test.ts` の写しを消す）
6. **いちばん長い産地つきの品名でも `⚠ 切らしている（N品に要る）` に重ならない**ことを
   テストが見ている（いまは見ていない。**列を左へ詰めるので、ここを開ける**）

## 結果（2026-09-13）

**6件すべて入った。**`tsc --noEmit` ／ `npm run build` ／ **619テスト全件パス。**
**ヘッドレスの Chromium で実際に開いて確かめた**（JS エラー0件）。

- **見出しの下は空になった。**帯は残した（タブで跳ねないため）
- **`まぐろ` `いわし` `いか` `塩` が青、`羊毛` `竹` `羊の乳` `粘土` が緑**で並ぶ（ハルヴェラ・2頁目）
- **総額は右そろえの字、ボタンは `買う` だけ。**買えないときは
  **総額がオレンジ＋ボタンの字が理由**（`足りない` 17,982レン で確認）
- **個数を空にすると総額の場所に `個数を入れて`**（ボタンは `買う` のまま灰）

### ついでに直したもの（受入条件5・6）

- ⚠ **`layout.test.ts` が持っていた列の式の写しを消した。**
  `layout.ts` の `ROW_*` が唯一の出どころで、`PurchaseMenu.ts` も同じものを読む
- ⚠ **`⚠ 切らしている（N品に要る）` が品名に重ならないことを、テストが見るようにした。**
  **総額を分けたぶん列が 20px 左へ寄る**ので、ここが開いているかを測る必要があった
  （**それまで誰も見ていなかった**）
