# #33 実装計画 — 島にいるうちに「戻るまでに要る素材」を見せる

**束F の3件目** ／ 上位計画: [bundle-f-places-plan.md](bundle-f-places-plan.md) ／ **作成**: 2026-09-12 ／ main

## 目的

素材は**採れる島でしか買えず**、四島を10日ごと・**一周40日**で回る。
島を出ると**30日戻らない。**いまは**出てから初めて足りないと分かる。**

遊ぶ人5人全員が「知りようがない」を挙げ、1人は「**仕組みを変える前にこれを先に**」と言っている。
→ [5人の意見](../item-taxonomy/evaluation/material-unlock-player-opinions.md)

⚠ **産地縛りは残す**（5人とも「むしろ一番いいところ」）。**直すのは情報だけ。**

## 実測（2026-09-12・`ALL_ITEMS` 135品 ／ `ALL_RECIPES` 85本）

**素材（レシピを持たない品）まで展開して数えた。**

| 島 | その島でしか買えない素材 | いちばん要るもの |
|---|---|---|
| ハルヴェラ | **8種** | 羊毛 12本・竹 12本・羊の乳 9本 |
| リナツィア | **6種** | 蜂蜜 21本・蜜蝋 12本 |
| ノアキータ | **11種** | 綿 22本・稲わら 20本・柿 17本 |
| ミフユリア | **11種** | 氷 11本・トナカイの角 11本・レモン 10本 |

⚠ **1本のレシピが要する素材は、中央3種・最大19種。**深い品ほど素材が見えない。
**これが「帳簿仕事」の実体**で、いま手でやらせている引き算である。

## ⚠ 数の出し方を決める — 「必要数」は出さない

同じ実測から、**「全レシピを1回ずつ」なら綿 214個・稲わら 150個**になる。
**これを「必要数」として出さない。**

- 誰も**1回ずつは作らない**ので、この数は**嘘になる**
- issue に **「最適解を教えない」「買うかどうかはプレイヤーに決めさせる」**とある

→ 出すのは **「あなたが作れる N 品に要る」（本数）と「手持ち」の2つだけ。**
   **足りているかの判断はプレイヤーがする。**

## 決定済みの前提と出典

| 前提 | 出典 |
|---|---|
| 産地縛りは残す（素材は産地の島でだけ買える） | #33（5人の意見で不採用が確定） |
| 判断材料は**プレイヤー自身の行動**から出す | #33 |
| 一周40日・寄港10日・航海日なし | `islands.ts` ／ `WorldState` |
| 商人が並べるのは `origin === 現在地` か `なし` で、U1 か U2 を通ったもの | `evaluate.ts: stockedByIslandMerchant` |

**「プレイヤー自身の行動」の出どころ**: **解禁済みのレシピ**（`RecipeUnlocks.unlockedRecipes()`）。
解禁は `everHeld`（手に入れたことがある品）で進むので、**すでにプレイヤーの行動から出ている。**
新しい記録を足さない ＝ セーブの形も変わらない。

⚠ **展開は解禁済みのレシピだけを通る。**作り方を知らない品は**買うしかない**ので、
そこで展開を止めて「要るもの」に数える。**これが実際の不足と一致する。**
