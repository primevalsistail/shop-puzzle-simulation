## 目的

**いまあるデータから、3ルートの取り分を金額で並べて見せる。**新しい仕組みは足さない。

関係は `derive.ts` が既に1行で持っている:

```
作る利益 − 転売利益 ＝ 加工利益 × 買値率      … 買値率が正である限り常に正
```

`derive.ts` の注記にある例がそのまま答えである:
> 蕎麦粉のパン: 転売 +50 ／ 材料を買って作る +106 ／ 材料も自分で作る **+124**

## ⚠ 実装中に見つけた誤り — `materials.ts` が出来高で割っていなかった

**#33 で入れた `expandToMaterials` が `outputQuantity`（1回の出来高）で割っていなかった。**
**85本中59本が2個以上**（2個:42 / 3個:12 / 4個:5）なので、段ごとに最大4倍に膨らむ。

#33 では**表示していたのが「本数」だけ**なので画面には出ていなかったが、
**#23 はこの展開から金額を出す**ので、直さないと表示する金額がずれる。

→ 直した。**#33 に訂正コメントを入れた**（綿 214個 → **94.8個** ／ 稲わら 150個 → **47.3個**）。
