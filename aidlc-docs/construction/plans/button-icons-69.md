# #69 実装計画 —— ボタンの絵を絵文字から画像に差し替える

## 目的

**絵文字が出ない環境でも、ボタンが読めるようにする。**

⚠ **見た目の好みの話ではない。**確認用のヘッドレス Chromium では
**`🛒🔨💾📂🗂❓` が豆腐（□）で出る。**この環境のフォントを調べた結果（2026-09-15）:

| 記号 | フォント |
|---|---|
| `▶` `⚙` | DejaVu Sans Mono にある |
| **`⏸` `🛒` `💾`（ほか絵文字）** | **無い → 豆腐** |

## 決定済みの前提と出典

- **PO 判断 2026-09-12**「絵文字→画像アイコンがいいかと思います」（#69）
- **絵は9枚**（依頼書 [handoff-button-icons.md](../../inception/worldbuilding/prompts/handoff-button-icons.md)）。
  ⚠ **`⏸ 停止` のぶん（`pause.png`）が依頼書から漏れていた。**
  **`進める` は押すと `停止` に変わる**ので、片方だけ絵にすると**押した瞬間に□が出る**
- **原本は `inception/worldbuilding/art/button-icons/`、`public/art/icon/` はそこからの写し**
  （`faces.ts` と同じ決まり。**描き直したら原本を直してから写す。逆をしない**）
- ⚠ **`vite.config.ts` の `base` が `/` ではない。**`BASE_URL` を頭に付けないと配った先で 404
  （`faces.ts` の注記）
- **絵の受入は 2026-09-15 に PO が済ませている**（8枚。`pause.png` は追加で依頼中）

## 今回決めないこと

- **絵柄の描き直し。**8枚は PO 受入済み。**数字を追ってさらに太らせない**
  （絵本風の線の強弱が失われ、記号に寄る）
- **ボタンの寸法・並び。**`layout.ts` の `BTN_ICON_W/H`・`BTN_ACTION_H` は動かさない
- **絵文字を使っているほかの場所**（持ち物の `◀ ▶` のページ送りなど）。
  ⚠ **あれは記号であって絵文字ではなく、フォントにある**

## 受入条件

1. **操作板に絵文字が1つも残っていない**（`▶` `⏸` を含む）
2. **絵が無くても落ちない。**読み込みに失敗したボタンも押せる
3. **`layout.test.ts` がボタンの寸法を測れる状態のまま**（写しを `GameScene` に作らない）
4. **テスト・型・ビルドが通る**
5. **#47 に目視の行を足す**（実際の画面で9個が見分けられるか）
