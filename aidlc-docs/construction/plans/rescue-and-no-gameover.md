# 救済アイテムと、GAME OVER の撤去

**作成**: 2026-09-15 ／ **ブランチ**: `feat/stage4-start` の続き
**PO 回答**: [questions-before-numbers.md](../../sessions/questions-before-numbers.md) Q3

---

## 目的

**詰みを無くす。**⚠ **立ち直る手段があるのに終わらせない。**

---

## 決定済みの前提（PO 2026-09-15）

> **立て直しの救済方法は欲しい。GAMEOVERにならない仕組みを考えた方がいい気がする**
> **ただで買えてすごい安く売れるものを用意するのはどうでしょうか？買0、売5の「砂」みたいな。**
> **あくまで救済案なので「店に並べたくない」レベルのものがいいです。**
> **数字は知らんよ。そっちで調整してよ。**

⚠ **数は main が決める。**

---

## ⚠ 上限が要る理由（実測）

**客は1升あたり 5.4個/日買う。升は最大130。**
**上限が無いと、盤面を救済品で埋めるのが最良の稼ぎ方になる。**

| 置いた升 | 1日の稼ぎ（売値5・仕入れ0） |
|---|---|
| 30升 | **810レン** |
| 130升 | **3,510レン** |

⚠ **加工の稼ぎ（概算 624レン/日）を上回る。**「店に並べたくないもの」が最適解になる。

**→ 1日に手に入る数に上限を置く。**

---

## 決めた数（main。PO 指示により）

| | 値 | 理由 |
|---|---|---|
| **売値** | **5レン** | PO の例のまま。**最安の仕入れ品 `羊の乳` が30レン**なので、はっきり下 |
| **買値** | **0レン** | PO の例のまま |
| **1日に買える数** | **20個** | **上限 100レン/日。**⚠ **どの稼ぎ方より下**に留まり、**`羊の乳` を1日で買える** |
| **升数** | **1升** | 救済なので盤面を食わない |
| **格** | **日用** | |

## やること

### 1. 救済の品を1つ足す

- ⚠ **品を足す前に [island-goods.md §0](../../inception/worldbuilding/island-goods.md) を読むこと**
- ⚠ **`display.reading`（ひらがなの読み）が必須**（欠けると検索が黙って外れる。不変条件テストが縛っている）
- **どの島でも常に買える**（解禁規則の外）
- **産地は `なし`**

### 2. 買値0 の扱い

⚠ **`買値 = 売値 × PURCHASE_RATE(0.7) × 産地割引` の全品一律という不変条件への例外になる。**

- **例外は1つだけ。名前を付けて `derive.ts` に置く**
- ⚠ **`derive.ts` の「その島の中で率は2つだけ」という注記を更新すること**
- ⚠ **例外を品ごとに散らさない。**「救済の品は買値0」という1本の規則にする

### 3. 1日に買える数の上限

- ⚠ **引いた日をセーブに積むこと**（納品の `orderDay` と同じ形）。
  **積まないとロードで買い直せる**
- **画面には残り数を出す**（買えないときに理由が分かるように）

### 4. GAME OVER を外す

⚠ **常にただで買える品があるなら、詰みは起きない。**
**それなのに `money <= 0` で幕が出るのは、立ち直る手段があるのに終わらせること。**

- **`GameService.checkGoalAndGameOver()` から GAME OVER の判定を外す**
- ⚠ **目標側は #97 で既に外してあるので、この関数は空になる。関数ごと消す**
- **`GameScene` の `PROGRESS_GAME_OVER` の購読と `showGameOver()` を消す**
- **`GameEvents.PROGRESS_GAME_OVER` の扱いは、実装する側が決めてよい**
  （名前だけ残して「誰も出さない」と注記／消す、のどちらでも）
- ⚠ **`curtainShown` が GAME OVER 側で戻らない件は、幕ごと消えるので一緒に解決する**

---

## 受入条件

1. **所持金0でも、救済の品を買って並べて売れる**
2. **1日に買える数に上限があり、超えると買えない。日が変わると戻る**
3. ⚠ **ロードで買い直せない**（引いた日がセーブに載っている）
4. **`money <= 0` でも GAME OVER が出ない**
5. ⚠ **救済の品を盤面いっぱいに並べても、加工の稼ぎを超えない**（測る道具で確かめる）
6. **`npx vitest run` 全件パス ／ `npx tsc --noEmit` ／ `npm run build`**
