# 改装タブの指摘4件（PO 指示 2026-09-13・画面への赤入れ）

## 目的

**取引 ＞ 改装タブの画面に、PO が赤で4箇所の指摘を入れた。**そのとおりに直す。
指摘は2種類に分かれる —— **①見出しの下の `所持金` を落とす（商人タブと同じ直し）
②行の中身を作り替える（効き目の前後・金額とボタンの分離）**。
**4つ目（`船の購入` が無い）は別物で、#97 の中身そのものである。**

## 決定済みの前提（議論の対象ではない）

- 原文は PO の赤入れ（2026-09-13、画面への書き込み）。**言い回しではなく
  「出す／出さない」「何を出すか」の指示**なので、#79（文言は PO の領分）には当たらない
- ⚠ **`所持金` は、商人タブの赤入れ（`merchant-tab-po-marks.md`）で
  「改装タブの分は PO へ回す」と保留していたもの。**今回の赤入れがその答えである。
  **コードの注記が「消してはいけない」と書いているのは右側の
  `払えば目標が遠のく…` の1行**であって、`所持金` ではない。⚠ **右の1行は残す**
- ⚠ **いま出ている `32,000レン 不足` の 32,000 は「不足額」ではなく「費用」**
  （`Upgrades.ts` の `COSTS.棚[0] = 32_000`。来客 10,000／利益率 14,000／手際 12,000 も
  画面の数字と一致する）。**PO の `37000レン` は 32,000 + 所持金 5,000 で、
  `不足` を「あと32,000足りない」と読んだ結果である。**
  → **`不足` の付け方がそもそも読み違えを生んでいる**ので、指摘のとおり
  **金額（＝費用）を裸で出し、ボタンを別に置く**のが直しになる。**出す額は 32,000 のまま**
- ⚠ **寸法は `src/ui/layout.ts` だけが持つ**（CLAUDE.md）。
  `UpgradeMenu.ts` がいま持っている `ROW_H` と `CONTENT_L + 28` 等の直値を移す
- **金額とボタンの分け方は商人タブと同じ形にする**（`BUY_TOTAL_*` / `BUY_BTN_W` /
  `BUY_LABEL` / `BUY_REASON_FUNDS`）。**隣り合う2タブで作りが違うと、同じ操作に見えない**
