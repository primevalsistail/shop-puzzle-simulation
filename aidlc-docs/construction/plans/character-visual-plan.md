## 受入条件

1. **依頼文が、`char.md` / `world.md` に出典の無い設定を足していない。**
   足す必要が出たら、先に `char.md` 側へ書き戻してから依頼文に入れる
2. **世界の縛りに反するものが入っていない** —— 武器・魔法具・紋章や文字の入った衣服・季節記号
3. **110×305 に縮小しても、他7人と識別できる**（シルエットと色面だけで。顔の描き込みに頼らない）
4. **髪と上着の主色が `0x1a2a3a`（濃紺）に沈まない。**かつ**既存6人の髪色と被らない**
5. **左右反転しても破綻しない**（SD とスプライトで左向きを作る可能性があるため）
6. PO の3問が回答済みで、`char-visual.md` に**未定の欄が残っていない**

## main が確定させたもの（4区分）

| 区分 | 内容 | 根拠 |
|---|---|---|
| **既決** | 服の構成（短めの上着／細身のズボン）と、**こだわりを置く3点＝襟元・髪留め・靴** | `char.md`「外見」。**差し色の置き場所はここから導ける** |
| **既決** | 服は**1着で通す。**衣替え・防寒差分を作らない | `world.md`「四季がない」。**10日で気候の違う4島を回るので、季節物を着せると世界の前提と衝突する** |
| **調査** | 表示枠 110×305、地色 `0x1a2a3a`、枠線 `0x2a4a6a`、来店客側は `0x1a3a2a` | `src/ui/CharacterStrip.ts` ／ `src/ui/layout.ts:20-22` |
| **調査** | **他7人の髪色で埋まっていない明度帯は「明るい金茶〜亜麻」だけ** | `characters.md`（黒・赤茶・焦茶・栗・白に近い・濃い灰） |
| **技術判断** | **三面図はポーズ・表情の癖を持たせない**（直立・腕は体側・平常表情1つ） | **SD と差分の基準になるため。**癖のある姿勢を基準にすると、派生のたびに癖が増幅する |
| **技術判断** | **各面を個別ファイルで、短辺1024px以上で納品** | 表示は 110×305 だが **#10 が未決。**⚠ **縮小はできるが拡大はできない** |
| **技術判断** | **依頼文に「固定部」を作る**（世界の縛り＋人物の確定事項）。以降の全キャラ・全差分で使い回す | 同じ人物を**8人×複数枚**出す必要がある（#21 #20 #6）。毎回書き直すと揺れる |

## 手順

1. PO が3問に答える → [character-visual-questions.md](../../sessions/character-visual-questions.md)
2. main が `char-visual.md` の未定欄を埋め、**ChatGPT へ貼る依頼文**を同ファイル §7 に確定させる
3. PO が ChatGPT で三面図を起こす
4. 出てきた絵を受入条件1〜5で照合する。**外れていたら依頼文のどこが足りなかったかを `char-visual.md` に書き戻す**
5. 確定した三面図を基準に、SD と残り7人へ進む（**別サイクル**）
6. `#15` の本文に `char-visual.md` へのリンクと完了条件を書き戻す（⚠ **本文が空のままにしない**）
