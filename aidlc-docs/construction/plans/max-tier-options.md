# 作り込みの深さを、何段まで用意するか

## 何の話か

島で買った**素材**を加工すると、別のものができる。
それを**さらに加工**すると、また別のものができる。

**その段を、何段まで用意するか。**

```
素材 → 1回加工したもの → 2回加工したもの → …
```

**いまは4段目が終点。**それ以上深いものは無い。

## 前提

- **作り方は少しずつ開いていく。**最初から全部は作れない
- **目標に届いた時点で、作り残しがあるのが正常**（全部は作れない設計）
- ゲーム内で **200日**、実時間で **5〜10時間**くらい遊ぶ想定

## 案

- **A. 4段**（いまのまま）
- **B. 7段**
- **C. 10段**
- **D. 上限なし**（終点を決めない。「これが最後の1品」が存在しない）
