# 画面の配色を役割名にまとめる

## 目的

**色を役割で呼べるようにして、画面全体を明るくする。**
いま色は呼び出し側に直書きで、`src/ui` と `src/scenes` に **232箇所・155色**ある。
同じ役割に別の値が当たっていても気づけない。

## 決まっていること（出典つき）

| | 中身 | 出典 |
|---|---|---|
| 配色 | 39役の16進、ボタンは3状態、幕は不透明度つき | `inception/worldbuilding/prompts/ui-palette.md`（ChatGPT） |
| 品の色 | **主種類4色にする**（161色をやめる） | PO 2026-09-14「4色でいいよ」→ `audit.md` |
| 4色の値 | 食料 `#c89884` ／ 道具 `#91c884` ／ 飲みもの `#84b3c8` ／ 衣類 `#ba84c8` | 上の範囲（彩度18-38・明度58-72）から色相を90度ずつ離して選び、実測した |

**検算済み**（数字は `audit.md`）。ChatGPT の主張した比はすべて実測と一致した。

## 今回決めないこと

- **一日の時間帯による色の変化**（朝も夜も同じ色で通す）
- **島ごとの色**
- **人物の絵の配色**（別に確定済み）

## 受入条件

1. **`src/ui` と `src/scenes` に生の16進が残らない。**テストで見る
2. **`items.ts` が品ごとの色を持たない。**主種類から引く
3. **既存のテストが全部通る**
4. **画面を出して、暗くないことを目で見る**

## 触ってよい範囲

`src/ui/**` ／ `src/scenes/**` ／ `src/taxonomy/items.ts` ／ `src/taxonomy/axes.ts`（`Display` から色を外す）

⚠ **触らない**: `src/components/**` ／ `src/sim/**` ／ `src/taxonomy/{craft,recipes,routes,evaluate}.ts`
**別セッションが編集中**（2026-09-14 時点で11ファイル）。PO 確認済み「配色で壊れることはない」。
