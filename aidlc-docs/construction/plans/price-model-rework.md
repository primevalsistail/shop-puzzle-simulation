## 目的

**値段を「品そのもの」から決める。場と置き方は掛けるだけにする。**

---

## 決定済みの前提（PO 2026-09-15。議論の対象ではない）

| | 決定 | 出典 |
|---|---|---|
| **層の分け方** | **層1＝物の基準値 ／ 層2＝需要と並べ方**。**需要とボーナスは基準値と切る** | PO「需要とボーナスは『物の基準値』とは切るべき」 |
| **加工時間** | ⚠ **層1 から外す** | **ペルソナ4人全員** |
| **深さ（tier）** | ⚠ **層1 に係数を持たない** | PO「**2重計上しないでください**」 |
| **升数** | **層1 に入れる。比例より少しだけ上** | **ペルソナ4人全員が挙げた唯一の要素** |

**決まった形**

```
売値（tier2以上） ＝ 材料費 ＋ 加工利益
加工利益 ＝ 係数 × 升数^k × 格の倍率        （k は 1 より少しだけ大きい）
```

⚠ **加工時間も tier も出力数も入らない。**

---

## ⚠ なぜ tier を入れないか（二重計上になるから）

**深さは、もう材料費が運んでいる。**
**材料費は下の段の売値の積み上げで、T7 の材料費には T2〜T6 の加工利益が全部入っている。**

**実測**: ⚠ **tier と升数の相関 r = 0.659**（T1〜T2 は 2.1升、T5 は 5.8、T7 は 9.0）。
**tier に係数を付けると、升数と材料費で既に払っているものを3度目に払うことになる。**

---

## ⚠ なぜ「比例ちょうど」ではないか

**1升あたりが同じなら、大きい品は「同じ単価で、置きにくいだけ」。必ず小さい品に負け、形の意味が消える。**
**上乗せは欲ではなく、置きにくさへの対価。**

---

## やること

### 1. `derive.ts` の `craftProfit`

```ts
// いま
const minutesPerUnit = recipe.durationMinutes / recipe.outputQuantity
return PROFIT_SCALE * Math.pow(minutesPerUnit, PROFIT_EXPONENT) * LUXURY_PROFIT[item.luxury]
```

→ **`cellCount(item)` を底にする。**
⚠ **`PROFIT_EXPONENT`（0.6）は意味が変わるので名前を変えること**（分の指数 → 升数の指数）。
⚠ **`PROFIT_SCALE` は底が変わる**ので（分 15〜480 → 升 1〜9）**必ず測り直す。**

⚠ **触らないもの**: **材料費の側は今までどおり `outputQuantity` で割る**（1個あたりの材料費なので正しい）。

### 2. 出力数が値段から消える帰結を、コメントに残す

**「1回に4個できる品」は、1個あたりの値打ちが下がらなくなる。**
⚠ **まとめて作れることは、値打ちではなく生産の速さの利点になる。**（PO 確認済み）

### 3. 層2 は触らない

**需要（`DEMAND_TABLE`）・並べ方のボーナス（`SET_RULES`）・産地割引・買値率 0.7 はそのまま。**
⚠ **`finalPrice` の作りも変えない。**

### 4. 不変条件を測り直す

- **INV-6 作った品は材料より高い**（`加工利益 > 0`。`cellCount >= 1` なので自明だが、検査は残す）
- ⚠ **「深く作るほど取り分が増える」** —— **いまは材料費の積み上げと升数の相関が運ぶ。**
  **tier ごとの売値の中央値が単調に増えることを測り、検査にする**
- **「作る > 転売」** —— **作る優位 ＝ 加工利益 × 買値率**。符号は変わらないが測る

### 5. ⚠ ペルソナから出た条件を検査にする

> **比例を下回ると「小さい品を敷き詰めるのが正解」、上回ると「大きい品だけ」に一本化して、
> テトリスの形の意味が消えます**（経営シム好き）

→ ⚠ **「大きい品だけで埋めた盤面」より「隙間を小さい品で埋めた盤面」のほうが総額が高いこと。**
**k が行き過ぎたらこの検査が落ちる。**

### 6. 測って、`GOAL_AMOUNT` を切りのいい数字にする

**狙い: 「取り合わせを狙う」が 160〜200日**（`what-players-should-do.md`。最短120日）。
⚠ **「浅い品だけ作る」（＝並べ方を工夫しない人）が何日になるかも併せて出す。**

## 今回決めないこと

- ⚠ **買値の一律 0.7**（経営シム好きが「目利きが消える」と言ったが、**不変条件と衝突する。別に扱う**）
- ⚠ **「飽き」**（やりこみ層の案。軸が増える）
- ⚠ **tier5以上の材料が4島にまたがる件**（構造の話。別に扱う）
- ⚠ **救済アイテムと GAME OVER の撤去**（回答済み・未実装。この後）

## 受入条件

1. **`craftProfit` が `cellCount` を底にしている。時間も tier も出力数も入っていない**
2. **層2（需要・ボーナス・産地割引・買値率）が1文字も変わっていない**
3. **tier ごとの売値の中央値が単調に増える**（検査つき）
4. ⚠ **「隙間を小さい品で埋めた盤面」のほうが総額が高い**（検査つき）
5. **`npx vitest run` 全件パス ／ `npx tsc --noEmit` ／ `npm run build`**
6. **測って、`GOAL_AMOUNT` の候補が出ている**
