## Q. 島に合わない品を「売れにくく」しますか

いまは、その島に**合う品が 1.3倍**売れやすいだけで、**合わない品は等倍（減らない）**です。
だから**島が変わっても並べ替える理由が弱い**（合う品を足せばいいだけで、外す理由がない）。

**⚠ 実測したら、1島では方針6 が逆を向いていました。**
ハルヴェラでは、**前の島（ミフユリア）の棚をそのまま持ち込んだほうが 6〜7% 儲かります**
（`寒い土地` の品は売値が高く、1.3倍をもらった `温暖な土地` の棚に勝つ）。
→ [stage4-demand-measure.md](stage4-demand-measure.md)

| | | 何が起きるか |
|---|---|---|
| | | 合う棚 ÷ 前の島の棚（実測） |
|---|---|---|
| **A. 合う品を強くするだけ** | 4行を `1.15 / 1.40 / 1.75 / 1.45` へ | **1.30〜1.69倍**。持ち込んでも損はしないので、並べ替えは「足す」だけ |
| **B. 合わない品も下げる**【推奨】 | 上記＋合わない品を一律 **0.8倍** | **1.67〜2.17倍**。**前の島の棚を持ち込むと確実に損をする** |

**推奨は B。**A だと「捨てる」判断が起きないので、往復になりません。

⚠ どちらでも **`温暖な土地` だけ 1.75〜1.95 と高くなります**（該当32品は売値が低いため。#38 の偏りを倍率で吸収した結果）。
⚠ 倍率の具体値は実測で解いた値です。**段6 で測り直します。**

[Answer]:できればA。ユーザに「損したくないから」っていう消極的な案を取らせたくないです。
