# 段3（ボーナス構造）— 決めてもらうこと（1件）

**回答者**: ユーザー ／ **作成**: 2026-09-12

## 話の前提

方針5 で、ボーナスを **tier で「店全体ぶん」と「その品ぶん」に振り分ける**と決まっています
（tier1 は全体90%、tier7 は個別90%）。**この振り分け自体は決定済みで、質問ではありません。**

決まっていないのは、**集まった「店全体ぶん」をどう積むか**です。
足し算で積むと、区画が増えるほど効果が爆発します（13×10 の実測で **値段 65倍**）。
**区画数で割る（平均にする）しかありません。**

## Q. 平均にすると「同じ島の品を敷き詰てると客が8倍来る」が消えます。消してよいですか

いま、同じ島の産を並べると店全体の集客が伸び、**最大8倍**まで行きます（上限で頭打ち）。
平均にすると、これが **1.15倍**になります。

| | | 代償 |
|---|---|---|
| **A. 消してよい**【推奨】 | 全部まとめて平均にする | 客足を伸ばす手段が、**並べ方から「来客頻度の強化を買う」へ移る** |
| **B. 集客だけ今のまま残す** | 集客だけ足し算＋上限8.0、他は平均 | ⚠ 効き目の種類ごとに規則が違う**例外が1つ増える**。さらに、**9×8 以降は上限8.0 に貼り付いたままなので、どのみち終盤は並べ方で客足が動きません**（実測：同じ島で揃えなくても 13×10 で 8.7） |

**推奨は A。**B は「遊びを残す」ように見えますが、**実測ではその遊びは終盤すでに死んでいます**
（上限に貼り付くため）。残すのは例外だけです。

**⚠ A を採ると、集客という効き目は当面ほぼ効かなくなります**（1.15倍）。
倍率を上げ直すかどうかは、段6 の測り直し（#61）で決めます。

[Answer]: 何が言いたいかわかりませんが、ボーナスとして「客足を増やす」はあってもいいです。一方で「8倍」は大きすぎます。理解できますか？

**→ A（平均にする）を採り、集客はボーナスとして残す。**
8倍という幅が大きすぎるのであって、集客という効き目そのものを捨てるという意味ではない。
平均にすると 1.15倍まで落ちるので、**R5 の倍率を上げ直して「効くが大きすぎない」幅に置く。**
main の置いた目標値は **並べ方で客足が動く幅を最大2倍程度**（段6 で測り直す（#61））。
