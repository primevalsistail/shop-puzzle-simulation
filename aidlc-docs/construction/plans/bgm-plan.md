# BGM を入れる（#14）

**作成**: 2026-09-15 ／ **担当**: main（サブへ委任しない）

## 目的

**8曲を実際に鳴るところまで入れる。**時間帯で曲が替わり、設定で切れること。

## 決定済みの前提（出典つき）

| 何 | 出典 |
|---|---|
| 8曲の構成・替わりかた・置き場・表記の場所 | [bgm.md](../../inception/worldbuilding/bgm.md) |
| 曲名8つ・長さ・規約 | [bgm-candidates.md](../../inception/worldbuilding/bgm-candidates.md) |
| 曲は切らない（そのまま使う） | PO 判断 2026-09-15（[audit.md](../../audit.md)） |
| 音量つまみは作らない | bgm.md §4 |

⚠ **`DayPhase`（`作業|営業|睡眠`）は BGM に使えない。**
**朝（6-10）と夜（20-24）がどちらも `作業`** なので、**BGM 用の区分を別に作る。**

⚠ **`TIME_PHASE_CHANGED` も使えない。**24:00→6:00 の飛びで `作業`→`作業` となり、**出ない。**
→ **毎フレーム時刻から区分を出して、変わったら切り替える。**

## 今回決めないこと

- **効果音**（#124）
- **音量つまみ**（bgm.md §4 で「作らない」と決まっている）
- **ミフユリアの曲が雪に聞こえるか**（聴いてから。替えは「泉のほとりで」）

## 受入条件

1. **時間帯で曲が替わる** —— 6:00〜10:00 朝 ／ 10:00〜20:00 いまの島の昼 ／ 20:00〜24:00 夜
2. **島が替わると昼の曲も替わる**（4島4曲）
3. **昼の曲は毎日その頭から鳴る**（前日の続きにしない）
4. ⚠ **速さ（1・3・10倍）で曲は変わらない。**曲の速さも変えない
5. **替わり目は1秒ほどかけて前の曲から次へ**
6. **設定（⚙️）に「音楽を鳴らす」が1行あり、切ると止まる。**次に開いても覚えている
7. **設定の面のいちばん下に配布元が出る。**効果音（#124）も後から足せる形
8. **タイトル画面とはじまりの場面はタイトルの曲**、**商船を買った幕はエンディングの曲**
9. **`npm test` が通る**

## 置き場

- **原本 `audio/`、写しが `public/audio/`**（⚠ 絵と同じ向き。逆をしない）
- **`ogg` ＋ `m4a` の2本**（ogg だけだと Safari で鳴らない）

### ⚠ 手順4 は変えた —— 読み込みは鳴らすときに1曲ずつ

**計画では `BootScene` でまとめて読むつもりだった。****やめた。**
**8曲で 15MB あり、先に全部読むとタイトルが出るまで待たされる。**
**1曲 2MB で、鳴らすのは常に1曲**なので、`BgmPlayer.play()` が
**その場の場面の `load` で1本だけ読む**（読み終わる前に別の曲へ移ったら捨てる）。

### 知らないと踏むこと

- ⚠ **`DayPhase`（`作業|営業|睡眠`）は BGM に使えない。**
  **朝（6-10）と夜（20-24）がどちらも `作業`。**区分は `audio/bgm.ts` の `bandOf()` に別に持たせた
- ⚠ **`TIME_PHASE_CHANGED` も使えない。**24:00→6:00 の飛びで `作業`→`作業` となり、**出ない。**
  → **顔絵と同じく毎フレーム見る**（`GameScene.syncBgm()`）
- ⚠ **淡くするのに場面の `tweens` を使わない。**場面が終わると途中で止まり、
  **小さいまま鳴り続ける。**`game.events` の `step` で自分で進めている
- ⚠ **`BgmPlayer` は1つだけ。**場面ごとに作ると**曲が重なって鳴る**（`bgm(scene)` が使い回す）
- ⚠ **`Phaser.Sound.BaseSound` に `volume` は無い。**持っているのは
  `WebAudioSound` ／ `HTML5AudioSound` の側

### まだ確かめていない

## 追記: 音量つまみ（2026-09-15・PO 指示）

**入ったあとに出た指示**（→ `audit.md`）。**入／切に加えて 0〜100 の音量。**

| 入ったもの | |
|---|---|
| `src/audio/musicSettings.ts` | **`musicOn.ts` から改名。**入／切と音量の両方を持つ |
| `musicGain()` | **鳴らす側が見るのはここ1つ**（0〜1。**切ってあれば 0**）。⚠ **2箇所で見ない** |
| `OptionSlider`（`options.ts`） | ⚠ **`OptionSwitch` に旗を足さず、隣に型を足した**（元からの決まり） |
| `layout.ts` | `slider` の区分と、溝・丸・数字の位置（**行と同じ高さ**） |
| `OptionsMenu.slider()` | ⚠ **面ごと作り直さない**（掴んでいる最中に消える）。丸と数字だけ動かす |

### 知らないと踏むこと

- ⚠ **下地と字を先に作る。**あとから作ると**後のものが上に出て、溝も丸も数字も隠れる**
- ⚠ **場面の入力に付けた「離した」の見張りは、閉じるとき自分で外す。**
  `destroy()` では外れず、**開くたびに増える**
- ⚠ **音量を変えたとき、淡くしている最中なら行き先だけ差し替える。**
  **その場で音量を書くと、替わり目につまみを動かしたとき音が飛ぶ**
