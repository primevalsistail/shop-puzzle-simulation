## 決まったこと

### A. 手際（`craft.ts` ／ 改装タブ）

1. ⚠ **「難しすぎて着手できない」を外す**（`canAttempt` と `ATTEMPT_HEADROOM`）。
   **手際の意味は「加工が速くなる」1つだけにする。**
   ⚠ **外しても止まるものはほとんど変わらない**（実測: 手際10 で 32品 → **9品は1日に収まらず結局着手できない**）。
   **難しい品は「その日のうちに終わらない加工は着手できない」という既にある決まりで止まる。**
2. **改装の `手際` の行は、累計の倍率を `前 → 後` で出す**（PO 指示）。
   **`1 → 1.7 → 3.0 → 5.3 → 9.2 → 16.0`**（1段 = 2^(4/5) = 1.741倍）。
   ⚠ **この数は「作業精度」そのもので、全品がその倍率で速くなるわけではない**
   （簡単な品は `SPEED_FLOOR` に張り付いて止まる）。**実際の分数は工房の `時間` の列が正。**
3. **説明の一言は `加工が速くなる` のまま**（1 で「品が増える」効き目が無くなるため）。

### B. レシピの解禁（#111）

> **1レシピ単位にする。材料が全種そろった瞬間に、そのレシピだけが開く。日付の枠は外す。**

⚠ **「材料のどれか1つ」にはしない**（PO 回答「全種そろった」）。
**実測: どれか1つだと Day 1 に 45/106本、うち tier3以上が23本開く**（全部だと5本）。

⚠ **`allowedGroupCount` と `UNLOCK_INTERVAL_DAYS` が要らなくなる。**
**読む本番コードがゼロになったものは消すこと。**
⚠ **「1寄港あたり2〜3回」という PO 指定はここで無効になる。**`RecipeUnlocks` の注記を書き換える。

### C. 納品の表

4. **`数量` の列を `0/7` にする**（必要な数の代わりに「手持ち/必要」）
5. **`廃棄` は残し、押したら確認を出す。**⚠ **ダイアログ形式**（PO 指示）。
   **この作りのダイアログは `Tutorial` ／ `SaveLoadMenu` ／ できごとの窓の3つ。**
   ⚠ **4つ目の形を作らず、そこへ揃える**（全画面の暗幕 ＋ 中央の不透明な面）
6. **依頼が入る確率はそのまま**

### D. 工房の表

7. **`需要` の列の中身を「売れる島」に変える**（列名は `需要` のまま）。
   ⚠ **`向く土地: どこでも` の品は売れる島が無いので空欄**（PO 了承済み）
8. **`材料` の列を足す**（→ #107）
9. **儲け方の3ルートは出さない**（→ #108。⚠ **`routeValues` は消さない。戻せるように残す**）

### E. 改装タブ

11. **ボタンの字は `改装` のまま**
