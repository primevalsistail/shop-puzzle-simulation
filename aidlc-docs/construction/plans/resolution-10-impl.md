## 技術判断と根拠（PO 判断ではない）

### 1. ⚠ カメラの `zoom` では実現できない。`layout.ts` の数を実際に ×1.5 する

**「座標は 1280 のまま、カメラを 1.5倍にして見た目だけ上げる」案を捨てた。**
**根拠**: **Phaser 3.90 の `DOMElementCSSRenderer` はカメラの `zoom` を参照していない**
（`node_modules/phaser/src/gameobjects/domelement/` に `zoom` の出現がゼロ）。
⚠ **`<input>` は `scene.add.dom()` で置いている**（工房の回数 ／ 一覧の検索 ／ 仕入れの個数 ／ 型の名前）ので、
**位置と大きさが全部ずれる。**

**副次的に**: カメラ倍率だと `Text` を 11px で焼いてから1.5倍に伸ばすことになり、
**49箇所すべてに `resolution` を渡さないとぼやける。**
**実際に ×1.5 すれば 16.5px で焼かれるので、その細工が要らない。**

### 2. ⚠ 端数は丸めない。正確に ×1.5 する

**奇数は121個中16個**（うち12個がフォント。`11 → 16.5` / `13 → 19.5` / `15 → 22.5` / `17 → 25.5`）。
⚠ **丸めると相似が崩れ、「見た目を変えない」という受入条件を自分で破る。**
**17 に切り上げると字幅が約3%伸び、`layout.test.ts` の「枠に収まるか」を割る可能性がある。**
**CSS も canvas も小数の px を受け付けるので、`16.5px` のまま置く。**

### 3. ⚠ `roundPixels` は `false` にする

`pixelArt: true` は `roundPixels: true` を含んでいた。
⚠ **小数座標を整数へ丸めるので、上の「正確に ×1.5」と噛み合わない。**
**`antialias: true` と一緒に、明示的に `roundPixels: false` を置く。**

### 4. ⚠ 掛けてよい数と、掛けてはいけない数

**掛ける**: 位置・幅・高さ・余白・フォントの px
**掛けない**: ⚠ **個数・行数・列数・色・確率・透明度**
**実例**: `PRESET_COLS = 2`（列数）／ `MSG_SCRIM_ALPHA = 0.65`（透明度）／
⚠ **`ORDER_BAR_T = GRID_ORIGIN_Y + 10 * CELL_SIZE + 2` の `10` は行数**（`GRID_ORIGIN_Y` と `2` は掛ける）

## サブが上げた保留の捌き（2026-09-14。**どちらも技術判断。PO へは上げない**）

### 1. `PresetMenu.ts` の `Math.floor` で ×1.5 にならない3箇所 → ⚠ **このまま許容する**

| | 旧 | 現在 | 正確な1.5倍 | ずれ |
|---|---:|---:|---:|---|
| `CELL_H` = `floor((ROWS_BOTTOM - ROWS_TOP) / ROWS)` | 90 | **136** | 135 | +0.74% |
| `PREVIEW_H` = `CELL_H - 33` | 68 | **103** | 102 | +0.98% |
| 縮小図の1升 = `max(3, floor(min(...)))` | 5 | **8** | 7.5 | +6.7% |

**理由**: ⚠ **この3つは「固定の寸法」ではなく「入る数を割り出す式」である。**
**残りの高さを行数で割って切り捨てる／枠に何px の升が入るかを切り捨てる**ものなので、
**座標系が変われば割り直されるのが正しい振る舞い**で、式は今のままで合っている。

**実害が無いことを確かめた**: **5行 × 136 = 680 ≤ 681**（一覧の範囲に収まる）／
**縮小図は 8 × 13 = 104 ≤ 105、8 × 10 = 80 ≤ 103**（枠に収まる）。
**画面上のずれは最大3px**（1280換算2px）。
⚠ **`Math.floor` を外しても 136.2 になるだけで 135 にはならない。**
**135 を出すには「1.5刻みで丸める」式に変えることになり、「式に書き直さない」に反する。**

### 2. コメント中の px が 1280系のまま → ⚠ **#117 に切り出した**

⚠ **機械的に 1.5倍してはいけない。**
**多くが Chromium での実測値**（「`10,000,000レン` は 183.2px になり、枠 174px からはみ出した」）で、
**掛けた数は誰も測っていない。**掛けると**測っていない数が「実測」として残る。**

**応急として `layout.ts` の冒頭に「以下のコメントの px は 1280系」と書いた。**
**1行ずつ「現在値か実測値か」を見分ける作業は #117。**
