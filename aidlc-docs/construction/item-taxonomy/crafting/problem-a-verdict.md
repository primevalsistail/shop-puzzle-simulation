# 問題A 判定 — 加工が「時間的に作れない」

独立評価。設計側の意図は見ていない（`problem-a-time.md` のみを読んだ）。
利益・儲けには踏み込まない。

---

## 0. まず、日の構造を数字にしておく

判定の全部がこの1本の式に乗るので、先に置く。時刻は 0:00 からの分。

| 枠 | 区間 | 長さ |
|---|---|---|
| 作業枠A | 360〜600（6:00-10:00） | 240分 |
| 営業 | 600〜1200（10:00-20:00） | 600分 |
| 作業枠B | 1200〜1440（20:00-24:00） | 240分 |

6:00 に所要 D 分の加工を始めたときの **失う営業分**：

```
損失(D) = clamp(D - 240, 0, 600)
```

つまり **3つの帯がある**。

| 帯 | D の範囲 | 失う営業分 | 意味 |
|---|---|---|---|
| 無償帯 | D ≤ 240 | **0** | 朝の作業枠に収まる。営業を1分も削らない |
| 有償帯 | 240 < D ≤ 840 | D − 240（0〜600） | 営業に食い込む。1分伸びるごとに営業1分を失う |
| 全損帯 | 840 < D ≤ 1080 | 600（全部） | 営業が消え、さらに夜の作業枠も食う |
| 不可 | D > 1080 | — | 日をまたぐので着手できない |

**重要**：損失は D に比例しない。**240分と840分に折れ目がある折れ線**である。
この非線形性は日の区分（240/600/240）が既に供給しているもので、加工ルール側で作る必要がない。
以下の A2 の判定はここが効く。

---

## 1. 結論（推す案）

### **A2-a（単純な割り算）を推す。A2-b・A2-c・A3・A4 はいずれも採らない。**

具体的には：

- 品は **工数** を持つ。値は **応急処置前の 30〜1440 に戻す**（圧縮を解く）
- プレイヤーは **加工値** を持つ。**初期 2 → 上限 6**
- 所要時間 = 工数 ÷ 加工値。**それだけ。追加の規則・門・割増は入れない**

これで全72品が初日から日に収まり（最大 1440÷2 = 720分 ≤ 1080）、
加工値が 2→6 に育つ間に、重い品が **有償帯 → 無償帯** へ順に移る。

**ただし、先に言っておくべきことがある。**

> **問題A（時間内に作れるか）は、A1（いま入っている応急処置）で既に解けている。**
> 15〜480分・全72品が日に収まる、で到達可能性の欠陥はゼロになっている。
> A2-a を推すのは「作れない品を無くすため」ではない。**A1 に無い「育つ値」が欲しいから**である。
> もし成長要素が要らないなら、**A1 のままで問題Aは閉じてよい**。これは正直に書いておく。

A2-a は A1 の上位互換になっている。**A1 は A2-a の断面にすぎない**からである
（工数 30〜1440・加工値 3 は、所要時間 10〜480 とほぼ一致する。現行の 15〜480 と同じ分布）。
つまり A1 → A2-a は作り直しではなく、**固定していた定数を変数に開く**だけの移行になる。

## 2. 置いた合格ライン

「解決した」の定義。5本、全部満たして合格とする。

| # | 条件 | 根拠 |
|---|---|---|
| **L1** | **どの加工値でも、全72品が「その日のうちに着手・完了」できる。**つまり常に D ≤ 1080。作れない品ゼロ | §2 の不具合そのもの。ここが本題 |
| **L2** | L1 が「時刻ギリギリ」で成立していない。**遅くとも 12:00 までに着手すれば間に合う**品しかない（＝D ≤ 720） | 「朝8時までに着手しないと不可」は、不具合ではないが事故になる。余裕を要求する |
| **L3** | **無償帯（D ≤ 240）に入る品と、入らない品の両方が存在する。**全部無償でも全部有償でもない | 加工時間が意思決定として機能する最低条件。全部無償なら加工は無コストになり、時間の概念が要らなくなる |
| **L4** | **軸も例外も増やさない。**品ごと1値（工数）＋プレイヤー1値（加工値）で閉じる。新しい定数・閾値・場合分けを持ち込まない | 単純な方に倒す |
| **L5** | **現行データから機械的に移行できる。**72品を人手で振り直さない | 応急処置を捨てるコストを払わない |

L1 が本丸、L4 が同点決勝。**L1 を落とした案は他がどれだけ良くても不合格**とする。

## 3. 案ごとの判定

### A1 — 尺度を一律に圧縮（現行）：**合格。ただし L3 が薄く、成長が無い**

| | |
|---|---|
| L1 | ✅ 最大480分。6:00 着手で 14:00 完了。営業6時間が残る。作れない品はゼロ |
| L2 | ✅ 最大480分なら 16:00 まで着手可能。時刻ギリギリの品は無い |
| L3 | △ 中央90分。**240分を超える品だけが営業を削る**が、その帯は 240〜480 しかなく、最大でも損失240分（営業の4割）で頭打ち |
| L4 | ✅ 最も単純 |
| L5 | ✅ 既に入っている |

**総合：問題A の 4本の設問のうち「作れない品が出ないか」は、A1 で既に達成されている。**
残る不満は §A1 が自分で書いている「プレイヤー側に育つ値が無い」の一点で、
これは **到達可能性の問題ではなく、進行設計の問題**。A1 を否定する理由には弱い。

---

### A2-a — 単純な割り算：**合格。推奨**

#### 検算1：「加工値が低いうちは工数の高いものが不利」は成立するか

**二通りの読み方があり、答えが逆になる。**

**(i) 品どうしの所要時間の比 → 成立しない。** これは §A2 の但し書きの通り。
工数 30 と 1440 の比は、加工値がいくつでも 48:1 のまま。加工値は全品に同じ倍率でかかるので、
比は絶対に動かない。これは割り算の性質なので検算するまでもなく確定。

**(ii) 失う営業分 → 強く成立する。** そして**ゲームで効くのはこちら**。
損失は clamp(D−240, 0, 600) という**折れ線**なので、比が一定でも損失の比は一定にならない。
数字を置く（工数は 30〜1440 に戻した前提、6:00 着手）。

| 工数 | 加工値 2 → D / 損失 | 加工値 3 → D / 損失 | 加工値 4 → D / 損失 | 加工値 6 → D / 損失 |
|---|---|---|---|---|
| 30（最軽） | 15 / **0** | 10 / **0** | 7.5 / **0** | 5 / **0** |
| 240 | 120 / **0** | 80 / **0** | 60 / **0** | 40 / **0** |
| 480 | 240 / **0** | 160 / **0** | 120 / **0** | 80 / **0** |
| 960 | 480 / **240** | 320 / **80** | 240 / **0** | 160 / **0** |
| 1440（最重） | 720 / **480** | 480 / **240** | 360 / **120** | 240 / **0** |

読み取れること：

- **軽い品は加工値がいくつでも損失0。**成長しても得るものが無い＝最初から最終形
- **重い品だけが状態遷移する。**工数1440 は 加工値 2→6 の間に 損失480 → 0 へ動く
- 損失の比を見ると、加工値2で 1440品:960品 = 480:240 = 2.0倍、加工値3で 240:80 = **3.0倍**、
  加工値4で 120:0 = **∞**。**所要時間の比は 1.5 倍で固定なのに、損失の比は加工値とともに動く**
- **「低い加工値では工数の高いものが不利」は、営業損失で測れば正しい。**しかも
  「所要時間の比」より遥かに鋭く効く（∞ になる区間がある）

**したがって §A2 の「単純な割り算だと品どうしの有利不利が変わらない」は、
所要時間の比としては正しいが、ゲーム上の帰結としては誤り。**
日の区分（240分の無償枠）が既に折れ目を作っているので、**噛み合わせ方を追加する必要がない。**
b・c は解決済みの問題を解こうとしている。

#### 検算2：合格ライン

| | |
|---|---|
| L1 | ✅ 加工値の**初期値が全て**。工数上限1440に対し、**初期 ≥ 1.34（=1440/1080）なら全品が日に収まる**。初期1だと 1440分 > 1080分で **§2 の不具合が完全に再発する**ので、初期1は禁止。**初期2を置けば最大720分**で確実に成立 |
| L2 | ✅ 初期2で最大720分 → 24:00−720分 = **12:00 まで着手可能**。「朝8時までに」の事故は起きない |
| L3 | ✅ 加工値2の時点で 工数240以下（＝D 120以下）は無償、工数480超は有償。両方存在する |
| L4 | ✅ **追加値は加工値1本のみ。**式は割り算1回。例外なし |
| L5 | ✅ 現行の 15〜480 に一律 ×3 で 45〜1440。もしくは圧縮前の原データを戻すだけ |

**総合：全て合格。**

#### 一点だけ注意（設計判断として残す）

**現行の圧縮スケール（15〜480）のまま A2-a を乗せると、成長帯が薄い。**
最大480分は無償境界240分のちょうど2倍しかないので、**加工値が1→2になった瞬間に全品が無償帯に入り、
そこで成長が終わる**（L3 が壊れる）。A2-a を採るなら **圧縮を解いて 30〜1440 に戻すのが前提条件**。
逆に言えば、A2-a は「応急処置をやめられる」ことが最大の利点であって、
圧縮を残したまま加工値だけ足すのは意味が薄い。

### A2-b — 門にする：**不合格（L4 違反、かつ式が定義されていない）**

**「加工値がその品の工数に届く」が単位として成立していない。**

加工値の定義は「1分あたりこなせる工数」＝ 工数/分。工数は「手間の量」。
`加工値 ≥ 工数` を素直に書くと `工数/分 ≥ 工数` → `1/分 ≥ 1` → **`所要時間 ≤ 1分`**。
つまり文字通りに実装すると「**その品が1分以内で作れるようになるまで着手不可**」という門になる。
明らかに意図と違う。

意図通りに動かすには「加工値がXに届いたら」の X を別途決める必要があり、
**72品ぶんの閾値 or 換算定数が新しく1本増える。**L4 に反する。

さらに決定的なのは、**A2-a には既に門が備わっている**こと。
「日をまたげない」＝ `工数 / 加工値 ≤ その時点の残り時間`。
加工値が低いうちは重い品に着手できず、育つと着手できるようになる——
**b が作りたい挙動は、a に既に入っている。**門を二重に置く理由がない。

---

### A2-c — 超過分に割増：**不合格（L1 を壊す。§2 の不具合を再生産する）**

**式が未定義な上、どう補っても悪化する。**

**文字通りに読むと破綻する。**`足りない分 = 工数 − 加工値` とすると、工数1440・加工値2で
`(1440÷2) × (1 + 1438) = 720 × 1439 = 1,036,080分`。b と同じ単位の不整合。

**好意的に読み替えても直らない。**「無償枠240分を基準にした超過率」と解釈して
`時間 = (工数/加工値) × (1 + max(0, 素の時間 − 240) / 240)` としてみる：

| 工数1440 のとき | 素の時間 | 割増後 | 判定 |
|---|---|---|---|
| 加工値 2.5 | 576分 | 576 × (1+1.4) = **1382分** | **> 1080 → 作れない**（L1 破り） |
| 加工値 3 | 480分 | 480 × (1+1.0) = **960分** | 24:00−960 = **8:00 までに着手しないと不可**（§2 の症状そのもの） |
| 加工値 4 | 360分 | 360 × (1+0.5) = 540分 | 可 |
| 加工値 6 | 240分 | 240 × (1+0) = 240分 | 可 |

**加工値が低いときに、いちばん重い品が作れなくなる。**
これは §2 で報告された不具合（1440分の品が永久に作れない／960分の品が朝8時締切）を、
**加工値という新しい形で復活させている。**

罰の方向も逆。c は「まだ届いていない品を、さらに遠ざける」。
**日をまたげない制約が既に絶対的な罰（＝着手不可）を課している**ところに、
その手前で追加の罰を重ねている。二重罰。

加えて基準値（上の 240）という定数が1本増える。L1・L4 両方に反する。**採る理由が無い。**

---

### A3 — 日をまたげるようにする：**不合格（L3・L4 を壊し、装置を1つ失う）**

| | |
|---|---|
| L1 | ✅ どんな長さでも作れる |
| L2 | — 概念が消える |
| L3 | ❌ **無償帯という概念が消える。**朝起きたら夜まで店が閉まっている＝営業600分を丸ごと失う日が生まれる。加工時間の意味が「営業と引き換え」から「単なる待ち」に変質する |
| L4 | ❌ 規則を1本消すので一見単純だが、**「寝ている間の進行」「起床時に加工中だった場合」「営業時間の途中で完了した場合」の3つの状態を新しく扱う必要が出る。**正味では複雑になる |
| L5 | ✅ |

そして最大の損失：**「日をまたげない」は制約ではなく設計装置である。**
これがあるから「今日この品を作るか、営業を優先するか」という1日単位の意思決定が生まれ、
在庫配置パズルと噛み合う。外すと加工は放置タイマーになる。

**A2 と組み合わせる場合はさらに悪い。**A3 は A2-a の自然な門（D ≤ 残り時間）を消すので、
加工値を上げる理由が「営業損失が減る」だけに痩せる。**A2 と A3 は組み合わせるべきでない。**

---

### A4 — 起きている時間を延ばす：**不合格（L1 を満たさない。文書自身が認めている）**

睡眠を全部削っても 1日 = 1440分 = 最大工数の所要時間そのもの。
**1440分の品は「6:00 に始めて翌6:00 に終わる」＝日をまたぐので、依然として着手不可。**
L1 を満たさない。単独では問題を解かない。

かつ、睡眠を削ると営業600分に対する作業枠が 240+240 → 最大 840分 に膨らみ、
**「営業を削らずに作れる品」の範囲が広がりすぎて L3 も壊れる**（加工がほぼ無コスト化する）。
「いちばん何も変えなくて済む」は正しいが、**何も解決しない**。

## 4. 見落としている案

「そもそも別の切り口がある」ものを5本。上から有力順。

### A5 — 工数の単位を「作業枠」にする（**A2-a に無料で足せる。推奨**）

分ではなく **240分＝1枠** を単位にして工数を表す。「半枠」「1枠」「6枠」。

- 何が良いか：**「日に収まるか」「営業を削るか」が暗算不要になる。**
  1枠以下＝無償、3.5枠以下＝営業内で完了、4.5枠が上限——と設計意図が数字に直接現れる
- §2 の不具合（1440分＝6枠が日に入らない）は、この単位なら**表を作った時点で目視で分かる**。
  分で書いていたから見落とした、という側面がある
- 表記の変更だけなので、A2-a と競合しない。**併用すべき**

### A6 — 中断・再開できるようにする（残り工数を持ち越す）

「日をまたげない」は残したまま、**1品の加工を作業枠A・Bにまたいで進められる**ようにする。
持つ値は「残り工数」1つ。

- L1 が構造的に解決する（どんな重い品も、朝240＋夜240を積めばいつかは終わる）
- **営業を1分も削らずに重い品を作る道が常に存在する**（何日かかけて）
- ただし「その日の意思決定」が「何日がかりの計画」に変わるので、遊びの粒度が変わる。
  状態も1つ増える（L4 に触る）
- **A2-a で足りるなら要らない。**A2-a を入れてなお重い品が辛すぎるなら、次の一手はこれ

### A7 — 加工中も店を開けたままにする（前提を覆す案）

**§1 の「加工している間は店が閉まる」が、問題A の唯一の原因である。**
時計が進むこと自体は問題ではなく、その間に客が来ないことが問題。

「営業中も加工は進むが、客が来ると中断されて加工が遅れる」なら、
時間の長短は「営業効率が落ちる」に変換され、**着手可否という崖が消える**。

確定済み前提を覆すので今回の選択肢としては範囲外だが、
**A1〜A4 は全部この前提の下流の対症療法**である、という指摘はしておく価値がある。
将来この前提を見直す機会があるなら、A1〜A4 の全てが不要になる。

### A8 — 「いつまでに着手すれば間に合うか」を画面に出す（設計変更ではない）

§2 の「960分のものは朝8時までに着手しないと不可」は、**不具合ではなく情報不足**。
締切が見えていれば制約として機能する。1440分の永久不可は UI では解けないが、
**A2-a を入れた後に残る L2 相当のヒヤリハットは、これで足りる。**
どの案を採っても入れておくべき。

### A9 — 上限を無償枠に合わせて切る（最も単純だが、加工の重みが消える）

所要時間の上限を **240分（朝の作業枠ちょうど）** にする。全品が営業を一切削らずに作れる。
問題A は定義ごと消滅する。

- L1・L2・L4・L5 は完全合格
- **L3 が壊れる。**加工が無コストになり、「作るか営業するか」の判断が消える
- 「いちばん単純」を最優先するならこれ。ただし**加工時間という軸を捨てるのと同義**なので、
  軸を残したいなら採らない

## 5. 補足（範囲外につき一行のみ）

工数の重い品が営業600分を大きく削ることの是非、
および加工値を上げる動機が採算に見合うかは、**利益側で扱うべき**。ここでは判定しない。
