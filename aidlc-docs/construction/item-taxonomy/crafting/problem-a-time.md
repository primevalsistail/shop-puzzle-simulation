# 問題A — 加工が「時間的に作れない」

**このファイルだけで判断できるように書いてある。他の資料は要らない。**
**⚠ この問題だけを見てほしい。利益・儲けの話はここでは扱わない**（別の人が別に見ている）。

---

## 1. 前提

**在庫配置パズル型の店舗経営シミュレーション。**船倉の升目が売り場。素材を仕入れて加工し、売る。

**一日の区分**（確定済み）

| 時刻 | 区分 |
|---|---|
| 6:00-10:00 | 作業 |
| 10:00-20:00 | **営業**（客が来るのはここだけ） |
| 20:00-24:00 | 作業 |
| 24:00 → 6:00 | 睡眠（飛ばして翌日へ） |

**起きている時間は 1080分/日**（6:00〜24:00）。**営業は 600分/日。**

**加工のルール**（確定済み）
- **加工している間は店が閉まる。**所要分だけ時計が進み、**その間は客が来ない**＝売る機会の損失
- **その日のうちに終わらない加工は着手できない**（日をまたげない）

## 2. 何が起きたか

**所要時間がもともと 30〜1440分だった。**1080分を超える3本
（チーズ・干し肉・ぶどうの酒＝各1440分）が**何時に始めても日をまたぐので、永久に作れなかった。**
960分のものも**朝8時までに着手しないと不可**だった。

**いまは応急処置として、所要時間の尺度を一律に圧縮してある**（上限 1440分 → **480分**）。
現在の分布: **15分〜480分**（中央90分）。**全72レシピが1日に収まっている。**

## 3. 案

### A1 — 尺度を一律に圧縮する（**いま入っている応急処置**）
所要時間の上限を 480分にした。品どうしの比はほぼ保たれている。
**プレイヤー側に育つ値は無い。**最初から最後まで同じ時間がかかる。

### A2 — 「工数」と「加工値」に分ける
品は **工数**（その品を作るのに要る手間の量）を持つ。プレイヤーは **加工値**（1分あたりこなせる工数）を持ち、
**遊ぶうちに上がる**。所要時間 = 工数 ÷ 加工値。**上手くなるほど速く作れる。**

ただし**単純な割り算だと全品が同じ倍率で速くなるだけ**で、品どうしの有利不利は加工値がいくつでも変わらない。
そこで噛み合わせ方に案がある。

- **A2-a 単純な割り算**: 時間 = 工数 ÷ 加工値
- **A2-b 門にする**: 加工値がその品の工数に届かないと**そもそも着手できない**
- **A2-c 超過分に割増**: 時間 = (工数 ÷ 加工値) × (1 + 足りない分)。**届いていない品ほど余計に時間がかかる**

### A3 — 日をまたげるようにする
「その日のうちに終わらない加工は着手できない」をやめ、寝ている間も加工が続く。
**尺度を縮めなくてよくなる**が、**朝起きたら夜まで店が閉まっている**という状態が起きうる。

### A4 — 起きている時間を延ばす
睡眠を削って1日を長くする。**いちばん何も変えなくて済む**が、
1440分の加工は24時間ぶんなので、**睡眠を全部無くしても日をまたぐ。**

3. **A2 を採る場合、a・b・c のどれか。**「加工値が低いうちは工数の高いものが不利」が
   **実際に成立するか**を、式に照らして確かめてほしい
