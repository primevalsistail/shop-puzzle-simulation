# 問題B — 加工しても「利益が上げられない」

## 1. 前提

**在庫配置パズル型の店舗経営シミュレーション。**船倉の升目が売り場で、品は升目を取る。
素材を仕入れて加工し、売る。**加工している間は店が閉まる**（作る時間 ＝ 売る機会の損失）。

**値段の決まり方**（いまの式）

```
tier1（素材）の売値 = 基準値 × 贅沢さの倍率        （日用1.0 / 上等1.5 / 贅沢2.4）
tier2以上の売値     = (Σ 材料の売値) × 加工倍率 ÷ 出力数
加工倍率            = 1.30 + 0.25 × min(所要分 / 240, 2) + 0.15 × 贅沢さの順位
```

**贅沢さは回転率も持つ**（同じ時間で何個捌けるか）: **日用 1.0 ／ 上等 0.7 ／ 贅沢 0.45**。
狙いは「**日用＝薄利多売／贅沢＝厚利少売**」の対比を作ること。

**設計上の警告**（過去に明文化されている）:
> 加工倍率を**所要時間だけ**から決めてはならない。`利益 ÷ 時間` が全品一定になり、
> **「何を買ってどう売っても結局同じ」**になる。回転率の差を必ず併せて入れること。

## 2. 何が起きているか（実測・72レシピ）

**「稼ぎ密度」＝ 利益 × 回転率 ÷ 1個あたりの加工分**、で測った。

| | 値 |
|---|---|
| 稼ぎ密度の開き | **57倍**（最小0.15 / 中央0.71 / 最大8.46） |
| 上位5品 | **全部 7.5〜15分の冷たい飲みもの**（温めたぶどうの酒・冷たいミントの茶・冷たいいちごの乳・塩レモン水・いちごのかき氷） |
| 工数との相関 | 利益幅 **+0.49** ／ 利益率 **+0.42** ／ **稼ぎ密度 −0.41** |
| 贅沢さ別の稼ぎ密度（中央値） | 日用 **0.52** ／ 上等 **0.92** ／ **贅沢 1.89** |

**読み取れること**

1. **「難しいほど利益幅も利益率も大きい」は成立している**（相関 +0.49 / +0.42）。
   **なのに時間で割ると逆転する**（−0.41）。長い加工は時間あたりでは全部負ける
2. **短い仕上げを1回足すのが最強。**例:
   ```
   冷たいミントの茶: 材料費364 → 売値536   （15分で +172）
   　材料: ミントの茶(136) 氷×2(48) 蜂蜜(132)
   ```
   **加工倍率が材料費に掛け算される**ので、**高価な材料に短い仕上げを足すほど儲かる**
3. **回転率が効いていない。**狙いは「日用＝薄利多売／贅沢＝厚利少売」だったが、
   **贅沢が稼ぎ密度でも一方的に勝っている**（0.52 → 0.92 → 1.89）。対比が逆転している

## 3. 案

### B1 — 売値を工数比例にする
```
売値 = Σ材料費 + 所要分 × 単価
```
**かけた手間ぶんだけ儲かる。**高価な材料に15分の仕上げを足しても15分ぶんしか儲からない。
**⚠ §1 の警告（`利益÷時間` が一定になる）に正面から当たる。**回転率が効いていないといけない。

### B2 — 材料費比例と工数比例を混ぜる
```
売値 = Σ材料費 × 小さめの倍率 + 所要分 × 単価
```
材料費の寄与を弱め、工数の寄与を足す。**B1 ほど一様にならない。**

### B3 — 回転率を直す
式は変えず、**贅沢さの回転率（1.0 / 0.7 / 0.45）を、対比が実際に出る値にし直す。**
いまは贅沢の利幅が大きすぎて 0.45 では抑えきれていない。

### B4 — 升目で差をつける
稼ぎ密度は**時間**だけで割っている。この店は**升目が売り場**なので、
**升目あたりの稼ぎ**も同時に効くはず。短い飲みものが強いのは、時間だけで見ているからかもしれない。
式を変えず、**かたち・大きさの側で差をつける。**

### B5 — 現状維持
57倍の開きと「短い飲みもの一択」を、**問題ではないと判断する。**

2. **§1 の警告（`利益÷時間` が一定になると「結局同じ」になる）を、その案が踏まないか**
3. **「簡単で利益率がいい」と「難しいけど利益幅がいい」が両立するか。**
   どちらか一方が常に強いなら、その案は失敗
4. **B4 について**: 升目まで入れて測るのが正しいのかどうか。正しいなら、どう測るのか
