# 相談：店舗経営シミュレーションで「利益効率が一択になる」問題

## ゲームの構造

在庫配置パズル型の店舗経営シミュレーション。

- 船倉が升目になっていて、**そこがそのまま売り場**。品はテトリスのように場所を取る（1〜6升）
- 素材を仕入れ、加工し、売る
- **加工している間は店が閉まる**（作る時間＝売る機会の損失）
- 一日は 6:00-10:00 作業 / 10:00-20:00 営業 / 20:00-24:00 作業 / 24:00→6:00 睡眠
- 起きている時間は 1080分/日、営業は 600分/日
- **その日のうちに終わらない加工は着手できない**

現在 122品・72レシピ。

## 値段の決まり方

```
tier1（素材）の売値 = 基準値 × 贅沢さの倍率      （日用1.0 / 上等1.5 / 贅沢2.4）
tier2以上の売値     = (Σ 材料の売値) × 加工倍率 ÷ 出力数
加工倍率            = 1.30 + 0.25 × min(所要分 / 240, 2) + 0.15 × 贅沢さの順位
```

贅沢さは**回転率**も持つ（同じ時間で何個捌けるか）: 日用 1.0 / 上等 0.7 / 贅沢 0.45。
狙いは「日用＝薄利多売 / 贅沢＝厚利少売」の対比を作ること。

## 問題

「稼ぎ密度 ＝ 利益 × 回転率 ÷ 1個あたりの加工分」で測ると：

- **開きが57倍**（最小0.15 / 中央0.71 / 最大8.46）
- **上位5品が全部 7.5〜15分の冷たい飲みもの**
- 工数との相関: 利益幅 **+0.49** / 利益率 **+0.42** / **稼ぎ密度 −0.41**

つまり「難しいほど利益幅も利益率も大きい」は成立しているのに、**時間で割ると逆転する**。

原因は**加工倍率が材料費に掛け算される**こと。例：

```
冷たいミントの茶: 材料費364 → 売値536（15分で +172）
  材料: ミントの茶(136) 氷×2(48) 蜂蜜(132)
```

**高価な材料に短い仕上げを1回足すのが最強**になる。

## これまでに検証して、ダメだった案

**前提**: 時間あたりの稼ぎと升目あたりの稼ぎの比を取ると `s / (t·v)` になり、
**材料費も加工倍率も約分で消える**（s=升目, t=分, v=回転率）。
つまり**利益の大きさをどういじっても「何が何に強いか」は動かない**。

| 案 | 結果 |
|---|---|
| 売値を工数比例に `Σ材料費 + 分×単価` | 稼ぎ密度が定数化。日用が常勝かつ同率。「何を作っても同じ」になる |
| 材料費比例と工数比例を混ぜる | `d(密度)/dt = −ΣM(k−1)v/t² < 0` が**どんな係数でも成立**。短い品が必ず勝つ |
| 回転率(1.0/0.7/0.45)を調整 | 回転率は両軸の分子に共通で入るので**対比を作る力が原理的にない**。揃えると「どれも同じ」になる |
| 升目で差をつける | 後述。単独では効かない |
| 利益を `clamp(利益, 分×lo, 分×hi)` で両端を切る | 外れ値は抑えるが**フロンティアが広がらない** |

## いま行き詰まっている点

2資源（時間・升目）のパレートフロンティアに乗る品を数えると、**72品中2品しかない**。
理想は5品以上（各贅沢さ層から、短い品も長い品も）。

広がらない理由が数字で出た：

| | 開き |
|---|---|
| **利益** | **186倍** |
| 所要分 | 48倍 |
| **升目** | **6倍**（1〜6升） |

**升目という資源の幅が6倍しかないのに、利益が186倍ある。**
6段階しかない量で186倍の量を釣り合わせられない。

組み合わせを試した結果：

| 案 | フロンティア | 時間軸の開き | 升目軸の開き |
|---|---|---|---|
| 現状 | 2品 | 57倍 | 93倍 |
| 利益クランプのみ | 2品 | 40倍 | 83倍 |
| 利益クランプ ＋ 升目∝売値 | 2品 | 40倍 | **21倍** |
| 利益クランプ(強) ＋ 升目∝売値 | 3品 | **7倍** | 40倍 |

# 検討中の案：価格を3層に分ける

上記の行き詰まりに対して、以下の案が出ている。**実測したところ、かなり効く。**

## 考え方

```
売値 S = 材料費 C + 加工利益 P + 配置利益 B
```

役割を分ける。

| 層 | 役割 |
|---|---|
| **材料費 C** | **回収するもの。**利益源ではない。加工して損をしないための土台 |
| **加工利益 P** | **加工時間から作るもの。材料価格と切り離す** |
| **配置利益 B** | **大きく稼ぐためのもの。**隣接条件から算出 |

**加工利益は `材料費 × 加工倍率` にしない。**
その式だと高価な材料ほど加工利益まで大きくなり、
「高価な材料に短い加工を足す」商品が極端に強くなるため（現状の問題そのもの）。

```
加工利益 P = K × 所要時間^α     （0 < α < 1）
```

`α < 1` にすることで、

- 加工時間が長いほど**利益額**は増える
- ただし**時間あたり利益**は徐々に下がる

つまり **短時間加工＝時間効率がよい／長時間加工＝1回の利益額が大きい**、という役割分担になる。

## 配置ボーナスの掛け方

```
実売値 = 基礎売値 × (1 + 隣接ボーナス)   ← これはダメ
```

材料費まで倍率の対象になるので、高価な材料の商品ほど隣接ボーナスの絶対額も大きくなり、
再び高価格商品が有利になる。**利益部分だけに配置効果を乗せる。**

```
売値 S = 材料費 + 加工利益 × (1 + 配置倍率)
```

例（材料費500・加工利益100）:

| 配置 | 売値 | 利益 |
|---|---|---|
| なし | 600 | 100 |
| 良い | 700 | 200 |
| 非常に良い | 900 | 400 |

**加工すれば最低限黒字になるが、大きく儲けるには配置を考える必要がある**、という形にできる。

## 設計原則としての整理

1. 材料費は必ず回収する
2. 加工時間に応じて基礎利益を与える
3. **加工利益は材料価格と切り離す**
4. 加工時間が長いほど利益額は増えるが、時間効率は徐々に下がる
5. **最も大きな利益差は隣接配置から発生させる**
6. 隣接ボーナスは材料費ではなく**利益部分**に作用させる

狙うゲーム構造は「**何を作るかで基礎利益を作り、どう並べるかで大きく稼ぐ**」。

## 主人公ステータスとの接続

- **手際** … 加工難易度と加工時間に作用（どう作るか）
- **見立て** … 配置による利益に作用（どう売るか）

# この案を実データ（72レシピ）で試算した結果

**行き詰まりが解消される。**

| | 現状 | `C + K×t^0.8` | `C + K×t^0.8 × 贅沢さ倍率` |
|---|---|---|---|
| **利益の開き** | **186倍** | **22倍** | — |
| **フロンティア** | **2品** | **15品** | **15品** |
| 時間軸の開き | 57倍 | 4.4倍 | **2.3倍** |
| 升目軸の開き | 93倍 | 24.9倍 | 16.8倍 |
| 層 | — | 日用・上等 | **上等・贅沢** |
| tier | — | 2・3・4 | 2・3・4 |

**理由**: 利益が材料費から切り離されると、利益の幅は `t^α` だけで決まる。
所要分の幅は48倍なので `48^0.8 ≈ 22倍` に縮み、**升目の幅6倍と釣り合う桁になる。**

α を変えた場合:

| α | 利益の開き | フロンティア | 時間軸 | 升目軸 | 短/長 |
|---|---|---|---|---|---|
| 0.4 | 4.7倍 | 11品 | 17.8倍 | 9.6倍 | 短○ 長× |
| 0.5 | 6.9倍 | 8品 | 12.6倍 | 11.4倍 | 短○ 長× |
| 0.6 | 10.2倍 | 10品 | 8.9倍 | 13.8倍 | 短○ 長○ |
| 0.7 | 15.0倍 | 13品 | 6.3倍 | 17.7倍 | 短○ 長○ |
| **0.8** | 22.1倍 | **15品** | 4.4倍 | 24.9倍 | 短○ 長○ |

## ⚠ 試算で見つかった穴

**`P = K × t^α` だけだと `贅沢` がフロンティアから完全に消える。**

利益に贅沢さが入らないのに、回転率だけ 0.45 で罰せられるため、贅沢が一方的に不利になる。
**利益側にも贅沢さ倍率を掛けると層は戻る**（上等・贅沢）が、**今度は日用が落ちる**。
3層すべてをフロンティアに載せる係数がまだ見つかっていない。

## 聞きたいこと

1. **この3層構造（材料費 + 加工利益 + 配置利益）の方向で妥当か？**
   見落としている副作用はあるか？
2. **α と、贅沢さの扱いをどう決めるべきか。**
   `P = K × t^α` だと贅沢が消え、`× 贅沢さ倍率` だと日用が消える。
   **3層すべてがフロンティアに載る形はあるか？**
   （回転率 1.0/0.7/0.45 のほうを動かすべきか？）
3. **配置利益 B を「利益部分にだけ乗せる」設計は、
   `B` が大きくなるほど「加工の中身が何であれ配置がすべて」になる危険はないか？**
   `B` の上限や、`P` との比率はどう置くべきか？
4. **2資源（時間・升目）だけで戦略の多様性を作るのは、そもそも無理があるか？**
   第3の希少資源（資金・需要の飽和・在庫の上限など）が要るか？
5. パレートフロンティアの品数を増やす、という目標設定自体が妥当か？
   別の測り方をすべきか？

## 制約

- **軸・値・例外・特別扱いを増やしたくない**（複雑化を避ける方針）
- アイテムの属性は5軸のみ：主種類 / tier（導出）/ 産地 / 贅沢さ / 向く土地
- 価格・tierは**導出値**で、手書きしない
- 規則はアイテムIDを直接参照しない
