# 1. 分かっていること

## 問題A（時間的に作れない）

**すでに解けている。**所要時間の尺度を 1440分 → 480分 に圧縮する応急処置を入れてあり、
**全72レシピが1日に収まっている（作れない品はゼロ）。**
以下はすべて「**育つ値を入れるか**」という別の話。

**⚠ こちらが以前『単純な割り算では有利不利が変わらない』と言ったのは、ゲーム上は誤りだった。**
6:00 着手なら **失う営業分 = `clamp(所要 − 240, 0, 600)`**（朝の作業枠が240分あるため）。

| 工数1440 vs 960 | 損失の比 |
|---|---|
| 加工値2 | 480:240 = **2.0倍** |
| 加工値3 | 240:80 = **3.0倍** |
| 加工値4 | 120:0 = **∞** |

**折れ線なので、所要の比が一定でも損失の比は動く。**一日の区分（240/600/240）が非線形性を供給していた。

**S − D 方式についての検算**:
```
2^((D−S)/5) = 2^(D/5) × 2^(−S/5)
```
**`S` が全品共通の倍率として括り出せる**ので、**指数式そのものは「÷加工値」と代数的に同じ。**
**差を作っているのは `clamp(…, 0.25, 4.0)` のほう** —
低い `D` の品は先に床に着いて止まり、高い `D` の品はまだ伸びる。**成長すると格上が格下に追いつく。**

**`D ≤ S+8` の門は成立している**（判定役が落とした A2-b は `加工値 ≥ 工数` の**単位が合っていなかった**別物）。
ただし**「作れない品」が意図的に戻る**。元の問題は*永久に*作れないことだったので、`S` が伸びれば解ける以上は別物。

## 問題B（利益が一択）

**未解決。**稼ぎ密度は **57倍**の開きがあり、**上位5品が全部 7.5〜15分の冷たい飲みもの**。

**決め手の数式**: 時間あたりと升目あたりの稼ぎの比は `s / (t·v)` になり、**材料費も加工倍率も約分で消える。**
→ **利益の大きさをどういじっても「何が何に強いか」は動かない。**

| 案 | 判定 |
|---|---|
| B1 工数比例 | **不合格** — 稼ぎ密度が定数化。日用が常勝かつ同率。Phase 1 の警告に直撃 |
| B2 混ぜる | **不合格** — `d(密度)/dt < 0` が**どんな係数でも成立**。短い品が必ず勝つ |
| B3 回転率を直す | **不合格** — 回転率は両軸の分子に共通で入るので**対比を作る力が原理的にない** |
| **B4 升目で差をつける** | **条件つき合格** — **「加工は嵩を減らす」の明文化が必須。**深い贅沢品を6升にすると差が1.03倍しかつかず、ミント茶が両軸で勝つ。**深い贅沢品は3升以下** |
| **B8'（新案）** | `利益 = clamp(ΣM×(m−1), 分×lo, 分×hi)`。**80%の品は現行式のまま**、突出した両端だけ切る |

## 主人公ステータス案の当てはめ

| | 効き | 理由 |
|---|---|---|
| **手際**（時間短縮） | **効く（問題A）** | 中身は「加工値」と同じ。提案の「作れないではなく作ると重い」は判定役が A2-b を落とした理由と一致 |
| **見立て**（配置・隣接） | **効く（問題B）** | **`s/(t·v)` を動かせる唯一の方向**。主人公の設定「見立て好き」とも直結 |
| **技術**（出力数増・材料減） | **⚠ 悪化** | 利益の増分が**売値に比例**。**いま最強の「高価な材料に短い仕上げ」が最も得をする** |
| **目利き**（仕入れが安い） | **⚠ 悪化** | 同上。増分が**材料費に比例**するので、材料費が高く時間が短い品が最も得をする |

**⚠ いまプレイヤー側の値はゼロ。**入れる本数だけ「複雑化しない」方針から離れる。

# 2. 決めてほしいこと

## Question 1 — 問題A（時間）の解き方

A) **S − D 方式を採る**（`D ≤ S+8` ＋ `clamp(2^((D−S)/5), 0.25, 4.0)`）**【推奨】**
   4段階（作れない／背伸び／適正／量産）が作れる。
   **条件2つ**: `D` は **tier から導出**（手書きしない。122品ぶんの新データを増やさないため） ／
   **「一度に作れる個数の増加」は入れない**（利益を売値比例で増やすので、いまの一択を強める）
B) **A2-a（÷加工値）**
   代数的にはほぼ同じで**もっと単純**。ただし4段階も「格上が追いつく」感覚も出ない
C) **`clamp` だけ採る**（門は入れない）
   「作れない品」を戻さずに、**成長で格上が追いつく**部分だけ取る
