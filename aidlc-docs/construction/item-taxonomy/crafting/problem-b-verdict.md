# 問題B 判定 — 加工しても利益が上げられない / 稼ぎ方が一択

独立評価。`problem-b-profit.md` のみを読んで書いた。他の資料・コード・履歴は参照していない。
「時間内に作れるか」には踏み込んでいない。

---

## 1. 結論

**推すのは B4 ＋「利益を時間比例の帯で挟む」（後述 B8'、B2 の限定版）。**
B4 が構造の修理、B8' が大きさの較正。**B1・B2 単独・B3 単独・B5 はいずれも不合格。**

理由を一行で言うと:

> **B1・B2・B3 は利益の「大きさ」しか動かさない。「何が何に強いか」は動かせない。**
> **稼ぎ密度の比 `時間密度 ÷ 升目密度 = 升目 s ÷ 加工分 t` から、材料費も加工倍率も回転率も全部消える。**
> **`s/t` を触れるのは B4 だけであり、したがって二つの戦略を同時に成立させられるのも B4 だけ。**

導出（後で使うので先に置く）。1升に1個並ぶとして

```
時間密度 D_t = 利益 ÷ 加工分            = p / t
升目密度 D_s = 利益 × 回転率 ÷ 升目      = p·v / s
D_t / D_s = s / (t·v)
```

`p`（＝ΣM×(m−1)）が丸ごと約分される。B1・B2・B3 が触るのは全部 `p` か `v` であって、
`p` は両軸の分子に共通で入るから、**どちらの軸で誰が勝つかの相対関係を一切変えられない**。
順位のシャッフルはできるが、軸を増やせない。軸が一本しかない最適化の解は常に一品である。
**「一択」は式の係数の問題ではなく、測っている資源が一つしかないことの必然。**

なお付随して指摘しておく。**説明書の「稼ぎ密度 ＝ 利益 × 回転率 ÷ 加工分」は2軸を混ぜている。**
回転率は「1升を1日占有して何個捌けるか」＝**升目側**の量で、加工分は**時間側**の量。
1個作るのに `t` 分かけて `p` 稼ぐのだから、加工時間あたりの効率は `p/t` であって `p·v/t` ではない。
（幸い結論は変わらない。`p/t` で並べ替えても冷たいミントの茶が首位のままである — §3.6 で数字を出す。）

## 2. 置いた合格ライン

**まず測り方を2軸に分ける。**
- 時間軸 `D_t = 利益 ÷ 加工分`（回転率は入れない）
- 升目軸 `D_s = 利益 × 回転率 ÷ 升目`

**この2つを1つのスカラーに重み付けで合成してはいけない。**合成した瞬間に軸が1本に戻り、
また一品が勝つ。72レシピを `(D_t, D_s)` の散布図に置き、パレート非劣解（フロンティア）を見る。

そのうえで、以下5つを全部満たしたら「解決」とする。

| # | 条件 | 現状 |
|---|---|---|
| **L1** | **支配品がない。**両軸の上位3に同時に入る品が存在しない | ✗（冷たいミントの茶が事実上の支配品） |
| **L2** | **フロンティアに厚みがある。**非劣解が5品以上あり、日用/上等/贅沢の各層から1品以上、かつ短工程（≤30分）と長工程（≥120分）の両方から1品以上載る | ✗（上位5品が全部 7.5〜15分の冷たい飲みもの） |
| **L3** | **軸の開きが釣り合う。**各軸の max/min が **10倍以内**、かつ **2軸の開きの比が3倍以内** | ✗（時間軸57倍。升目軸は未測定） |
| **L4** | **切替点が盤面の内側にある。**最適な陳列構成が入れ替わる `升目S / 加工分T` の比が、実プレイで通るレンジ（序盤の小さい船倉〜終盤）の 20〜80% 分位のどこかにある。フロンティアがあっても実際には常に片側しか使われないなら意味がない | 未測定 |
| **L5** | **§1警告を踏まない。**`利益 ÷ 加工分` が定数に張り付く品が **全体の20%以下** | ✓（現状は張り付いていない） |

**L3 の「10倍以内」の根拠**: 差をゼロにしてはいけない（差がないと選択が消える＝§1警告そのもの）。
一方 57倍は「首位以外は全部ゴミ」。オーダーが1つ違う程度＝10倍なら、
他の制約（材料の在庫、升目、資金）でひっくり返る余地が残る。

**L3 後半「2軸の開きの比が3倍以内」が実は一番効く。**
軸が2本あっても、**開きが大きい方の軸が意思決定を独占する**。
現状 時間軸57倍に対し、資金効率（＝利益率 `1−1/m`）の開きは
`m−1` が 0.316（15分・日用）〜1.10（480分・贅沢）で **わずか3.5倍**。
16倍の差があるので、資金がどれだけ苦しくても利益率は判断材料にならない。
**「難しいけど利益幅がいい」が「簡単で利益率がいい」に勝てないのはこれが原因。**
軸を足すだけでは足りず、**開きを同オーダーに揃えないと足した軸は死ぬ。**

## 3. 案ごとの判定

数字の出所を明示する。**実測は「冷たいミントの茶」1品だけ**（説明書 §2）。
他は説明書の式・統計値から再構成した代表例で、**例示であって実測ではない**。
再構成が妥当なことは §3.0 で検算する。

### 3.0 検算（式が説明書の実測と合うことの確認）

```
冷たいミントの茶: 上等(rank1), 15分
  加工倍率 m = 1.30 + 0.25×(15/240) + 0.15×1 = 1.4656
  材料 ΣM = 136 + 48×2 + 132 = 364   ← 説明書の「氷×2(48)」は単価48
  売値 = 364 × 1.4656 = 533.5        （説明書の実測 536、誤差0.5%）
  利益 = 172, 稼ぎ密度 = 172×0.7/15 = 8.03  （説明書の最大 8.46 と整合）
```

以後の代表例（`m` は式から、`ΣM` は仮置き）:

| | 贅沢さ | 分 | m | ΣM | 利益 p | v | 稼ぎ密度 p·v/t |
|---|---|---|---|---|---|---|---|
| **A** 冷たいミントの茶（実測） | 上等 | 15 | 1.466 | 364 | 172 | 0.7 | **8.03** |
| **B** 長い日用品 | 日用 | 240 | 1.55 | 300 | 165 | 1.0 | 0.69 |
| **C** 長い贅沢品 | 贅沢 | 240 | 1.85 | 1000 | 850 | 0.45 | 1.59 |
| **D** 短い日用品 | 日用 | 15 | 1.316 | 100 | 32 | 1.0 | 2.13 |
| **E** 深い贅沢品 | 贅沢 | 480 | 2.10 | 1500 | 1650 | 0.45 | 1.55 |

B の 0.69 が説明書の中央値 0.71、C・E の 1.55〜1.59 が贅沢の中央値 1.89、A の 8.03 が最大 8.46 に
それぞれ近い。**代表例5品で説明書の分布をほぼ再現できている**ので、以下の比較に使う。

---

### 3.1 B1（売値 = ΣM + 分 × 単価）— **不合格**

```
利益 = t × r
稼ぎ密度 = t·r·v / t = r·v      ← t も ΣM も消える
```

**§1の警告に正面から当たる。**時間密度が **品目によらず定数**になり、残るのは回転率だけ。
すると

```
日用 r×1.00 ／ 上等 r×0.70 ／ 贅沢 r×0.45
```

**日用が常勝**する。しかも同じ贅沢さの中では全品まったく同率で、「何を買ってどう売っても同じ」。
開きは 1.0/0.45 = **2.2倍**しかなく、L3 の「差がなさすぎ」側で落ちる。L1・L2 も全滅。
贅沢品は作る理由が消えるので、贅沢さの階層自体が死ぬ。

判定基準3（両立）については、**字面だけは満たす**ので明記しておく。
`利益率 = t·r / (ΣM + t·r)` は ΣM が小さいほど高いので、
`r=10` として「ΣM=100・15分」の品は利益率 60%、「ΣM=400・240分」の品は 86%。
つまり「安い材料・短時間＝高利益率」「高い材料・長時間＝高利益幅」の対比は作れる。
**しかし密度が定数なので、その対比が意思決定に影響しない。**判定できても選ぶ意味がない。**失敗。**

### 3.2 B2（ΣM×小さめ倍率 ＋ 分×単価）— **単独では不合格 / 帯に直せば合格圏**

```
稼ぎ密度 = ΣM(k−1)·v / t + r·v
d(密度)/dt = − ΣM(k−1)·v / t² < 0     （k > 1 である限り常に負）
```

**`k` をどう選んでも、時間について単調減少。短い品が必ず勝つ。**
`k→1` で B1（全部同じ）、`k` を上げると現状（57倍）。
**この直線上に「両立する点」は存在しない。**二つの失敗の間を補間しているだけ。

数値（`k=1.10, r=1.0/分`）:

| | 利益 | 稼ぎ密度 |
|---|---|---|
| A（15分・ΣM=364） | 36.4 + 15 = 51.4 | 51.4×0.7/15 = **2.40** |
| B（240分・ΣM=300） | 30.0 + 240 = 270 | 270×1.0/240 = **1.13** |

開きは 11.6倍 → 2.1倍に縮むが、**首位は変わらない**。L1・L2 は落ちる。

**ただし「min/max で挟む」形に直せば話が変わる。**これを **B8'** として §5 に出す。

### 3.3 B3（回転率を直す）— **単独では不合格。ただし B4 の下では必要な較正**

**回転率は両軸の分子に共通で入るので、対比を作る力が原理的にない。**

```
D_t / D_s = s / (t·v)
```

に `v` は入るが、`v` は贅沢さ3段階しか取らない共通因子で、
**同じ贅沢さの品の間の相対関係は `v` では一切動かない**。
つまり B3 は「日用/上等/贅沢という3つのグループの高さ」を上下させるだけで、
「短い仕上げ一択」という**グループ内の**問題には触れられない。

そのうえ、狙い通りに中央値を揃えようとすると値が壊れる:

```
必要な v_贅沢 = 0.45 × (0.52 / 1.89) = 0.124   （8日に1個しか売れない）
必要な v_上等 = 0.70 × (0.52 / 0.92) = 0.396
```

`v=0.124` は「升目を8日間ふさぐ置物」。そして揃えた結果は
「日用も贅沢も稼ぎは同じ」＝**§1警告の別の顔**。L3 の下限側で落ちる。**単独では失敗。**

B4 の下では意味がある。升目密度 `p·v/s` の大きさを決めるのは `v` なので、
**軸を作った後にその軸の傾きを合わせる道具**としては B3 が要る。順序は B4 → B3。

### 3.4 B4（升目で差をつける）— **条件付き合格。これが必須の一手**

**唯一 `s/t` を動かせる案。**説明書の直感（「短い飲みものが強いのは時間だけで見ているから」）は
方向としては正しいが、**符号が保証されていない。条件を満たさないと逆効果になる。**

**条件: 出力の升目 `s` は、所要分 `t` に対して劣線形でなければならない。**

```
d(log s) / d(log t) < 1        理想は s ≈ 一定
```

`s ∝ t` だと `s/t` が一定になり、**升目軸は時間軸とまったく同じ順位を返す。B4 が丸ごと無効。**
そして「長い加工＝手のかかった大物＝場所を取る」は自然な発想なので、**放っておくとこの罠に落ちる。**

失敗する例（深い贅沢品を6升にした場合）:

| | 時間効率 p/t | 升目効率 p·v/s |
|---|---|---|
| A（15分・1升） | 172/15 = **11.5** | 172×0.7/1 = **120.4** |
| E（480分・**6升**） | 1650/480 = 3.4 | 1650×0.45/6 = 123.8 |

**A が両軸で勝つ（升目側で 1.03倍差しかない）→ 支配品。L1 で落ちる。**

成功する例（深い贅沢品を1升にした場合）:

| | 時間効率 p/t | 升目効率 p·v/s |
|---|---|---|
| A（15分・1升） | **11.5**（3.3倍勝ち） | 120.4 |
| E（480分・**1升**） | 3.4 | **742.5**（6.2倍勝ち） |

**両方がフロンティアに載る。**設計の言い方に直すと
**「加工は嵩を減らす」**（葡萄の樽 → 一本の酒瓶）。これは物理的にも自然で、
かつ「素材を仕入れて加工して売る」というゲームの筋にも合う。

**具体的な設計制約**（上の数値から）: E が A に升目軸で2倍以上勝つには
`1650×0.45/s > 2×120.4` → **`s < 3.1`**。深い贅沢品は **3升以下**に収める必要がある。

**最適解が実際に混ざることの確認（L4）。**
升目 `S`、1日に使える加工分 `T` として、1升を A に割くと1日 0.7個売れるので
加工 `0.7×15 = 10.5分/日`・利益 `172×0.7 = 120.4/日`。E は `0.45×480 = 216分/日`・利益 `742.5/日`。

```
T < 10.5·S              → 時間が足りない  → 時間効率最大のA一色（升が余る）
10.5·S < T < 216·S      → 混合が最適
T > 216·S               → 升が足りない    → 升目効率最大のE一色
```

**混合帯が `T/S` で 10.5〜216、幅20倍。**実プレイのレンジは楽にこの内側に入る。**L4 合格。**

数値例（S=20升、T=600分/日）:
```
x_E = (600 − 10.5×20) / (216 − 10.5) = 1.90升,  x_A = 18.1升
利益 = 18.1×120.4 + 1.90×742.5 = 2179 + 1412 = 3591/日
A一色: 20×120.4 = 2408/日（時間が390分余る）→ 混合が +49%
E一色: 4320分必要で不可能
```

**「日用の飲みもので回転を作りつつ、余った時間で贅沢品を1〜2升ぶん仕込む」が最適解になる。**
これは説明書が最初に狙っていた「薄利多売と厚利少売の併存」そのもの。
しかも **升目が増える（船倉が育つ）と最適な混合比が動く**ので、成長に伴って選択が変化する。

**§1警告**: B4 は式を触らないので `利益÷加工分` は定数化しない。**踏まない。**
**残る不足**: B4 は 57倍の開きを縮めない（L3 が未達）。だから次が要る。

### 3.5 B5（現状維持）— **不合格**

説明書自身が明示している狙い「日用＝薄利多売／贅沢＝厚利少売」に対し、
実測は 0.52 → 0.92 → **1.89** で**贅沢が薄利多売側でも勝っている**。
狙いの逆が出ているので、これは「許容できる偏り」ではなく**設計の失敗**。
57倍・上位5品が全部同カテゴリで L1〜L3 全滅。

### 3.6 補足 — 説明書の指標を `p/t` に直しても結論は変わらない

`稼ぎ密度` から回転率を外して純粋な時間効率にしても:

```
A 11.5 ／ C 3.54 ／ E 3.44 ／ D 2.13 ／ B 0.69
```

**A が首位のまま。**回転率が短い飲みものを勝たせているのではない。
勝たせているのは **「加工倍率が材料費に掛け算される一方、時間項が 240分で +0.25 しか動かない」**
という式の形そのもの。`m` は 15分で 1.32、480分で 1.80（rank0）— **時間が32倍でも倍率は1.4倍**。
分子が1.4倍しか伸びないのに分母が32倍になれば、時間効率は必ず落ちる。**これが −0.41 の正体。**

同じ理由で **利益率 `1 − 1/m` は `m` だけの関数**、つまり
**所要時間と贅沢さだけで決まり、材料費には一切依存しない。**
`m` は時間と共に単調増加するので、**「簡単な品の利益率が高い」は現行式では原理的に作れない。**
説明書の相関 +0.42 はこれの直接の帰結であり、B1〜B5 のどれもここを直さない（B1 は §3.1 の通り
形だけ直すが密度が死ぬ）。**判定基準3 は B4 だけでは満たせない。**

## 4. B4 について — 升目まで入れて測るのは正しいか、どう測るか

**正しい。というより、入れないと問題は原理的に解けない。**

理由:
1. **店の売上の上限は「升目 × 回転率」で決まる。**升目は時間と同格の希少資源であって、
   時間だけで割った指標は現実の制約の半分しか見ていない。
2. **希少資源が1つの最適化は、最適解も1つ。**一択は指標の設計から必然的に出てくる。
   資源が2つになって初めて、最適解が2品の混合になりうる（線形計画の基底の大きさ＝拘束の本数）。
   **「一択でなくする」ことと「拘束を2本にする」ことは同じこと。**
3. 説明書の `利益×回転率÷加工分` は既に升目側の量（回転率）を時間側の比に混ぜ込んでおり、
   **半分だけ入れてしまっている**。だから読みにくい。分けるのが正しい。

**測り方（そのまま手順として使える）:**

```
1. 72レシピそれぞれについて
     D_t = 利益 ÷ 加工分                （回転率を入れない）
     D_s = 利益 × 回転率 ÷ 出力の升目
2. (D_t, D_s) の散布図を描き、パレート非劣解を抽出 → L1・L2 を判定
3. 各軸の max/min と、2軸の開きの比を出す → L3 を判定
4. corr(所要分, D_t) と corr(所要分, D_s) を出す
     合格: corr(t, D_t) の絶対値 < 0.2（現状 −0.41）かつ corr(t, D_s) ≥ +0.2
     ← 片側を潰しただけで逆側に報酬がないなら失敗、を検出する
5. corr(log 所要分, log 升目) の回帰係数を出す
     合格: 傾き < 1（劣線形）。1に近いと B4 は無効になる
6. 上の2資源LPを、実プレイで通る (S, T) のレンジで解き、
   最適構成が入れ替わる T/S がレンジ内にあるか → L4 を判定
```

**やってはいけないこと**: `α·D_t + β·D_s` のような重み付き合成スコアで順位を作ること。
軸を1本に潰すので、また一品が勝つ。**2次元のまま見る。**

## 5. 見落としている案

推す順に4つ。上2つは強く推す。

### B8'（推奨・B8 を含む上位版）— 利益を「時間比例の帯」で挟む

```
利益 = clamp( ΣM × (m − 1),  分 × lo,  分 × hi )
売値 = ΣM + 利益
```

現行式を**真ん中の帯では丸ごと温存**し、両端だけ時間比例で切る。1行の変更。

- **上限 `hi`** が「高価な材料に15分の仕上げを足す」だけを狙い撃ちで潰す。
  A（ΣM=364・15分・利益172）は `hi=3.0/分` なら利益45に落ち、時間密度 `45×0.7/15 = 2.1`（8.03から）。
  一方 C（240分・利益850）は上限 `240×3.0 = 720` に軽く当たる程度、
  `hi=5.0/分` なら上限1200で**無傷**。**長い加工は一切影響を受けない。**
- **下限 `lo`** が「簡単な品の利益率が構造的に最低」（§3.6）を直す。
  D（ΣM=100・15分・利益32・利益率24%）は `lo=5.0/分` なら利益75、**利益率43%**。
  ΣM が大きい品ほど下限は効かないので、**「安い材料・短工程＝高利益率」が初めて成立する。**
  **判定基準3（両立）を満たせるのは、B1〜B5 の中には無く、これだけ。**

**較正**: `lo, hi` は現行の `利益/分` 分布の **P10 と P90** に取る。
そうすれば L5（帯に当たる品が20%以下）が構成的に保証され、
80%の品は現行式のまま＝ `利益÷加工分` は定数化しない。**§1警告を踏まない。**
（現状 `利益/分` は 0.15〜12.1 の**約80倍**の開き。P90/P10 に潰せば L3 の10倍以内に入る。）

**B2 との違い**: B2 は全品を混ぜるので `d(密度)/dt < 0` が全域で残る（§3.2）。
B8' は帯の外だけ触るので、**帯の中では材料費比例の設計思想がそのまま生き、
帯の外では時間比例になる。**「両方の失敗の中間」ではなく「両方の良いところの貼り合わせ」。

### B6 — 需要側に飽和を入れる（収穫逓減）

`v_i` を「その品をいくつ並べているか」の減少関数にする: `v_i(x) = v_i0 / (1 + x/κ)`。

**収穫逓減は、資源が1つのままでも一択を壊せる唯一の仕組み。**
最強の品でも並べすぎれば限界稼ぎが次善品を下回り、そこで手が止まる。
最適解は自動的に「上位数品の混合」になり、**κ 一つで「何品目を並べるゲームか」を直接制御できる。**
B4 と直交するので併用可。世界観的にも「同じ物ばかり出すと客が飽きる／値が崩れる」で自然。
**B4 だけだと最適解は2品（拘束2本）にしかならない。B6 を足すと3〜5品に広がる。**

### B9 — 「加工しない」を対抗馬として強くする

現状は加工しないと儲からない設計だが、**遠方の素材を素のまま売る**選択肢を強くすると、
加工分 `t = 0` の端点が生まれ、**時間軸で無限大の効率**を持つ。すると

- 時間が足りないとき → 仕入れて素売り
- 升目が足りないとき → 深く加工して1升の価値を上げる

という対比が **B4 と同じ構造の、より分かりやすい形**で出る。
「加工は升目を節約する手段」という位置づけが明確になり、B4 の意図をプレイヤーに伝えやすい。

### B7 — 付加価値を材料費の逓減関数にする（B8' が採れないときの代替）

```
売値 = ΣM + c × √ΣM × g(所要分)
```

高価な材料に一手足す旨味が `√` で鈍る。B2 より狙いは正確だが、
**式の形が変わって直感が効かなくなる**うえ、`c` と `g` の2つを較正する必要がある。
B8'（1行・現行式温存・パラメータ2つだが意味が明快）の方が単純なので、**優先順位は下。**

## 6. まとめ（実施順）

| 順 | 手 | 直すもの | 判定基準 |
|---|---|---|---|
| 1 | **B4** — 出力の升目を `t` に対して劣線形（深い品ほど1升あたり高価に）。深い贅沢品は3升以下 | 軸が1本しかない（＝一択の構造的原因） | L1, L2, L4 |
| 2 | **B8'** — 利益を `[分×P10, 分×P90]` で挟む | 57倍の開き ／ 簡単な品の利益率が構造的に最低 | L3, L5, 判定基準3 |
| 3 | **B3** — 回転率を再較正 | 升目軸の傾き（B4 で軸ができた後の較正） | L3 |
| 4 | （任意）**B6** — 需要飽和 | 最適解を2品から3〜5品へ広げる | L2 |

**却下: B1（§1警告に直撃・日用一択）／B2 単独（首位が変わらない）／B3 単独（対比を作る力がない）／B5。**

**この判定で一番外してほしくない点**: B4 は「升目も見よう」という測り方の話ではなく、
**升目の値そのものを設計する話**である。`s ∝ t` に置いた瞬間 B4 は何もしない（§3.4）。
**「加工は嵩を減らす」を明文化しない B4 は、B5（現状維持）と同じ結果になる。**
