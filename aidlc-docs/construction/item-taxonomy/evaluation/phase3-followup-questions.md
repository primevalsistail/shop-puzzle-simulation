# Phase 3 の評価 — 宿題の扱い

**判定結果**: [evaluation-result.md](evaluation-result.md)

**結論は「進んでよい。軸の設計には戻らない」。**軸に戻るべき項目は0件だった。
ただし**条件つき**で、検査2と検査5が不合格のまま残っている。

| 残った宿題 | 判定役の切り分け |
|---|---|
| **A. 揺れ5件が未決着**（依頼書 §4） | 開いたまま新品30個を振らせると、分布が「軸の性能」ではなく「振った人の読み」を測る。**ストレステスト前に決着させることが条件** |
| **B. 検査2 不合格** — `どこでも` 50.9%・需要4行が 3.8倍 | **品＋定義文の問題。**揺れ1を倒すだけで 3.8倍→1.7倍。ほかに「`道具` 19品のうち 寒い/暑い/温暖 が0」 |
| **C. 検査5 不合格** — 解禁条件 100 の対価が 143倍散る | **規則の定数の問題。**最も欲しい品が最も解禁できない＝向きが逆 |
| **D. R5・D2 が `産地` を直読み** | **規則の層の問題。**加工品60品に1品も当たらない＝上達するほど効かなくなる |
| **E. rules.ts の U4 と evaluate.ts の食い違い** | 評価器が `r.id === 'U1'` とIDで名指しして救っており、U5 を足しても無視される |

**なお**: 依頼書 §5 の「60本中49本が2島以上・四島＋海が5本」は**実測と合いません**。
こちらでも独立に検算し、**44本 / 1本**（透過的に遡った場合。直接材料なら 26本 / 0本）でした。
どの数え方でも 49/5 になりません。**この記録の訂正は、どの道を選んでも行います**（不要なら Q1 の Other に）。
