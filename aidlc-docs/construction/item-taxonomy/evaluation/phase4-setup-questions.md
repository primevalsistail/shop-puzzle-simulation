# Phase 4（拡張ストレステスト）の起こし方

**やること**: 新品30個・新レシピ10本を投げ込み、**Phase 0 の INV-1〜6 が破れるか**確認する。
**破れたら Phase 1（軸の設計）に戻る。**

**測るのは事実**（既存の定義を1行でも触ったか／既存の値が動いたか／型に導出値が生えたか／
規則にIDが出たか／`売値(出力)×出力数 > Σ売値(材料)` か）なので、計測自体は誰がやっても同じ。
**分かれるのは「どういう30個を投げるか」と「誰が選ぶか」。**

---

## Question 1
どういう30個を投げますか。

A) **わざと軸に収まりにくいものを狙う（破壊試験）****【推奨】**
   粘土もの・金属もの・生きもの・サービス的なもの・複数の島にまたがる素材など、
   **いまの5軸で置き場所に困るもの**を意図的に混ぜる。**壊れるなら早く壊す**のが Phase 4 の目的
B) **素直な追加**（いまの世界観から自然に出てくる品を30個）
   体系が普段づかいで壊れないかを見る。**壊れにくいので、通っても情報が少ない**
C) **半々**
X) Other（[Answer]: の後に記述してください）

[Answer]: C

## Question 2
誰が30個を選びますか。

A) **独立した別セッションに選ばせる****【推奨】**
   **このセッションは宿題B で品を足しており、無意識に「受け止めやすい品」を選ぶ危険がある。**
   INV-1〜6 の中身は渡さず、「この5軸に置きにくいものを出せ」とだけ頼む
B) **このセッションが選ぶ**（速いが、手加減が入りうる）
X) Other（[Answer]: の後に記述してください）

[Answer]: A

---

## 補足 — 30個をコミットするかは、結果を見てから決めます

Phase 4 は**体系の検査**であって品揃えを増やす工程ではないので、
**投げた30個をそのまま残すとは限りません。**壊れ方を見てから、残す／捨てる／作り直すを判断します。
