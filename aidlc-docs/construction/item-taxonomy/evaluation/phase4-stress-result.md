## 2. 不変条件（INV-1〜6）— 置けた23品での結果

| | 判定 | 中身 |

| **INV-1** 追加しても既存は変わらない | **違反 0** | 既存120品の **tier も売値も1つも動かなかった**（120品×2項目を全件照合） |

## 3. 数で出なかったほう — 起こした側が申告した「軸への疑問」10件

**全文は [phase4-new-items.md](phase4-new-items.md) §4・§5。**重いものだけ:

1. **`温暖な土地` が「その他」になっている。**生鮮の食料はすべてここに落ちる（新品だけで8品）。
   温める・冷やす・束ねる/容れる のどれでもない食べものに、他の行き場が無い
2. **`実りの土地` の「手段だけ・結果は含まない」に、除外先が指定されていない。**
   梅干し・干し柿・かぼちゃが宙に浮く。**梅干しと干し柿はほぼ同性格なのに、
   「干した形が小さいか」という起こした側が勝手に引いた線だけで違う値になった**
3. **`どこでも` を三通りに使ってしまった。**定義の二つ（土地を選ばない／用途が定まらない）に加えて、
   **軸の問いが品に届かなかったときの捨て場**として使った（帆・繕い・だし）
4. **`贅沢さ` が品の性質ではなく客の事情を聞いている。**猫・羊で答えが定まらない。
   下限も浅く、水と火が `日用` に潰れた
5. **産地の `なし` が四つの意味を背負っている**（旬が無い／海のもの／加工品／世界の外）
6. **海鳥の卵で産地の規則が二本同時に当たり、優先順位が書かれていないので
   文書の並び順だけを根拠に決めた**（判断の中身ではない）
7. **軸に無いものが三つ**: 傷み具合／鮮度、使っても減るか、レシピの無い加工品の tier
8. **月単位の加工（干す・漬ける・発酵）を表す場所が無い。**
   「加工中は店が閉まる」世界で、梅干しの数ヶ月をどう書くか
9. **水と道具を材料欄に書くべきか分からない**（減る材料と、使うだけの道具が同じ書き方になる）
