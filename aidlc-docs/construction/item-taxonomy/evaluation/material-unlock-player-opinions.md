# 遊ぶ人5人の意見 — 素材を「100個売ったらどこでも買える」にするか

コード・設計文書・git 履歴・こちらの推奨・過去の却下理由は**一切渡していない**。
5セッションは互いを知らず、独立に答えている。

## 1. 結論 — **提案された形に賛成した人は 0 / 5**

| 視点 | 結論 | 一言 |
|---|---|---|
| 効率型 | **条件つき。提案の形なら入れない** | 「解放できるなら全部解放するのが最適」と判断してしまい、**面白い状態をわざわざ潰す作業に何時間も使う**ことになる |
| のんびり型 | **条件つき。ただし「100個」では私に一生届かない** | **罰が重い人ほど条件に届かない。**もう困っていない人にだけ配られる救済 |
| パズル型 | **入れない** | 加工品の解禁は**取引**、素材の解禁は**免除**。「考えることが減って、しかも得をする」が一番よくない |
| 世界観型 | **入れない** | 頑張ったご褒美が**島の個性の消滅**。報酬の向きが逆 |
| 素 | **入れない** | 加工品のは「解禁」だが、素材のは「**撤廃**」。見た目が同じなので同じ良さがあるように錯覚する |

**5人とも「産地縛りそのものは残してほしい。むしろこのゲームの一番いいところ」と書いている。**
賛成が0なのではなく、**不満の在りかが違う**という一致。

## 2. 「100個売ったら」という条件への批判（4人が独立に同じ穴を指摘）

- **解放だけを回収する投げ売り作業が最適になる**（効率・パズル・世界観・素の4人）。
  素材を安値でダンプするのが最短ルート。**加工が面白いゲームなのに、加工しないのが最適な区間ができる**
- **よく使う素材ほど解放されない**（素）。羊毛は毎回フェルトにするので生では売らない。
  **どうでもいい素材から先に解放される**
- **救済の向きが逆**（のんびり）。詰まっている人ほど売れていないので届かない
- **タイミングが逆**（パズル・素）。やりくりを覚えきって面白くなった頃に、やりくりが取り上げられる。
  **上手くなるほど簡単になる**

## 3. 入れた場合に失われるもの（挙がった順に頻度が高いもの）

1. **升目のやりくりが消える**（5人全員）。「先の島のために積む＝売り場が狭くなる」という
   **痛みのある選択**がなくなり、升目は常に売り場に全振りが正解になる
2. **島の顔が消える**（5人全員）。「ミフユリア＝毛皮と氷の島」が「毛皮がちょっと安い島」になる
3. **40日周期が時計として意味を失う**（パズル・世界観・素）。先を読む理由がなくなる
4. **順路が選べない設計の意味が薄れる**（世界観・パズル）。ただの待ち時間になる

## 4. 本当の不満はどこか — 5人が同じ3つを挙げた

| # | 不満 | いつ | 何人 |
|---|---|---|---|
| **(a)** | **知りようがなかった。**1周目に、30日前に通り過ぎた島の素材が要ると初めて知る | 2〜5時間目 | 5人 |
| **(b)** | **「あと1個」で40日。**小さい読み違えに対して罰が大きすぎ、しかも**打つ手がない** | 5〜10時間目 | 5人 |
| **(c)** | **買い物リストが固定され、暗記・帳簿仕事になる** | 10時間目以降 | 4人 |

- **(b) の二重の痛み**（効率・世界観・素）: 作れないだけでなく、**半端に集めた素材が40日間ずっと升目に居座る**
- **(c) は解禁では直らない**（パズル）。むしろ**制約が足りないほうの問題**

## 5. 5人が出した代案 — 2つに収束した

### 代案1 — **割高・少量の調達**（**5人全員**が挙げた）

呼び方は違うが中身は同じ。「行商人とすれ違う」（素）／「島の店の隅によその品が3つだけ倍の値段で並ぶ」（世界観）／
「割高な取り寄せ」（効率・のんびり）／「端数だけ金で埋める」（パズル）。

**全員が同じ歯止めを付けている**:
- **1寄港あたり数個まで**（「9個を10個にはできるが、0個を10個にはできない」— パズル）
- **産地の1.5〜2倍**。「自分で運べば済むのにあえて買う＝完全に損」（パズル）
- **(b) にだけ効き、計画の代わりにはならない**

> **効率型の指摘**: これは罰を「待ち時間」から「金」に置き換えるので、
> **「今回は取り寄せて損切りする／次の周まで我慢して利幅を守る」という判断が増える。**
> 考えどころは減らない

### 代案2 — **不足を先に見せる**（4人。効率型のみ挙げず）

島にいるうちに「次にここへ戻るまでに要る素材と、いま持っている数の差分」を見せる。
**買うかどうかは決めさせる。**

> 「**買い忘れは自分の責任にしたいが、知らなかったを責任にされたくない**」（パズル）
> 「縛りが嫌なのではなく、**暗算を強要されるのが嫌**」（素）
> 「攻略サイトを見ないので、**ゲームの中に情報があるかどうかが全部**。
> 　**素材の開放より、こっちを先にやってほしいくらい**」（のんびり）

### その他（1〜2人）

- **周回ごとの揺らぎ**（パズル・世界観）— (c) に効く。「答えを消すのではなく、答えを毎回変えてほしい」
- **代用材**（素）— 毛皮が切れたらトナカイの革で代用。出来は落ちて安く売れる。「作れない」が「今回は下位版」になる
- **樽・木箱**（素）— まとめて詰めると少ない升目で運べるが、**中身は売り場に出せず、開けるのに時間がかかる**
- **素材の劣化**（効率）— 余る側にもコストを付け、「上限まで買う」を正解でなくする。ただし本人も「管理が増えるので好みではない」
- **待ち時間にやることを残す**（のんびり）— 店の改装・並べ替え・値段の見直し
- **やらないでほしい**（世界観）— **升目の外に置ける倉庫。**「今回の案より害が大きい」

## 6. こちらの所見との突き合わせ

| こちらが挙げていた点 | 5人の反応 |
|---|---|
| 報酬の向きが逆（巡らなくてよくなることが報酬） | **一致**（パズル・世界観・素が独立に同じことを言った） |
| 加工品の解禁と素材の解禁は別物 | **一致し、より鋭い言葉になった** — 「取引 vs 免除」「解禁 vs 撤廃」 |
| 在庫パズルが薄くなる | **5人全員が最重要として挙げた**（こちらの想定より重い） |
| 本当の問題は「取り返しがつかない」ことでは | **一致。**ただし**もう1つあった** → **(a) 知りようがない**（情報の問題）。**5人全員が挙げ、こちらは見落としていた** |

**こちらが見落としていた穴**: **「100個売る」条件そのものが投げ売り作業を最適化する**（4人が独立に指摘）。
判定役も検査5でこの条件を不合格にしたが、**理由は「対価が143倍散る」であって、この穴ではなかった。**
つまり**加工品側の U2 にも同じ問題があるかどうかは、まだ誰も見ていない。**
