## 4. 迷いの記録

### 4-1. 素直な追加のほうで迷ったところ

**A4 大根 — 「向く土地」がどちらにも読めた**
大根は生鮮なので定義どおりなら `温暖な土地`。しかし煮て食べれば体を温めるので `寒い土地` にも読めます。
「向く土地」の定義が **品そのものの性質** を聞いているのか、**その品を使った結果** を聞いているのかが定義文から
決められませんでした。生のまま売るのだから品そのものは生鮮だ、という線を自分で引いて `温暖な土地` にしています。
同じ迷いは A1 ふきのとう、A6 鱈、A15 木の匙にもあります（匙は熱いものを掬うが、匙自体は温めない）。

**A5 梅 — 「一般的にどの季節のイメージか」が二つある**
梅の花は早春、梅の実は初夏です。産地の決め方は「季節のイメージ」だけを見ろと書いてあるので、
どちらのイメージを取るかで島が変わります（ハルヴェラ／リナツィア）。
**「梅」という語から先に浮かぶのは花のほう**、という理由でハルヴェラにしました。これは私が引いた線で、
定義文には根拠がありません。

**A8 梅干し／A9 干し柿 — 「実りの土地」から締め出された品の行き先が無い**
どちらも「多すぎる収穫を捌く」ために作られる品です。ところが定義は「蓄えるは**手段**（塩・容れ物）に限り、
**蓄えた結果**（保存食そのもの）は含まない」と明記しているので、`実りの土地` を選べません。
残るのは、
- `温暖な土地`（持ち歩き）… ただし定義は「**持ち歩くために作られた形をしているか**」で見ろと言っている。
  干し柿は小さく干し上がるので形として持ち歩きに向く、と読んで A9 はこちらにしました。
- `どこでも`… 定義は「土地を選ばない／用途が一つに定まらない素材」。梅干しは用途がはっきりしているので
  本当は当てはまりません。それでも他に置き場が無く、A8 は **どこでもへ落とすかたちで妥協** しました。

A8 と A9 は性格がほとんど同じ品なのに、**「干した形が小さいか」だけで違う値になっています。**
この線引きは私が作ったもので、定義から出てきたものではありません。

**A13 木綿の手ぬぐい — 暑い土地と温暖な土地の両方に読めた**
汗を拭う・濡らして首に巻く＝熱を逃がす、で `暑い土地`。一方、軽装で持ち歩く布＝ `温暖な土地` にも読めます。
「濡らして使う」ほうが用途として強いと見て `暑い土地` にしました。

**A7 わかめ — `どこでも` の二つの意味が混ざった**
`どこでも` の定義には「土地を選ばない」と「用途が一つに定まらない素材」の二つが入っています。
わかめは後者のつもりで置きましたが、この二つは本来別の話です（§5 に書きました）。

### 4-2. 置きにくい品のほうで迷ったところ

**B1 乳の出る羊 — 「主種類」を埋められませんでした**
生きた羊は、乳を出せば `飲みもの` の元、毛を刈れば `衣類` の元、潰せば `食料` です。
**そのどれでもあり、いま現在はそのどれでもありません。** 主種類は「これは**何であるか**」を聞く軸ですが、
生きものは「何になりうるか」でしか答えられませんでした。ひとつ選ぶと嘘になるので、空欄にしています。
贅沢さも同様で、暮らしの道具として買うなら `日用`、財産として買うなら `贅沢` です。
売り手側から見て「無くても困らないが暮らしを良くする」だろうと踏んで `上等` にしましたが、これは妥協です。
升目 2×3 も苦しく、**羊は形が決まっておらず、動くし、寝ると縮みます。**

**B2 蜜蜂の巣箱 — tier の考え方に噛み合いませんでした**
tier は「どれだけ加工されているか」をレシピから自動で決める、とあります。
巣箱は R10 で作れるので tier は決まります。ところが**中身の蜂蜜は誰も加工していません。**
勝手に増えます。「加工されている度合い」でこの品を測ると、箱の分しか数えられません。
主種類も、箱として見れば `道具`、蜜を出す点では `食料` です。箱のほうを取って `道具` にしました。
向く土地も、蜜は「実りの土地」の産物という気がしますが、定義の「束ねる・容れる・蓄える」には当たらないので
`どこでも` へ落としています。

**B3 りんごの苗木 — 産地の規則が二つの季節を指した**
りんごの旬は秋（ノアキータ）ですが、苗木を植えるのは春です。
**「その品が一般的にどの季節のイメージか」で決めろと言われると、りんごの苗木は春のイメージです。**
一方「りんご」という語のイメージは秋です。同じ規則が二つの答えを出したので、
**品の名前ではなく品の使いどきを取る**、という線を自分で引いてハルヴェラにしました。
主種類も、食べられない・着られない・使う道具でもないので、消去法で `道具` にしています。これは嘘に近いです。

**B4 鼠捕りの猫 — 主種類も贅沢さも値段も埋められませんでした**
猫は売り物なのか、船の備品なのか、こちらが決められません。
- 主種類: 四つのどれでもありません。空欄。
- 贅沢さ: 蓄えを守る役として買えば `日用`、連れとして買えば `贅沢`。**同じ猫を同じ値段で、
  買う客によって理由が変わります。** 贅沢さは「客がどれだけ奮発して買うか」＝**客側の事情**を聞く軸なので、
  品の側の性質としては答えが出ませんでした。空欄。
- 値段: 空欄。
- 向く土地だけは `実りの土地` と書けました（蓄えを鼠から守る＝多すぎる収穫を捌く側の道具）。
  ただしこれも「守る」であって「束ねる・容れる・蓄える」ではありません。

**B5 種火の壺 — 品なのか、船の設備なのか**
「加工している間は店が閉まる」世界で、火はほぼすべての加工の前提です。
売り物として棚に出す品でありながら、**これが無いと船倉の他のレシピが動かない**という点で、
他の品と同列に扱えません。向く土地も、熱を与えるから `寒い土地` と書けますが、
**暑いリナツィアでも煮炊きには火が要ります。** 定義は「体を温めるのに役立つ」なので文字どおりなら `寒い土地`。
用途の実態と定義がずれたまま `寒い土地` にしました。

**B6 真水の樽 — 贅沢さの下限が無い**
`日用` の定義は「無ければ困るので、**値段を見て買う**もの」です。
水は無ければ死にますが、**四島のどこでも汲めるので、そもそも値段を見て買うものではありません。**
「無ければ困る」の度合いが `日用` より一段深く、しかも値がほとんど付かない。
この段が軸に無いので `日用` に押し込みました。値段 4 も名目です。
主種類も、飲むから `飲みもの` ですが、実態は R4・R9 のような**加工の材料**です。

**B7 空の松樽 — 「何度も使うもの」が軸に出てこない**
樽は使っても減りません。中身を出せばまた樽です。ところが**中身を入れると「塩漬けの樽」など別の品になり、
中身を出すとまた「空の松樽」に戻ります。** 一つの実体が品名を行き来する動きを、
5軸のどこにも書けませんでした。四つの値自体は埋まりますが、**埋まったところが品の本質を捉えていません。**

**B8 端切れ — 小さすぎて升目にも値段にも乗らない**
1升も要りません。値段も 2 と書きましたが、実際は「ついでに付ける」ものです。
主種類は、布だから `衣類`、火口や詰め物として使うなら `道具`。用途が定まらないので `どこでも` の
定義（用途が一つに定まらない素材）には合いますが、主種類のほうには「定まらない」に相当する値がありません。
布であることを取って `衣類` にしました。

**B9 帆 — 大きすぎ、そして売り物ではない**
既存に「木綿の帆布」があるので、帆そのものは自然に作れます。しかし帆は**船の一部**です。
売り物として棚に出すことは無いのに、船倉の升目は食う。
主種類は、布として `衣類`、船を動かす仕掛けとして `道具`。動かす側を取って `道具` にしました。
向く土地は**どの定義にも当たりません**（風を受けることは、温めも冷やしも束ねも容れもしません）。
`どこでも` へ落としましたが、これは「土地を選ばない」でも「用途が定まらない」でもなく、
**軸の問いが帆に届いていないだけ**です。

**B10 繕いの手間 — そもそも品ではない**
客の持ち込んだ服を直して代金だけ受け取ります。**升目を占めず、在庫にならず、産地も無く、
主種類の四つのどれでもありません。** 店舟の商いとしてはごく自然にありうる（衣類の加工品が19もある世界です）のに、
品の表に一行として置いた瞬間、ほとんどの欄が空になります。
主種類は空欄にしました。升目は 0 と書きましたが、0 という値が許されているかは分かりません。

**B11 昆布のだし — 客に売らない中間物**
飲めるので `飲みもの` に置きましたが、**単体では誰も買いません。** 次の料理の材料です。
贅沢さは「客がどれだけ奮発して買うか」を聞く軸なので、**客が買わない品には答えがありません。**
`日用` と書いたのは、そう書かないと表が埋まらないからです。
向く土地も同じ理由で `どこでも` に落としました。
（既存の「蕎麦粉」「毛糸」「木綿糸」も同じ性格のはずで、これは私が新しく作った問題ではなさそうです。）

**B12 海鳥の卵 — 産地の規則が二本、同時に当たった**
- 「海のものは `なし`」… 海鳥です。
- 「旬が春ならハルヴェラ」… 繁殖期は春です。
既存の「かもめの羽根」があるので、海鳥そのものは世界にいます。
卵は**島の崖で採る**ので、海のものと言い切るのも苦しい。
規則が二本当たったときにどちらが優先するかが書かれていないので、
**「なし」のほうが例外規定として後に書かれている**という、文書の並び順だけを根拠に `なし` にしました。
これは中身の判断ではありません。

**B13 漂着した異国の壺 — 産地も tier も置けませんでした**
「四島とそれを結ぶ穏やかな海。それ以外の土地は無い」「粘土は無い」と書いてあります。
だから焼きものの壺は、**この世界の中では作れません。**
- 産地: 四島のどれでもなく、海のものでもなく、加工品でもない（誰かが加工したが、その誰かは世界の外にいる）。
  `なし` は「旬を持たないもの」の値なので、これに当てはめるのは意味が違います。空欄にしました。
- tier: 「レシピから自動で決まる」とあります。**レシピが存在しない加工品には tier が決まりません。**
この品を出した理由は、四島だけの世界に「外から来たもの」を一つ置くと、
産地の軸が `なし` を二通りの意味（旬が無い／世界の外）で使わされるからです。

**B14 着古した毛皮裏の外套 — 同じ品なのに値が違う**
新品と同じレシピ、同じ tier、同じ主種類、同じ向く土地です。違うのは**傷み具合**だけ。
5軸に傷み具合の欄が無いので、**表の上では新品と見分けがつきません。**
贅沢さだけが動くと考えて `贅沢`→`日用` に落としましたが、これは
「同じ品の贅沢さが状態によって変わってよいのか」という判断を、私が勝手にしたものです。
（B1 の羊が老いる、B3 の苗木が育つ、B12 の卵が古びる、も同じ問題です。）

**B15 かぼちゃ — 産地も向く土地も、二つに割れた**
- 産地: 採るのは夏の終わり（リナツィア）、食べるイメージは冬（ミフユリア）、実りとしては秋（ノアキータ）。
  **一つの品に三つの島が当たりました。** 「一般的な季節のイメージ」という基準は、
  かぼちゃのように**採りどきと食べどきがずれる作物**には答えを出しません。
  実りの塊という見た目を取って `ノアキータ` にしましたが、根拠は弱いです。
- 向く土地: 生鮮なので `温暖な土地`。しかし**割らなければ何ヶ月も置けます**＝「蓄える」に近い。
  ただし定義は「蓄えるは手段に限る」なので `実りの土地` は選べません。`温暖な土地` に妥協しました。

### 4-3. レシピで迷ったところ

**R1 梅干し／R2 干し柿 — 「かかる分数」が加工時間として異常**
梅干しは本来数ヶ月、干し柿も数週間です。300分・240分と書きましたが、
これは「他の加工品と並べたときに極端にならない数字」を選んだだけで、実態とは関係ありません。
**「加工している間は店が閉まる」世界で、月単位で待つ加工をどう表すのか**が分かりませんでした。
時間の経過だけで進む加工（干す・漬ける・発酵）は、船倉を塞がずに進んでよいはずですが、
それを表す場所がありません。

**R4 松の葉の茶／R9 昆布のだし — 「真水の樽」を材料に数えるべきか**
水を材料に書くと、ほぼ全レシピに水が1個ずつ並びます。書かないと、水が無くても茶ができます。
書くほうを選びましたが、**既存レシピが水をどう扱っているか分からないので、噛み合っていない可能性があります。**
また樽は使っても減らない（B7）ので、「材料として消える」と書いてよいのかも分かりません。

**R8 木の匙 — 道具を材料に書いた**
「やすり×1」を材料に入れましたが、やすりは使っても無くなりません。
**減る材料と、使うだけの道具**が、材料欄では同じ書き方になってしまいます。

**R10 蜜蜂の巣箱 — レシピで作れるのは箱だけ**
松と蜜蝋と縄で作れるのは**空の箱**です。蜂は作れません。
「蜂ごとの巣箱」を品として出す以上、**レシピの外から蜂が入る**ことになりますが、
その入り方を書く場所がありませんでした。

## 5. 軸そのものへの疑問

**(1) 「向く土地」の `温暖な土地` が、事実上の「その他」になっている**
生鮮の食料はすべてここに落ちます（A1〜A6、B12、B15）。
温める・冷やす・束ねる/容れる、のどれでもない食べものは、**「生鮮だから温暖」以外に行き場がありません。**
結果として `温暖な土地` は「ハルヴェラに向く品」ではなく「分類できなかった食料」の置き場になっています。

**(2) `実りの土地` の「手段だけ／結果は含まない」という線が、保存食を宙に浮かせる**
保存食は「多すぎる収穫を捌く」ためのものなのに、定義でわざわざ除外されています（A8・A9・B15）。
除外された品の受け皿が用意されていないので、`どこでも` か `温暖な土地` に押し込むしかありません。
**除外の線は引かれているのに、除外先が指定されていない**のが噛み合っていないと感じました。

**(3) `どこでも` が二つの別の意味を兼ねている**
「土地を選ばない」（＝どの島でも同じくらい役に立つ）と、
「用途が一つに定まらない」（＝そもそも役立ち方が決まっていない）は別の話です。
前者は B6 真水、後者は A7 わかめ・B8 端切れ。**さらに私は三つめの使い方をしました**——
B9 帆・B10 繕い・B11 だしのように、**軸の問いが品に届かなかったときの捨て場**として使っています。
`どこでも` が多い、という数え方をすると、この三種類が混ざったまま数えられます。

**(4) 「主種類」に、素材でも道具でもない実体を置く値が無い**
生きもの（B1 羊、B4 猫、B3 苗木、B2 蜂）と、品ですらないもの（B10 繕いの手間）が入りません。
四つの値はすべて「客がそれをどう消費するか」で切られていますが、
**消費されないもの・自分で増えるもの・働くもの**が世界に自然に存在します。

**(5) 「贅沢さ」は品の性質ではなく客の事情を聞いている**
定義がすべて「客がどう買うか」で書かれているので、
**同じ品を違う理由で買う客がいると答えが定まりません**（B4 猫、B1 羊）。
また下限が浅く、水や火のような「値段を見るまでもなく要るもの」（B5・B6）が `日用` に潰れます。

**(6) 「産地」が、加工品の島の色をすべて消す**
「加工したものは旬を持たないのですべて `なし`」なので、**加工品は120品中すべて産地なしのはずです。**
新しく作った加工品15本も全部 `なし` になりました。
四島を巡る店舟という設定なのに、**加工した瞬間にどの島の品でもなくなります。**
これは規則としては明快ですが、島ごとの性格を品に残す手段が素材にしか無い、ということでもあります。

**(7) 「産地」の `なし` が、少なくとも三つの意味を持たされている**
「旬が無い」「海のもの」「加工品」、そして B13 では「世界の外から来た」。
同じ値で四つの事情を表しているので、`なし` の品を後から見分けられません。

**(8) tier が「レシピから自動で決まる」ため、レシピの無い加工品を置けない**
B13 のような漂着物、あるいは客からの持ち込み品（B14 の中古、B10 の預かり品）に tier が付きません。

**(9) 軸に「傷み具合／鮮度」と「使っても減るか」が無い**
B14 の中古、B7 の樽、R8 のやすりは、この二つが無いせいで表の上で新品や消耗品と区別できません。
生鮮（A1〜A6）も、時間で悪くなることを表せません。

**(10) 升目が「形」だけで、大きさの外れ値と動くものを表せない**
B9 帆は大きすぎ、B8 端切れは小さすぎ、B10 繕いの手間は 0 升、B1 羊と B4 猫は形が変わり動きます。
升目は静止した箱を前提にしています。
