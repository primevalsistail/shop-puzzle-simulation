## 2. 自分が置いた「破れた」の線

合格ラインが書かれていないので、ここで決める。**3本引く。2本は「破れ」の線、1本は「破れでない」の線。**

### 線A（破れ）— Phase 0 が書いた INV-2b の手続きに、そのまま掛かるか

Phase 0 の判定文をそのまま使う:

> 「この軸は〈問い〉に答える。値 X は〈　　〉である」に全値を入れ、同じ形の文になるか。
> **1つでも形が変わる値があれば、その軸は2本に分裂している**

**形が変わる値が1つでもあれば破れ。**これは私の裁量ではなく、Phase 0 が自分で書いた手続きである。

### 線B（破れ）— 「品を見れば決まる」が実データで外れているか

Phase 2 §4-E は、改訂の根拠として **「改訂後は4値とも品を見れば決まる」** を挙げ、
揺れ#4 の決着でも **「品を手に取れば決まる基準なので INV-2b を保てる」** と書いている。
つまり **「品を見れば決まる」は、この軸が INV-2b を満たしているという主張の担保そのもの**である。

よって、こう置く:

> **同じ定義文を独立に読んだ二者が、同じ性格をもつ品の集合を別の値に振り分けたなら、
> その軸は「品を見れば決まる」を満たしていない。担保が外れた以上、INV-2b は主張されていないのと同じ。**

**「起こした側が迷った」だけでは足りない。**迷いは主観なので、**既存120品の実データに同じ割れ方が
出ていること**を条件に加える。出ていなければ、それは起こした側の読みの問題として却下する。

### (1) `温暖な土地` が事実上の「その他」になっている

**判定: 線B に掛かる。破れ。ただし申告の中身は不正確で、破れの正体は別のところにある。**

**申告は事実に反する。**「生鮮の食料はすべてここに落ちる」と書かれているが、既存120品で確かめると:

| tier1 の 食料・飲みもの 37品 | 向く土地 |
|---|---|
| たけのこ・アスパラガス・さやえんどう・そら豆・いちご・菜の花・よもぎ・羊の乳・いちじく・ぶどう・鮭・かに・まぐろ・いわし・いか | `温暖な土地` **15品** |
| 茶の葉・とうもろこし・なす・ひまわりの種・蜂蜜・栗・柿・りんご・さつまいも・米・蕎麦の実・くるみ・オリーブ・えのきたけ・昆布・レモン | **`どこでも` 16品** |
| とうがらし・トナカイの肉 / すいか・ミント・氷 / 塩 | 寒2 / 暑3 / 実1 |

**生鮮は「すべて温暖に落ちて」いない。半々に割れている。**
そして **たけのこ・アスパラガス・いちじく**（温暖側）と **なす・さつまいも・えのきたけ**（どこでも側）は、
どちらも生鮮の農産物で、レシピの材料かどうかでも、持ち歩く形かどうかでも分けられない。
**定義文から出ない線で割れている。**

さらに Phase 4 のセッションは、生鮮8品（ふきのとう・桃・松茸・大根・梅・鱈・かぼちゃ・海鳥の卵）を
**全部 `温暖な土地`** に置いた。**同じ定義文を読んだ二者が、同じ性格の集合を別々に振り分けた。**
線B の条件をそのまま満たす。

**破れの正体**は「その他化」ではなく、**`温暖な土地` の判定基準に `生鮮` という語が入っていること**である。
そして `生鮮` は、**Phase 2 §3-A がまさに「定義文が書けない」として値から落とした語**である:

> 時間劣化の機構が無い以上、`生鮮` の**定義文が書けない**（「生鮮とは傷みやすいものである」→ 傷む機構が無い）。
> 定義できない値を置くのは PR-1 に触れる。**復活させる条件: Phase 1 に戻って問いを立て直す**

**定義文が書けないと認めた語を、別の軸の判定基準として使っている。**
これが `温暖な土地` の境界が決まらない直接の原因であり、**§1 で「戻る」と判定した唯一の根拠**である。

### (2) `実りの土地` の「手段だけ／結果は含まない」に除外先が無い

**判定: INV-2 違反ではない。(1) に吸収される別の問題（受け皿の不在）。**

除外の線そのものは一意である。「蓄えるは手段に限る」は品を見れば判定でき、値の形も変わらない

問題は**除外された品の行き先**だが、その行き先は `温暖な土地` と `どこでも` であり、

なお申告の「梅干しと干し柿がほぼ同性格なのに、干した形が小さいかだけで違う値になった」は、
**(1) の実例として正しい**。証拠力は (1) に合算する。

### (3) `どこでも` を三通りに使ってしまった

**判定: 線A に掛かる。INV-2b 違反、確定。**

現行の定義文（`axes.ts` / Phase 2 §4-E）を Phase 0 の手続きに掛ける:

| 軸の問い: **どんな土地で役に立つ品か** | 値の文 | 形 |
|---|---|---|
| `寒い土地` | 体を温めるのに役立つ品である | 土地への答え |
| `暑い土地` | 体を冷やすのに役立つ品である | 土地への答え |
| `温暖な土地` | 外で過ごす暮らしに役立つ品である | 土地への答え |
| `実りの土地` | 多すぎる収穫を捌くのに役立つ品である | 土地への答え |
| `どこでも` | 土地を選ばない品である **／ 用途が一つに定まらない品である** | **後半だけ「用途への答え」** |

**後半は「どんな土地で役に立つか」への答えになっていない。**「用途が定まっているか」という別の問いへの答えである。
Phase 0 の判定文どおり、**この軸は2本に分裂している。**

しかもこれは事故ではない。**Phase 2 §4-E の揺れ#5（2026-09-07）が、承知のうえで明文で認めている**:

> `どこでも` に「選ばない」と「**選べない**」の2種があることを、取りこぼしではなく**定義として認める**

**「認める」と書いても INV-2b は満たされない。**Phase 0 は「1つでも形が変わる値があれば分裂している」と書いており、
例外条項を持たない。同じ揺れ表の #3 では **INV-2a を根拠に生魚を動かしている**ので、
この手続きを知らなかったわけでもない。

**実データでも両方の意味に人口がいる**（片方が空なら「使っていない」で済むが、そうではない）:

- 「用途が定まらない素材」側: 竹・トナカイの革・木綿の帆布・オリーブ・蜜蝋・流木・軽石・松・白樺

**三つ目の使い方（軸の問いが届かない品の捨て場）も、Phase 4 が作った問題ではない。**
既存120品には「加工品でありかつ他のレシピの材料でもある」中間物が **22品**あり
（蕎麦粉・オリーブ油・バター・塩鮭・干し肉・いちごのジャム・ぶどうの酒・木綿糸・角留めの革帯・やすり ほか）、
その多くが `どこでも` に入っている。B11 昆布のだしは**この22品と同型**であって、新種ではない。
起こした側の「これは私が新しく作った問題ではなさそう」という自己申告は**正しい**。

### (4) `主種類` に、素材でも道具でもない実体を置く値が無い

**判定: 問題でない。**

挙げられたのは羊・猫・苗木・蜂・繕いの手間。**5つとも、この世界に商品として存在しない**（→ 争点2）。

### (5) `贅沢さ` が品の性質ではなく客の事情を聞いている

**判定: INV-2 違反ではない。挙げられた実例は世界に存在しないか、世界事実に基づかない。**

線A に掛からない。3値は同じ形に揃っている:

- `日用` = 無ければ困るので値段を見て買う品である
- `上等` = 無くても困らないが暮らしを良くする品である
- `贅沢` = 要るからではなく欲しいから買う品である

**すべて「客がこう買う品である」の形。**INV-2b を満たす。

「同じ品を違う理由で買う客がいると答えが定まらない」という指摘は、**客に事情があれば成り立つ**。
しかし characters.md は明記している:

> **個人ではなく類型**として扱う ／ 個人を作らない ／ **類型は取引行動で分ける（感情や見立てで分けない）**

**この世界の客は事情を持たない。**4類型はすべて「買い方」で切られている。
そして実例に挙がった猫（B4）と羊（B1）は、**どちらも世界に存在しない品**である。
**存在しない品でしか揺れない軸は、揺れているとは判定しない。**

**「下限が浅く、水と火が `日用` に潰れる」は世界事実に基づかない。**

- 「真水はどの島でも汲めるので値段を見て買うものではない」— **world.md にも island-goods.md にも無い。**
  そもそも**「水」という品が既存120品に存在しない。**

  既存レシピは火も水も材料に取っていない。

**どちらも起こした側が持ち込んだ設定である。**証拠として採らない。

### (7) `産地` の `なし` が四つの意味を背負っている

**判定: INV-2 違反ではない。ただし、この申告は文書側の実在する誤りを掘り当てている。**

> **旬が無い（通年で採れる）ものは、海 ＝ 産地 `なし`。**

| 軽石 | 海面を漂って流れてくる |
| かもめの羽根 | かもめは**季節を問わず**船について回る |

**7品すべてが「旬が無い」で説明されている。**そして決定的なのは逆側である——

| 海のものだが**島を持つ**品 | 産地 | 理由 |

**ではなぜ起こした側は「四つの意味」と読んだのか。文書が嘘をついているからである:**

### (9) 軸に「傷み具合／鮮度」と「使っても減るか」が無い

**判定: 2件を分けて扱う。片方は §1 の結論に直結し、もう片方は新しい論点だが破れではない。**

**(9a) 鮮度 — Phase 2 は「落とした」つもりだが、落ちていない。**

Phase 2 §3-A は鮮度を意図的に落とし、復活条件を「Phase 1 に戻る」と明記した。
**それ自体は正しい判断である。**しかし (1) で見たとおり、**落としたはずの `生鮮` が
`温暖な土地` の判定基準として生き残っている。**

> `温暖な土地` = 外で過ごす時間の長い暮らしに役立つもの（軽装・持ち歩き・**生鮮**）

**「定義文が書けない」と認めた語に、別の軸の判定が寄りかかっている。**
だから `温暖な土地` の境界が実データで決まらない。**これが §1 の「戻る」の根拠である。**

**(9b) 消耗 — 却下の根拠が、今回出た事象に届いていない。**

### 5-2. 「INV 6本中5本が通った」は、通過本数を水増ししている

**INV-4 と INV-5 は、今回まったくストレスされていない。**

  **型の静的性質。**品を何個足しても壊れようがない。実際 `rules.ts` の層2は既定で空配列である。
- **INV-5** の判定は「新品追加の diff が定義1件だけ」——**追加のしかたの性質。**

### 5-3. INV-1 の判定文が、実装より広い

いまの書き方だと、次にこれを検査する人が「違反あり」と判定してしまう。

## 6. 戻り先の指定

**戻すのは `向く土地` 1本。Phase 1 の「問い」の段。他の4軸は戻さない。**

### 手順

**① Phase 1 で、取り下げた問い「傷むか（鮮度・時間劣化）」の去就を先に決める。**
これを決めないと `温暖な土地` の定義を書き直せない。**Phase 2 の文言だけを直しても閉じない。**

**② 決めた結果で、`温暖な土地` の定義から `生鮮` を外すか、鮮度を軸として立てるかが決まる。**

どちらを選んでも既存品が動く。**動く量を先に出しておく（既存120品で実測）:**

| 選択 | `温暖な土地` | `どこでも` | 需要4行の比 | 代償 |
|---|---|---|---|---|
| （現状） | 26 | 51 = 42.5% | 2.89倍 | **境界が決まらない** |
| **A: `生鮮` を定義から外す**（取り下げを維持） | **11**（持ち歩き・軽装のみ） | **66 = 55.0%** | 2.00倍 | D1 の1行が痩せ、`どこでも` が過半を超える |

| **C: 鮮度を軸として立てる**（取り下げを撤回） | — | — | — | 軸が6本になる。B14 中古が同時に解ける。Phase 2 §3-A の復活条件そのもの |

> Phase 2 §3-A と正面から矛盾する。**A が §3-A と整合する唯一の案**だが、`どこでも` 55% を受け入れることになる。
