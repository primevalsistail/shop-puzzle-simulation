## 1. どんな世界か

**気候の違う四つの島を、決まった順に10日ごとに巡る店舟。**船倉が升目になっていて、そこが売り場。
島で素材を仕入れ、船倉で加工し、売る。**加工している間は店が閉まる。**

| 島 | 気候 | 相当する季節 |
|---|---|---|
| ハルヴェラ | 温暖 | 春 |
| リナツィア | 陽が強く暑い | 夏 |
| ノアキータ | 実りが絶えない | 秋 |
| ミフユリア | 雪が絶えない | 冬 |

**四島とそれを結ぶ穏やかな海。**それ以外の土地は無い。**季節は移らない**（各島の気候が一年じゅう続く）。
**金属は無い。粘土も無い。**

## 2. 品は5つの軸で表す

| # | 軸 | 問い | 値 |
|---|---|---|---|
| 1 | 主種類 | これは何であるか | `食料` `飲みもの` `衣類` `道具` |
| 2 | tier | どれだけ加工されているか | レシピから**自動で決まる**（書かない） |
| 3 | 産地 | どの島で採れるか | 四島 ＋ `なし` |
| 4 | 贅沢さ | 客がどれだけ奮発して買うか | `日用` < `上等` < `贅沢` |
| 5 | 向く土地 | どんな土地で役に立つ品か | `寒い土地` `暑い土地` `温暖な土地` `実りの土地` `どこでも` |

### 産地の決め方

**その品が一般的にどの季節のイメージかだけで決まる。**生育条件は持ち込まない。
旬が春ならハルヴェラ、夏ならリナツィア、秋ならノアキータ、冬ならミフユリア。

- **旬を持たない（通年の）ものは `なし`**
- **海のものは `なし`**
- **加工したものは旬を持たないので、すべて `なし`**
- **気候は「何が育つか」しか決めない。**だから**かたちになったもの**（着るもの・使うもの）は
  どの島も産さず、必ず加工品として現れる

### 向く土地の定義

| 値 | 定義 |
|---|---|
| `寒い土地` | **体を温める**のに役立つもの（熱を守る ／ 熱を与える） |
| `暑い土地` | **体を冷やす**のに役立つもの（熱を逃がす ／ 冷たさを与える） |
| `温暖な土地` | **外で過ごす時間の長い暮らし**に役立つもの（軽装・持ち歩き・生鮮）。「持ち歩き」は**持ち歩くために作られた形をしているか**で見る |
| `実りの土地` | **多すぎる収穫を捌く**のに役立つもの（束ねる・容れる・蓄える）。「蓄える」は**手段**（塩・容れ物）に限り、**蓄えた結果**（保存食そのもの）は含まない |
| `どこでも` | 土地を選ばないもの。**用途が一つに定まらないもの**（竹・革などの素材）もここ |

**必ず1つだけ選ぶ。**

### 贅沢さの定義

| 値 | 定義 |
|---|---|
| `日用` | 無ければ困るので、値段を見て買うもの |
| `上等` | 無くても困らないが、暮らしを良くするもの |
| `贅沢` | 要るから買うのではなく、欲しいから買うもの |

## 4. 出してほしいもの

### 新しい品 30個 — **半分ずつ、性格を分けてほしい**

**(A) 素直な追加 15個**
　いまの世界観から自然に出てくる品。上の120品と重複しないもの。

**(B) この5軸に置きにくい品 15個** ← **こちらが本題**
　**この世界にあってもおかしくないのに、上の5軸のどこに置けばいいか困るもの**を狙って出してほしい。
　「ありえないもの」を出しても意味がない。**ありえるのに、収まらないもの**を探してほしい。

> 手がかり（これに縛られなくてよい）: 生きているもの／何度も使うもの／人の手が要るもの／
> 一つの用途に決まらないもの／季節が二つにまたがるもの／島の産物とも海のものとも言えないもの／
> 大きすぎるもの・小さすぎるもの／売り物なのか道具なのか曖昧なもの

### 新しいレシピ 10本

新しい品のうち加工品にあたるものへ。既存の素材を材料に使ってよい。
各レシピに **材料と個数／一度に何個できるか／かかる分数** を付けてほしい。

### 各品に付けてほしいもの

- 名前
- **主種類・産地・贅沢さ・向く土地**（4つとも必ず埋める）
- 船倉で占める**升目の形**（例: 1×3、2×2、L字）
- 加工しない品なら**基準の値段**の見当（既存の目安: 米16／いちご84／かに144／トナカイの革48）
- 一行の説明

## 5. ★ いちばん大事なお願い

**軸に当てはめるとき、少しでも迷ったら、その迷いを全部書き出してほしい。**
