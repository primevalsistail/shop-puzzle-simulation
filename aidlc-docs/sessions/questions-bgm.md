## Question 4
**速さを 3倍・10倍にしたとき、朝と夜の曲をどうしますか。**

| 速さ | 朝 | 昼 | 夜 | 1日 |
|---|---|---|---|---|
| **等倍** | **24秒** | **60秒** | **24秒** | 108秒 |
| **3倍** | **8秒** | 20秒 | **8秒** | 36秒 |
| **10倍** | **2.4秒** | 6秒 | **2.4秒** | 10.8秒 |

A) 朝夜は等倍のときだけ ／ B) 速さに関わらず替える ／ C) 朝夜をやめて昼4曲だけ

[Answer]:ユーザペルソナに検討させて

→ **4人に別々のセッションで検討させた**（[原文](../inception/design-log/bgm-persona-review.md)）。**A が3人、B は4人とも却下。**
→ **採用: A。**⚠ **ただし問いの立て方が間違っていた** ——
**4人とも1日の中で速さを変える**と答えたので、**「3倍で遊んでいる日」という単位が存在しない。**
→ **速さを見るのは「朝・昼・夜が始まる瞬間」だけ。区分の途中で速さを変えても曲は替えない。**
**この条件が無いと A は選ばない、と3人が別々に書いた。**
→ ⚠ **反対が1人**（やりこみ層・「A だと朝夜の2曲を誰も聴かない場所に置くことになる」）。
**[bgm.md](../inception/worldbuilding/bgm.md) §3 に残した。**

## ⚠ ペルソナから出て、曲選びを変えたこと

| | 言われたこと | どうしたか |
|---|---|---|
| **昼の4曲の長さ** | **30秒ループだと、等倍では同じ30秒を18分ぶっ通し。****曲数より長さが効く** | **下限を 60秒 → 2分に上げた** |
| **朝と夜の長さ** | **等倍でも24秒しか鳴らない。**2分の曲の頭24秒ではない | **「24秒のループとして選ぶ。頭8秒で朝だと分かること」**に変えた |
| **昼の4曲の関係** | **同じシリーズから取る**だけだと、**替わったことに気づかない** | **「同じ手つきで、テンポと楽器ははっきり別物」**を足した |
| **音を切る日** | ⚠ **4人全員が「何日目に切るか」を答えた**（50〜80日目） | **設定の「音楽を鳴らす」は必ず要る**と確認 |

⚠ **拾わなかった案が2つある**（8曲の決定を動かさないため）。**後で飽きが出たら、ここが最初に戻る場所。**

- **朝夜を曲ではなく「昼の曲に乗る数秒の合図」にする**（カジュアル層）
- **2周目は同じ島でも別アレンジ**（カジュアル層。**4島40日で全曲を聞き終わり、残り160日は繰り返し**）

### こちらで決めたこと（違えば言ってください）

| | 決めたこと | なぜ |
|---|---|---|
| **タイトルと、はじまりの場面** | **同じ曲で通す**（専用曲を作らない） | **タイトルから地続き**に聞こえる |
| **睡眠（24:00〜6:00）** | ⚠ **曲を用意しない** | **時計がそこに留まらない。**24:00 に達した瞬間 6:00 へ飛ぶ |
| **できごとの窓** | ⚠ **曲を止めない** | 窓は選択肢があるときだけ出て、すぐ閉じる |
| **クリア後（自由航行）** | **島の曲のまま** | 居る場所は島なので、専用曲が要らない |
| **昼の4曲** | **同じ配布元の同じシリーズから取る** | バラバラだと**島が変わるたびに別のゲーム**になる |
| **歌もの** | ⚠ **選ばない** | この世界の言葉が決まっていない。歌詞が入ると**世界の外の言葉**が混ざる |
| **音を止める口** | **設定（⚙️）に「音楽を鳴らす」を1行足す** | **設定はもう有り**（#113）、**入・切のスイッチが並ぶ形**なので1行増やすだけ |
| **音量つまみ** | ⚠ **作らない** | いまの設定に**つまみという部品が無い** |
| **曲の速さ** | ⚠ **10倍速でも曲は速くしない** | 速さは「眺めるか流すか」の選択で、**世界の時間が速くなったわけではない** |
| **置き場** | 原本 `audio/`、`public/audio/` は写し | **絵と同じ形**（原本 `art/button-icons/` → `public/art/icon/`）。⚠ **逆をしない** |
| **形式** | **ogg ＋ m4a の2本**、1曲 1〜2MB 目安 | ogg だけだと Safari で鳴らない |

### ⚠ 知っておいてほしい制約が1つ

**ブラウザは、プレイヤーが1回押すまで音を鳴らしません。**
このゲームは**タイトル画面のボタンが最初の一押し**なので、
**タイトルを開いた直後は無音で、押した瞬間から鳴り始めます。**
⚠ **不具合ではありません。**避けられないので、**タイトル曲は「押してから鳴る」前提で選びます。**
