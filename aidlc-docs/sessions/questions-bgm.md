## Question 7（答え済み）
**島ごとの色を「昼」に置いたままにしますか。** → ⚠ **A（このまま）で決着。**

⚠ **Question 4 と 6 は、こちらの前提が間違っていたので取り下げました**（下の「取り下げ」）。
**その直しから出た最後の引っかかりが、この Question 7 でした。**

### 分かったこと

**時計は節目で必ず自分から止まり**（6:00 ／ 10:00 ／ 20:00）、**押し直すまで待ちます。**
**いちばん長く鳴るのは「6:00 で止まっている時間」と「20:00 で止まっている時間」**（PO 指摘）——
**棚を組み、仕入れ、夜の手仕事を仕込む時間で、長さはプレイヤー次第。**

| 曲 | 鳴る長さ |
|---|---|
| **朝**（共通1曲） | ⚠ **いちばん長い**（止まっている時間 ＋ 24秒） |
| **夜**（共通1曲） | ⚠ **2番目**（止まっている時間 ＋ 24秒） |
| **昼**（⚠ **島ごとに4曲**） | ⚠ **いちばん短い**（10:00 の停止は押し直すだけで過ぎる。走るのは 60秒・10倍なら6秒） |

→ ⚠ **いちばん数を作る4曲が、いちばん短く鳴る場所に置かれています。**
**「いまどの島に居るかが耳で分かる」という狙いが、いちばん薄いところに乗っている。**

### 選べるもの

A) **このまま。昼が島ごと**（**推奨**）
   **島の色は「店が開いている時間」に乗るのが素直。**
   ⚠ **短いぶん、4曲は頭の数秒で聞き分けられること**が条件になります。
   ⚠ **いちばん単純。**決めた構成を動かしません。

B) **島ごとを「朝」に移す**（朝4曲・昼1曲を共通に）
   ⚠ **いちばん長く聞く場所に島の色が乗ります。**
   ⚠ **ただし「店が開いた時間の曲」が全島同じになります。**

C) **朝も昼も島ごと**（朝4曲＋昼4曲 ＝ **11曲**）
   ⚠ **曲が3曲増えます。**探す手間もそのぶん増えます。

X) その他

[Answer]:むしろ待つしかないからBGMで変化を持たせている部分はあります

→ **採用: A。****理由がこちらの推奨より強い。**
**朝夜は手を動かしている時間、昼は待つしかない時間。**
⚠ **「短いから聞かれない」という見方が間違っていた。長さと、聞かれ方は別。**
→ **曲の条件を役割で分けた**（[bgm.md](../inception/worldbuilding/bgm.md) §1・§2）——
**朝夜は「うしろで鳴る・繰り返しに耐える・2分以上」、昼は「前に出る・60〜90秒で1日にほぼ一周」。**
⚠ **昼を2分以上にするのは取り下げた** —— **昼は毎日その頭から鳴る**ので、
**長い曲を選ぶと後半を誰も聞かない**（朝夜で踏んだのと同じ形）。

## 取り下げた問い（前提が間違っていました）

### Question 4（速さで朝夜を出し分けるか）—— ⚠ **問いとして成り立っていませんでした**

**「3倍だと8秒ごと、10倍だと2.4秒ごとに曲が替わる」と書きましたが、そうなりません。**
⚠ **時計は節目で必ず自分から止まります**（コード上の注記も「**節目で必ず止める**」）。
**区分の境を走り抜けることが無いので、「数秒ごとに曲が替わる」ことは起きません。**

→ **答えは「速さを見ない。時間帯だけで決まる」。**
→ ⚠ **ペルソナ4人にも、この間違った前提のまま渡してしまいました。**
**[bgm-persona-review.md](../inception/design-log/bgm-persona-review.md) の冒頭に書き戻してあります。**
**速さと関係ない指摘（曲の長さ・音を切る日）はそのまま効きます。**

### Question 6（時計が止まっているときの曲）—— ⚠ **PO 回答で決着**

> 「6時～10時までは朝の曲、10時から20時までは昼の曲、20時から24時は夜の曲ですが、
> **一番長いのは「6時で止まっている時間」と「20時で止まっている時間」**のはずです。
> **常に時計が動いているわけがありません。**」

→ **時間帯だけで決まる。止まっているかどうかは見ない。**
→ ⚠ **朝と夜は「24秒の断片」ではなく、いちばん長く聞く2曲。**
**素材の条件を「2分以上・何分ループしても耐えること」に直しました。**

### こちらで決めたこと（違えば言ってください）

| | 決めたこと | なぜ |
|---|---|---|
| **タイトルと、はじまりの場面** | **同じ曲で通す**（専用曲を作らない） | **タイトルから地続き**に聞こえる |
| **睡眠（24:00〜6:00）** | ⚠ **曲を用意しない** | **時計がそこに留まらない。**24:00 に達した瞬間 6:00 へ飛ぶ |
| **できごとの窓** | ⚠ **曲を止めない** | 窓は選択肢があるときだけ出て、すぐ閉じる |
| **クリア後（自由航行）** | **島の曲のまま** | 居る場所は島なので、専用曲が要らない |
| **昼の4曲** | **同じ配布元の同じシリーズから取る** | バラバラだと**島が変わるたびに別のゲーム**になる |
| **歌もの** | ⚠ **選ばない** | この世界の言葉が決まっていない。歌詞が入ると**世界の外の言葉**が混ざる |
| **音を止める口** | **設定（⚙️）に「音楽を鳴らす」を1行足す** | **設定はもう有り**（#113）、**入・切のスイッチが並ぶ形**なので1行増やすだけ |
| **音量つまみ** | ⚠ **作らない** | いまの設定に**つまみという部品が無い** |
| **曲の速さ** | ⚠ **10倍速でも曲は速くしない** | 速さは「眺めるか流すか」の選択で、**世界の時間が速くなったわけではない** |
| **置き場** | 原本 `audio/`、`public/audio/` は写し | **絵と同じ形**（原本 `art/button-icons/` → `public/art/icon/`）。⚠ **逆をしない** |
| **形式** | **ogg ＋ m4a の2本**、1曲 1〜2MB 目安 | ogg だけだと Safari で鳴らない |

### ⚠ 知っておいてほしい制約が1つ

**ブラウザは、プレイヤーが1回押すまで音を鳴らしません。**
このゲームは**タイトル画面のボタンが最初の一押し**なので、
**タイトルを開いた直後は無音で、押した瞬間から鳴り始めます。**
⚠ **不具合ではありません。**避けられないので、**タイトル曲は「押してから鳴る」前提で選びます。**
