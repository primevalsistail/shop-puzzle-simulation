## Question 1
**加工の曲線をどう直しますか。**（→ #112）

**いまどうなっているか**（実測）
**改装の `手際` は 6段**（`SKILL_VALUES = [10,14,18,22,26,30]`）で、**1段 = 2^(4/5) = 1.741倍**速くなります。
⚠ **あなたの指摘のとおりです。**

**そして「最初期から90分」も実物です** —— **Day 1 に開く5本のうち、バターが 180分/2個 ＝ 1個あたり 90分**、
**チーズは 480分/2個 ＝ 240分/個**。⚠ **営業時間は1日600分**なので、**バター1個で1日の15%**を使います。

**あなたが出した方針**（issue 本文）
> **基本は「多く仕入れて、多く加工する」／1つ作るのに最初期から90分みたいなイカれた数字にしない**
> **ただし最初に tier3, 4 に触るのは時間効率悪いなぁ…とは思わせたい**

**選べるもの**

A) **所要時間そのものを、tier1〜2 だけ大きく下げる**（**推奨**）
   **序盤の品を「まとめて作る」ものにします。**⚠ **tier3 以上は下げない**ので、
   **「最初に深い品へ手を出すと効率が悪い」は残ります。**
   ⚠ **推奨の理由**: **方針の2つを、1つの手当てで同時に満たせます。**

B) **`手際` の倍率を緩くする**（1.741倍 → 1.2倍など）
   ⚠ **1段ぶんの手応えは減りますが、最初期の 90分は 90分のままです。**
   **「イカれた数字」のほうは直りません。**

C) **A と B の両方**
   ⚠ **2つの軸を同時に動かすので、どちらが効いたか分からなくなります。**

X) その他（[Answer]: の後に書いてください）

[Answer]: X。**tier ベースにする。**「現状は低難易度なのに、初期から解放されるレシピがやたら時間がかかる。タイパが明らかに悪い」を打破したい。**目安**: tier2 は初期 1回10分・MAX 1回2分、tier7 は MAX 1回10分。⚠ **レシピごとの差は残す。**

## Question 2
**「預かり荷」を入れますか。**（→ #92）

**いまどうなっているか**
⚠ **預かり荷という概念はコードに1つもありません。**
**船倉は最初から丸ごと売り場**（`6×5`）で、升は「空き」か「品が置いてある」かの2つだけです。

⚠ **#7 の本文は「エンディングで預かり荷がすべて降りる」と書いていましたが、
降りるものが無いので、実際には何も起きませんでした。**

**選べるもの**

A) **入れない**（**推奨**）
   ⚠ **推奨の理由**: **入れると升の状態が1つ増え、`FloorGrid` ／ `PlacementManager` ／ 描画 ／
   セーブの4つに手が入ります。**そして**序盤の盤面が狭くなるので、配置の釣り合いを全部測り直すことになります。**
   **「売り場が広がる」圧は、改装の `棚`（6×5 → 13×10）が既に担っています。**

B) **入れる**
   **序盤ほど狭い、という圧が作れます。**
   ⚠ **どれだけ占めるか・どう減るかも決めることになります。**
   ⚠ **数値調整はこれが入ってからになります。**

X) その他（[Answer]: の後に書いてください）

[Answer]: A（入れない）。「要らない」

## Question 3
**エンディングのあと、資金が尽きたら GAME OVER を出しますか。**（→ #121）

**いまどうなっているか**
⚠ **出ません。** 商船を買うと旗が立ち、**以降 GAME OVER の判定が止まります。**
⚠ **商船の値段は 1,000万レン ＝ 目標額と同じ**なので、**ぴったり持って買うと所持金が 0 になります。**
**そこで棚に品が無ければ完全に詰んでいますが、画面は何も言いません。**

**選べるもの**

A) **出さない**（いまのまま）（**推奨**）
   **エンディングを見たあとは、終わらせない。**
   ⚠ **推奨の理由**: **「商船を買う」がこの game の終わりだと決めたので、その後ろに2つ目の終わりを作らない。**
   ⚠ **ただし Question 3-b が要ります**（下）。

B) **出す**
   **「詰んだのに画面が何も言わない」が消えます。**
   ⚠ **買った直後は所持金が 0 に近いので、買った直後だけ見逃す仕掛けが要ります。**

X) その他（[Answer]: の後に書いてください）

[Answer]: X。**GAME OVER にならない仕組みを考えるほうがいい。**⚠ **救済策として「ただで買える激マズ商品」を用意する案**（買0・売5の「砂」のようなもの。**あくまで救済なので『店に並べたくない』レベル**）。

### Question 3-b
**商船を買ったあと、所持金 0 から立て直せるようにしますか。**

⚠ **A を選んでも B を選んでも、これは別に要ります。**
**買った時点で棚に品が無ければ、売るものも仕入れる金もありません。**

A) **商船の値段を目標額より下げる**（**推奨**。例: 900万）
   ⚠ **いちばん小さい。**目標のバーは 1,000万のままで、**買っても手元に残ります。**
B) **買ったあとに一定額を戻す**
   ⚠ **「買ったのに金が増える」ので、理由が要ります。**
C) **何もしない**（詰んだら詰んだまま）

X) その他（[Answer]: の後に書いてください）

[Answer]: ⚠ **数字はこちらで決めてよい**（PO「数字は知らんよ。そっちで調整してよ」）。上の救済案がそのまま答え。
