# ロード画面（#123）への質問

**いまの姿**: タイトルの「つづきから」を押すと、**1日目のゲーム画面が先に組み上がり**、
その上にロードの枠（スロット3つ）が出る。PO 指摘のとおり、選ぶ前にゲーム画面が見えている。

**直し方の案（推奨）**: **タイトル → ロードの画面 → 選んだ後にゲーム画面**。
ロードの画面はゲーム画面を作らずに枠3つだけを出す専用の面にする。
枠を押した時点でゲーム画面を作り、読み込んだ状態で最初から表示する（1日目の画面は一度も出ない）。

---

## 答えてほしいこと

### Q1. ロードの画面の見た目は、いまの枠3つの面のままでよいか

- **案A（推奨）**: いまの枠3つの面を、背景だけ差し替えてそのまま出す。
  **理由**: 見た目が今と同じで、ゲーム内の ⚙️ から開くロードとも揃う。作るものが増えない
- 案B: タイトル画面の絵（題名・主人公）を残した上に枠3つを重ねる
- 案C: ロード画面用の絵や文言を新しく作る（絵の生成が要る）

### Q2. 枠を押した後の確認（「読み込む／やめる」）は要るか

タイトルから来た場合は**消えるものが無い**（まだ何も遊んでいない）。

- **案A（推奨）**: タイトルから来たときは確認を出さず、押したらすぐ始める
- 案B: 今までどおり確認を挟む（ゲーム内のロードと同じ手数にする）

### Q3. 「キャンセル」を押したらどこへ行くか

- **案A（推奨）**: タイトル画面へ戻る
- 案B: そのままロードの画面に留まる（戻る口が無くなるので、案Aを推す）

### Q4. ゲーム内（⚙️ → ロード）はいまのままでよいか

- **案A（推奨）**: そのまま。遊んでいる画面の上にダイアログで出し、確認も残す
  **理由**: そちらは**いま遊んでいる分が消える**ので、確認を外せない

## 答えなくて構いません（報告）

- 触る範囲: タイトル画面・ロードの面・ゲーム画面の入口だけ。セーブデータの形式は変えない
- ゲーム内のセーブ／ロードの動きは Q4 が案A なら変わらない
