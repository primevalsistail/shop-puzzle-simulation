## Question 3 —— 納品の報酬は何か【Q1=A / C で要る】

**何を決めるか**: #28。納品を果たしたとき、プレイヤーが受け取るもの。
**なぜ今必要か**: 報酬の種類で「200日の後半をどう持たせるか」への効き方が変わる。**額ではなく種類が構造。**

| 案 | 中身 |
|---|---|
| **A**（**推奨**） | **お金だけ。**額は仮置きし、#61 で測り直す |
| **B** | **レシピの解禁。**納品でしか開かない作り方がある |
| **C** | **売り場の升。**納品で盤面が広がる |
| **X** | Other |

[Answer]: A

### A を推す理由

**報酬の種類を増やすより、額で効かせるほうが軸が増えない**（「値を解かない、構造だけ決める」）。
⚠ **B は解禁経路が3本目になる**（いま U1 ＝ その島の産 ／ U2 ＝ 100個売る の2本）。
⚠ **C は強化費（#61 で未調整）と二重の拡張経路になる。**

### 影響

- ⚠ **A は目標到達を早める方向に効く**（金が増える）。**#28 の目的（200日の後半を持たせる）と逆を向く。**
  ただし**額は値なので #61 の測り直しで吸収できる**。構造は増えない
- **B・C は骨格が変わる。**入れると後から抜けない

## Question 4 —— 納品を断ったらどうなるか【Q1=A / C で要る】

**何を決めるか**: #28。注文の出方と、果たさなかったときの扱い。
**なぜ今必要か**: 罰が無いと「できたらやる」の飾りになり、200日の後半に効かない。

| 案 | 中身 |
|---|---|
| **A**（**推奨**） | **罰なし。**寄港ごとに1件、自動で出る。果たせなければ流れるだけ |
| **B** | **罰あり。**果たせないと次の注文が出ない（連続で受けるほど報酬が上がる、など） |
| **C** | **受けるかどうかを選ばせる。**受けたら果たす義務がある |
| **X** | Other |

### A を推す理由

## Question 5 —— 品出しの型を何で見分けるか【Q1=B / C で要る】
