## 7. 加工速度をどう見せるか

**同じ品で前後を比べた実測**（＝「いま作れる品」を固定して、その平均所要が何分になるか）:

| 段 | いま作れる品の平均 | |
|---|---|---|
| 0 → 1 | **227分 → 131分** | 1.74倍速 |
| 1 → 2 | **189分 → 108分** | 1.74倍速 |
| 2 → 3 | **129分 → 77分** | 1.68倍速 |
| 3 → 4 | **102分 → 65分** | 1.57倍速 |
| 4 → 5 | **65分 → 48分** | 1.35倍速 |

### main の考え

⚠ **`分` で出すのがいちばん伝わると思います。**
**工房の表に `時間` の列があって、そこは既に `90分` と出ています。**
**同じ単位なら、買った後にどう変わるかを実物で確かめられます。**

⚠ **倍率（`×0.66` など）は勧めません。**
**いまのコードの倍率は「所要時間の倍率」なので、小さいほど速い。**
**画面に `×0.66` と出ると、ふつうは「弱くなった」と読めます。**

⚠ **もう1つ、速さ以外の効き目があります** —— **作れる品が 74 → 106品に増えます**
（段0→1 で **74 → 92品**。序盤はこちらのほうが大きい）。
**数は速さで出し、品が増えることは説明の一言に入れる**のが収まりが良いと思います。

## 13. 「材料のうち1つで開放」を実際に数えました

**Day 1 に手に入る素材は 19品**（ハルヴェラの産 ＋ どの島でも買える産地なしの品）。

| 開け方 | 即開くレシピ | うち tier3以上 |
|---|---|---|
| **材料のどれか1つ**（ご提案） | **45 / 106本** | ⚠ **23本** |
| **材料を全部**（いまの条件） | **5 / 106本** | **0本** |

⚠ **「どれか1つ」だと、初日に tier3以上が23本開きます。**
**塩1品を持っただけで12本開きます**（塩は多くのレシピに入っているため）。
**「浅いものから順に深くしていく」という段が、初日に無くなります。**

### main の考え —— ご提案の**前半だけ**採るのが良いと思います

**ご提案は2つのことを同時に言っています。**

1. **「1レシピごとに」開く**（いまは**22系統のまとまり**で開いている）
2. **「材料のうち1つ」で開く**（いまは**全部**）

**1 は賛成です。**⚠ **朝を待つのも、まとめて開くのも、どちらも「系統＋日付の枠」のせい**なので、
**1レシピ単位にすれば、材料が揃った瞬間にそのレシピだけが開きます。**ご不満はここで解けます。

**2 は上の表のとおりで、勧めません。**
