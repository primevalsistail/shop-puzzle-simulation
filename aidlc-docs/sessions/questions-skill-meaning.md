# 「手際」は2つの機能を持っているのか —— 調べた結果

**作成**: 2026-09-14 ／ **回答者**: PO

---

## 結論を先に

**手際が2つの機能を持っているのではありません。****物差しは1本です。**

```
主人公の 手際 S  と  品の 難しさ D  の差だけで決まる
  着手できるか : D ≦ S + 8
  かかる時間   : 基準時間 × 2^((D − S) / 5)   ※ 0.25倍〜4倍で頭打ち
```

**差が大きいほど遅く、差が開きすぎると手が出ない。**
**設計の狙いは「作れない／背伸びすれば作れる／適正／量産できる」の4段階**で、
**「作れない」はこの物差しの端**です。別々の2機能を足したわけではありません。

## ⚠ ただし、ご指摘のとおり紛らわしい点があります

**「レシピの開放」という言葉が、別々の2つの仕組みに使われています。**

| | 何で決まるか | 画面でどう見えるか |
|---|---|---|
| **レシピの解禁**（`RecipeUnlocks`） | **材料を全部手にしたか ＋ 日付で増える枠** | ⚠ **工房の一覧に出てこない** |
| **着手できるか**（手際） | **手際 と 品の難しさの差** | **一覧には出るが、ボタンが `作れない`** |

⚠ **#111 で話しているのは上の行**（材料＋日付）**で、手際とは関係がありません。**
**main が前の質問票で両方を混ぜて書いたのが、分かりにくさの元でした。**

## 手際の「着手できない」側は、外せます

**外しても止まるものはほとんど変わりません**（実測）。

| 手際 | いま「難しすぎて着手不可」 | ⚠ **関門を外しても、1日に収まらないので着手できない品** |
|---|---|---|
| **10**（最初） | **32品** | **9品** |
| 14 | 14品 | 3品 |
| 18 | 6品 | 3品 |
| 22 | 2品 | 2品 |
| 30（最大） | 0品 | 0品 |

**関門を外しても、難しい品は「時間がかかりすぎて1日に収まらない」という形で止まります**
（**その日のうちに終わらない加工は着手できない**、という既にある決まり）。
**最初の時点で、本当に変わるのは 32 − 9 = 23品**で、
**その23品は「押せない」から「押せるが、まる1日近くかかる」に変わります。**
