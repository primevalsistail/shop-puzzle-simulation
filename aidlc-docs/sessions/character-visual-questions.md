## Question 1 —— 三面図をどの完成度で起こすか

**何を決めるか**: 三面図の段階で**画風**まで決めるか、形だけ決めて画風は SD の段階に回すか。
**なぜ今必要か**: ChatGPT への依頼文の書き方が変わる。**やり直しが起きる場所も変わる。**

| 案 | 中身 |
|---|---|
| **A**（**推奨**） | **形だけ確定させる。**線画＋簡易な塗り分けまで。**画風は決めない**（SD の段階で決める） |
| **B** | **画風ごと確定させる。**色も塗りも本番の絵柄で起こし、**この1枚を基準画にする** |
| **C** | **画風候補を2〜3案、同じ三面図で描き分けさせる。**見比べて選ぶ |
| **X** | Other（自由に書く） |

[Answer]: 画風の選択肢って何があるの？依頼前に決めるのはあり？

### A を推す理由

**三面図の目的は、形・比率・服の構成・色の配置を固定すること。**
ここに画風を混ぜると、**画風が気に入らなかったときに形まで作り直しになる。**

分けておけば、**形は据え置いたまま画風だけ振り直せる。**
PO の方針（「三面図を起こしてそれベースで SD を決める」）とも順序が合っている。

### 影響

- **A**: 画風の決定が SD の段階へ移る。⚠ **[#69](https://github.com/primevalsistail/shop-puzzle-simulation/issues/69)（アイコンを画像に）はその後**になる（アイコンとキャラの絵柄は揃える必要がある）
- **B**: 出戻りは減るが、**画風が外れたとき三面図ごと作り直し。**基準が無い状態で絵柄を選ぶことになる
- **C**: 選べるが、**ChatGPT に同一人物を複数画風で揃えさせる必要がある。**
  ⚠ **同一人物性が崩れると、画風ではなく人物の差を見比べることになって選定が濁る**

### main の応答（2026-09-13）—— 「画風の選択肢って何があるの？依頼前に決めるのはあり？」

**決めるのはあり。ただし言葉で決め切らないこと。**

画風の良し悪しを決めているのは次の2つで、**どちらも言葉では判定できない。**

1. ⚠ **110px に縮小して、まだ分かるか**（線の太さと色数で決まる）
2. ⚠ **同じ人物を8人×複数枚、生成で再現できるか**（#21 #20 #6 で要る）

だから **A を「画風を決めない」ではなく「候補を2つに絞り、正面1枚ずつで試してから三面図」に読み替える**のを
推奨に変える。**正面1枚なら描き直しが軽い。**三面図3面を候補ぶん作るのは無駄になる。

### 画風の候補（制約から5つを2つに絞った）

| | 画風 | 110px 耐性 | 生成の再現性 | SD 化 | 判定 |
|---|---|---|---|---|---|
| **甲** | **セル塗り**（アニメ調。線あり・平坦な塗り） | **高**（線が残る） | **高** | **自然** | **候補** |
| **乙** | **絵本風**（太い線・少ない色数・軽いテクスチャ） | **高**（線が太い） | 中 | しやすい | **候補** |
| 丙 | 淡彩・水彩風（細い線・淡い色） | ⚠ **低。輪郭が消える** | ⚠ 低（揺れが大きい） | 別物になる | 落とす |
| 丁 | フラット／ベクター（線なし・色面のみ） | 最高 | 最高 | しやすい | ⚠ **落とす。8人の描き分けが色とシルエットだけになる** |
| 戊 | ピクセルアート | — | — | — | ⚠ **落とす。**[#10](https://github.com/primevalsistail/shop-puzzle-simulation/issues/10)（解像度が荒い）と正面衝突し、**三面図→SD という段取りとも合わない**（ドットは直接打つもの） |

**甲**は既定値寄りだが、⚠ **既定値だから避けるということはしない**（`character-motive.md` で「陽気」を
既定値くさいという理由で外さず、比較で判定した先例がある）。
**乙**は世界の調子（明るく穏やか・素朴な商い）に最も近く、かつ線が太いので縮小に耐える。

**丙**は調子には一番合うが、⚠ **110×305 の枠で輪郭が消える**ので、この画面では成立しない。

## Question 2 —— 髪の基準形

**何を決めるか**: 三面図で髪をどの形に固定するか。
**なぜ今必要か**: `char.md` は「**その日の服との収まりを見ながら低くまとめたり片側へ流したりする**」と
書いている。**三面図は1つの姿に固定しないと基準にならない。**
⚠ **決めなかったほうは、後から「基準形からの派生」として足せる。**消えるわけではない。

| 案 | 中身 |
|---|---|
| **A**（**推奨**） | **低くまとめる**（うなじのあたりで一つに） |
| **B** | **片側へ流す**（肩の片側に寄せる） |
| **X** | Other |

[Answer]: 主人公だよね？Aでいいと思う。変な設定を残すと後で苦労しそうだから調整してもいい

### A を推す理由

**左右対称なので、反転しても破綻しない。**SD やスプライトで左向きを作る可能性がある
（[char-visual.md §3](../inception/worldbuilding/char-visual.md) の条件4）。
**背面図でも形がはっきり出る**ので、三面図として情報量が多い。
船の上で立ち回る持ち場（荷札と行き先の照合）とも馴染む。

### 影響

- **B** を基準にすると、⚠ **左右非対称が全派生に伝播する。**
  反転を使う場面（左を向く SD、桟橋側を向く立ち絵）で**髪が逆の肩に来る**ため、
  反転で済ませられず**専用の絵が要る**
- どちらを選んでも、もう一方は**後から差分として足せる。**⚠ **ただし今回は作らない**（#24 待ち）

### main の応答（2026-09-13）—— 「A でいいと思う。変な設定を残すと後で苦労しそうだから調整してもいい」

**A で確定。**そのうえで、⚠ **`char.md` の記述そのものを直した**（PO の許可による）。

| | |
|---|---|
| **修正前** | 肩より少し長い髪を、**その日の服との収まりを見ながら低くまとめたり片側へ流したりする** |
| **修正後** | 肩より少し長い髪を、**うなじのあたりで低くひとつにまとめている** |

⚠ **「日替わり」を残したままにしない。**残すと、絵を起こすたびに
「今日はどっちか」という決められない問いが出る。**基準が2つある状態は基準が無いのと同じ。**

**導出は失われていない。**「組み合わせを気にする」という表層は、
`char.md` の同じ段落にある**襟元・髪留め・靴の3点**がそのまま担う
（→ [char-visual.md §1](../inception/worldbuilding/char-visual.md)）。
⚠ **こだわりの置き場所が髪型から3点へ移っただけで、性格からの導出は同じ。**

## Question 3 —— 配色

**何を決めるか**: 髪・上着・差し色の3つ。
**なぜ今必要か**: ⚠ **110×305px に縮小されると、残るのはシルエットと色面だけ**になる。
色は「あとで塗る」ものではなく、**識別できるかどうかを決めている。**

⚠ **髪色は導出でほぼ1つに絞れている** → [char-visual.md §4](../inception/worldbuilding/char-visual.md)。
**他7人が黒／濃い灰／栗／赤茶／焦茶／白に近い で埋めており、**
**地色 `0x1a2a3a`（濃紺）に沈まず、かつ被らない帯は「明るい金茶〜亜麻」しか残っていない。**
下の3案はいずれも髪をその帯に置き、**上着と差し色だけを変えている。**

| 案 | 髪 | 上着 | 差し色（襟元・髪留め・靴の3点。**同じ1色で揃える**） |
|---|---|---|---|
| **A**（**推奨**） | 亜麻〜明るい金茶 | **生成り〜砂色**（明るい） | **赤茶** |
| **B** | 亜麻〜明るい金茶 | **くすんだ青緑**（中明度） | **橙** |
| **C** | 亜麻〜明るい金茶 | **濃い茶**（暗い） | **生成り** |
| **X** | Other |

[Answer]: 色配分はchatGPTに絵を起こす前に案を出させていいと思う。

### A を推す理由

**濃紺の地色に対して明度差が最大になり、110px でも輪郭が立つ。**
他7人が濃色に寄っているなかで**主人公だけが明るい塊**になるので、
`world.md` §6 の「**覚えるべきは主人公だけ**」と一致する。

差し色を**赤茶**にするのは、明るい基調の中で**3点（襟元・髪留め・靴）が目立ちすぎずに揃って見える**ため。
⚠ **3点が同じ色で揃っていること自体が「組み合わせを気にする人」の記号**になる
（`char.md`「襟元や髪留め、靴との合わせ方には少しこだわりがあり」）。

### 影響

- **B**: 落ち着くが、⚠ **上着が地色（濃紺）に寄るので輪郭が弱くなる。**
  来店客エリアの地色は `0x1a3a2a`（濃緑）なので、**そちら側ではさらに沈む**
- **C**: 顔まわりに視線が集まるが、⚠ **110px では明るい頭と暗い胴で塊が2つに割れて見える。**
  遠目で1人に見えなくなる恐れがある
- どの案でも、⚠ **柄・細い縁取り・小さな模様は入れない**（縮小で消える。土台 §3 の条件2）

### main の応答（2026-09-13）—— 「色配分は chatGPT に絵を起こす前に案を出させていい」

**賛成。ただし2つ条件を付ける。**

**① 髪色だけは固定して渡す（亜麻〜明るい金茶）。**
⚠ **これは好みではなく導出。**他7人の髪色で埋まっていない帯がここしか無く、
**濃紺の地色に沈まない**のもここだけ（→ [char-visual.md §4](../inception/worldbuilding/char-visual.md)）。
⚠ **ChatGPT はこの制約を検証できない**（他7人の設定も UI の地色も知らない）。
**出させるのは「上着と差し色の組み合わせ」に限る。**

**② 縮小した状態を一緒に見る。**
⚠ **フルサイズで綺麗な配色が 110px で沈むことがある。**
**案を並べるときは、必ず 110×305 に縮めたものを横に置いて判定する。**

**渡す制約**（これを書かないと既定値が出る）:
**地色は濃紺 `#1a2a3a`** ／ **柄・細い縁取り・小さな模様は入れない** ／
**襟元・髪留め・靴の3点は同じ1色で揃える** ／ **基調2色＋差し色1色まで**。
