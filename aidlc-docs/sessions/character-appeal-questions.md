## Question 1 —— キャラ帯に何を出すか

**何を決めるか**: 110×305px の枠に**全身**を出すか、**バストアップ**にするか。
**なぜ今必要か**: ⚠ **全身を入れる限り、顔は約20px・目は約2px。**
**何度描き直しても「遠くに立っている誰か」にしかならない。**
調査の原則（**密度は顔に集める／アクセントは顔まわりに置く**）が**どちらも効かない。**

| 案 | 中身 |
|---|---|
| **A**（**推奨**） | **バストアップ。**枠はそのまま、胸から上だけを出す |
| **B** | **枠を広げて全身を出す**（⚠ 盤面か右パネルが狭くなる） |
| **C** | **全身のまま。**顔は諦め、シルエットと色だけで識別させる |
| **X** | Other |

[Answer]: 店番をしている主人公のSD。カウンターに座っているイメージで2頭身。多分下半身は見えなくていい

**→ X で確定。**⚠ **A（バストアップ）より踏み込んだ。画面に出るのは「2頭身SDの店番」。**
**下半身は出ない。**→ **特徴を置ける場所が上半身だけになった**（依頼書 §2・§7 に反映）。
⚠ **「カウンター」は世界観に無い**（`world.md` は「船倉がそのまま売り場・客は桟橋に立つ」）ので、
**「船縁の向こうに座っている」に読み替えた。**構図は同じで、世界と衝突しない。

**A を推す理由**: **枠を1pxも変えずに、顔の面積が10倍以上になる。**
全身は三面図として手元に持てばよく、**画面に出す必要がない。**

**影響**: **B** は `layout.ts` の作り直し（⚠ **盤面 13×10 が入らなくなる恐れ**）。
**C** は今の状態が続く。**A** なら三面図の使い道は「設計図」のまま変わらない。

## Question 2 —— 頭身

**何を決めるか**: ノエラを何頭身で描くか。
**なぜ今必要か**: **顔の読みやすさと可愛さを同時に決める、最大のつまみ。**
調査では**実写7〜8／スタイライズド4〜5**。⚠ **今の絵は約7.5〜8**（最も読めない側）。

| 案 | 中身 |
|---|---|
| **A**（**推奨**） | **6〜6.5頭身。**大人に見えるが顔が読める |
| **B** | **4〜5頭身。**可愛さは最大。⚠ **21歳の商人には幼い** |
| **C** | **7〜8頭身のまま**（今の絵） |
| **X** | Other |

[Answer]: A

**A を推す理由**: **21歳で商いをする人が幼くなりすぎず、顔の面積は今の約1.3倍。**
⚠ **SD は別に作るので、ここで可愛さを最大化する必要はない。**

## Question 3 —— 差し色をどこに置くか

**何を決めるか**: `char.md` の「**襟元・髪留め・靴の3点を同じ色で揃える**」を維持するか。
**なぜ今必要か**: ⚠ **定石と逆だった。**調査は「**アクセントは一番見てほしい場所に集中**」と言う。
**3点に散らすと、画面最下部の靴が一番目立つ。**実際そうなった（今の絵で最初に目が行くのは赤いブーツ）。

| 案 | 中身 |
|---|---|
| **A**（**推奨**） | **顔まわりに寄せる。**襟元と髪留めに集中し、**靴は基調色にする** |
| **B** | **3点を維持する。**設定を優先 |
| **C** | **「合わせ方にこだわる」という設定自体を見直す** |
| **X** | Other |

[Answer]: A

**A を推す理由**: ⚠ **靴を外すだけで視線が顔へ戻る。**
**`char.md` の「合わせ方にこだわる」は残る**（襟元と髪留めが揃っている）。**変更が最小。**

## Question 4 —— 髪型を変えてよいか

**何を決めるか**: 「うなじで低くひとつにまとめる」を維持するか。
**なぜ今必要か**: ⚠ **髪はシルエットを作る最大の要素。**
調査では「**輪郭から出っ張りを作る。人は小さな出っ張りにも視線を動かす**」。
⚠ **これを私が反転のしやすさという技術理由だけで、最も平坦な形に固定した**（2026-09-13 の Q2）。

| 案 | 中身 |
|---|---|
| **A**（**推奨**） | **輪郭に出っ張りの出る形に変える。**⚠ **左右対称は維持する**（具体形は絵を見て選ぶ） |
| **B** | **今のまま。**反転のしやすさを優先 |
| **X** | Other |

[Answer]: 厳密には決めていないです。選択肢を用意してもいいけど、最初は一つで試したい。

**→ A で確定。1案で試す。**main が出した1案:
**高めの位置でひとつに結び、毛束を太く、毛先を跳ねさせる。**
⚠ **正面からも耳の横に髪の塊が見え、輪郭が出る。左右対称は維持。**

**A を推す理由**: ⚠ **左右対称を保てば、反転しやすいという利点は失われない。**
平坦であることと対称であることは別。

## Question 5 —— 参照をください（質問ではなく素材の依頼）

**魅力的だと思うキャラクターを3〜4点挙げてください。**
ゲーム・アニメ・絵本・何でも構いません。

⚠ **「どこが好きか」は書かなくて結構です。**
**どの軸（頭身・目・髪のシルエット・色・記号）が効いているかは、こちらで読み取ります。**
**言葉で「魅力的に」と言うより、実例のほうが早い** —— 2度の失敗がその証拠です。

[Answer]: アトリエシリーズから引っ張ってきて。ただし**絶対に盗作するようなことを避けてください**

### main の扱い（2026-09-13）

⚠ **作品名・キャラクター名・イラストレーター名は依頼書に一切書かない。**
**書くと、生成は学習データの特定のデザインを再現しようとする。**「〇〇風」も使わない。

**代わりに、調査で出た一般的な傾向だけを一般語に翻訳して渡した**（依頼書 §4）:

| 抽出した傾向 | 依頼書での書き方 |
|---|---|
| 錬金術という題材に合った**素朴で機能的な衣装**（エプロン・ポーチ・ブーツ） | **職業の道具が衣装に組み込まれている**（提げている・挿している・掛けている） |
| **明るく柔らかい塗り**、可愛らしさと日常性を重視 | **明るく柔らかい配色。**暗く沈んだ色でまとめない |
| 壮大な物語より**日常とキャラクター間の交流** | **構えていない、日常の場面が似合う佇まい** |

⚠ **禁止事項の表に「特定の作品・キャラクターの模倣」を明記した**（§9）。
**ノエラは錬金術師ではなく商人なので、道具も違う**（荷札・鞄）。**意匠が重なる余地はもともと小さい。**

## 調査の要点（判断の材料。読まなくても答えられます）

| 原則 | 今の絵 |
|---|---|
| **シルエットテスト**（塗りつぶして誰か分かるか） | ⚠ **落第。**輪郭から出ているものが無い |
| **腕や足を体から離してシルエットを潰さない** | ⚠ できていない |
| **頭身が主制御**（頭を大きくすると顔が「読める」） | ⚠ 7.5〜8頭身 |
| **密度は顔に集める**（顔まわりの描き込みを1段上げる） | ⚠ 顔の密度が最も低い |
| **配色 70:25:5。**アクセントは色相・明度・彩度のうち2つ以上をずらす | 赤茶はあるが**彩度が低く進出色になっていない** |
| **アクセントは顔・目に集中配置**（散らさない） | ⚠ **最大の赤茶が靴＝画面最下部** |
| **主人公には原色が使われやすい**（マリオ赤／ピカチュウ黄／ソニック青） | ⚠ 全身アースカラー |
| **視覚的タグ**（眼帯・赤マント・猫耳のような一目の記号） | ⚠ 無い。荷札は小さく埋もれている |

### ⚠ Q1 から出た、いちばん大きな発見

**2頭身・下半身なしにすると、今の設定で残る特徴は3つしかなかった** ——
**亜麻色の髪 ／ 生成りの上着 ／ 襟元の赤茶。しかも3つとも低彩度。**
**これでは「誰?」になる。**

**だから第3版は、Step 1 をバストアップに変えた。**
⚠ **画面に出るのが上半身だけなら、上半身で判定するのが正しい。**
**全身の棒立ちで魅力を判定させていたのが、2回の失敗の本体だった。**

**併せて上半身に特徴を足した**:
**髪のシルエット**（高い位置・太い毛束・跳ねた毛先）／
**肩掛け鞄の紐が胸元を斜めに横切る**（⚠ **輪郭に線が入る**。荷札も腰から胸元へ移した）／
**差し色を朱〜明るい赤へ**（⚠ **前回の赤茶は彩度が低く、アクセントとして働いていなかった**）。
