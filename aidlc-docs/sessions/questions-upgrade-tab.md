**`手際` の「前 → 後」に、何の数を出しますか。**

**いまどうなっているか**
赤入れのとおり4系統に「前 → 後」を入れました。3つは意味の読める数です ——
**棚 `8×7 → 9×8`**（升目）／**来客 `×1.6 → ×2.0`**（客の来やすさ）／
**利益率 `×1.6 → ×2.0`**（取り分）。
⚠ **`手際` だけ `18 → 22` で、この数は画面のほかの場所に一度も出てきません。**
何が 18 で、22 になると何がどれだけ変わるのかは、この行からは分かりません。

⚠ **速さの倍率に直せません。**`手際` は「難しい品ほど時間が縮む」形で効き、
**倍率には床（0.25倍）と天井（4.0倍）がある**ので、**同じ段でも品によって縮み方が違います。**
「×1.4 速くなる」と書くと、**床に着いている品では嘘になります。**

**選べるもの**

A) **いまのまま `18 → 22`**（**推奨**）
   数の意味は読めませんが、**進み具合（5段のうちどこか）は読めます。**
   ⚠ **いちばん小さい。**ほかの3つと形も揃います。

B) **一律の倍率にする**（`×1.0 → ×1.4` のように）
   ⚠ **床・天井に当たる品では嘘になります。**

C) **作れる品数にする**（`23品 → 41品`）
   本当の数で、意味も読めます。⚠ **解禁の進み具合でも数が動く**ので、
   **改装で増えたぶんと見分けが付きません。**

D) **`手際` だけ「前 → 後」を出さない**（一言のまま）
   ⚠ **4行のうち1行だけ形が違って見えます。**

赤入れは「`32,000レン 不足` → **`37000レン`** と `改装` ボタンに変更」でしたが、
⚠ **画面に出ていた 32,000 は不足額ではなく、棚の1段目の費用そのものです**
（来客 10,000／利益率 14,000／手際 12,000 も、費用の表と一致します）。
**37,000 は 32,000 ＋ 所持金 5,000** なので、**`不足` を「あと32,000足りない」と読まれたことになります。**

→ **`不足` という語を無くしました。**費用を裸で出し、`改装` ボタンを別に置いたので、
**読み違えの元がありません。出している額は 32,000 のままです。**
**買えないときは、ボタンの字が `足りない` に変わります**（商人タブと同じ作り）。
