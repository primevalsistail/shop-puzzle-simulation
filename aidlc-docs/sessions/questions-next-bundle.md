## Question 1
**次の束をどれにするか。**

| 案 | 束 | issue | 中身 | 規模 |
|---|---|---|---|---|
| **A** | **束N — 画面の数字が実際と違う**（**推奨**） | #73 #76 | 進捗バーが `累計売上/100万`、実際のクリアは `所持金/1000万`（**軸も額も違う**）／ 一覧の売値と実売が違う | **小**（2件） |
| **B** | **束I — 見た目の方針と素材** | #10 → #56 → #69 → #15 → #14 | 解像度 → 色に何を担わせるか → アイコンを画像に → キャラ → BGM | **大**（素材の調達を含む） |

| **D** | **単発を数件** | #64 #65 #66 #67 #70 など | 在庫上限の溢れ／検索がかなで引けない／型に名前／D&D が伝わらない | 小×n |
| X | Other | | | |

[Answer]: 

### A を推す理由

⚠ **どちらもペルソナが「投げ出す瞬間」に挙げた。**そして**2件とも「画面の数字が嘘」**という同じ型。

- **#73**: バーが100%になってもクリアしない。**目標額が3箇所に別書き**になっている
- **#76**: 一覧に `売120レン` と出ている品が、売れると `+156レン` になる。**強化を買うほどずれが広がる**

⚠ **#79（画面に足りない情報）の前提でもある。**
**数字が嘘のまま情報を足しても、足した情報も嘘になる。**
**2件と小さいので、次の大きい束の前に挟める。**

### 影響

- **A**: ⚠ **直すとプレイヤーの見え方が変わる**（バーを実際の条件に合わせると、
  **同じプレイで伸びが目に見えて遅くなる**）。**どちらを正とするかで PO 判断が1つ要る**
- **B**: ⚠ **#10（解像度）を決めないと素材が作れない。**ここが全部の前提になる。
  ⚠ **`#15`・`#14` は本文が空で、コード作業ではなく調達。**着手前に「何をもって完了とするか」を書く必要がある
- **C**: ⚠ **数値に触れずに構造だけ**で進める必要がある（`数値調整` は #61 の後）
- **D**: **束にならない小物**。⚠ **手は速いが、遊びの手触りは変わらない**
