### Q1. どのやり方で書き直すか（#126 #127 共通）

外部スキルを探した。**該当しそうなものは4つ。ただし全部インストール数が3桁以下で、
素性の強い出どころ（anthropics / vercel-labs のような）は1つも無い。**

| | スキル | 導入数 / repo★ | 中身 |
|---|---|---|---|
| **A** | `alterlab-ieu/alterlab_gameforge@game-narrative-director` | 95 / 36 | 「物語は語らず遊ばせる」を掲げる語り口の役。オープニング／エンディングの手順は**公開ページで確認できない** |
| **B** | `omer-metin/skills-for-antigravity@player-onboarding` | 48 / 147 | 初回体験の設計。**「一度に1つだけ教える」「文字を読ませない」**が芯。⚠ **会話で教えるのとは逆の思想** |
| **C** | `mrcalderon3d/everything-game-dev-code@onboarding-tutorial-design` | 15 / 83 | 中核ループ・つまずき所・UI 動線を入力に、**段階的に教える順番**を出す |
| **D** | `lvtd-llc/skills@game-story-world-character` | 68 / ★1 | Jesse Schell『Art of Game Design』下敷き。**物語の目的 → 遊びとの同期 → 引き金と受入条件**まで落とす5手順 |
| **E** | **手持ちの `fanout-prompt`** | —— | **複数案を並列で出させ、比べて、PO が1案選ぶ。**この文書群の書き方（決定の出典を残す）とそのまま噛み合う |

**推奨は E ＋ D。**理由は2つ。
**(1) 外部スキルはどれも「本文が公開ページで truncate されていて、中身を確かめずに入れることになる」。**
**(2) いま足りないのは文章力ではなく「何を伝えるか」の決定**で、そこは PO が選ぶ形（E）でしか埋まらない。
**D だけは「物語の目的を先に決める」手順が明文化されている**ので、E の案出しの下敷きに使える。

- [ ] **E ＋ D**（推奨）
- [ ] **A / B / C のどれかを入れる**（→ どれか: ____）
- [ ] 外部スキルは入れない。E だけ
