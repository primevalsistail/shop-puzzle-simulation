# プレイヤーにやらせたいこと

**PO 指定（2026-09-12）。これは方針であって、議論や進捗の記録ではない。**
数値や実装の状況はここに書かない。

---

## 1. ゲーム内の日付で **200日程度**遊ばせる

- 最短で 120日、**理想は 160〜200日**

## 2. 目標金額は**切りのいい数字**にする

- 100万・1000万のような数字。半端な額にしない

## 3. **購入と加工をベース**に、次の tier・拡張を続けさせる

- 進行の主軸は「買う」と「作る」
- その結果として次の tier へ進み、売り場の拡張が続く

## 4. 目標金額に到達する時点で、**最大拡張・レシピ全開放でなくてよい**

- 買い残し・作り残しがあるのが正常

## 5. **いろいろな商品配置を試す**状況を作る

そのために、tier で配置の性格を分ける。

| | 升目 | ボーナス |
|---|---|---|
| **低 tier** | **少ない升** | **薄い全体ボーナス** |
| **高 tier** | **大きい升** | **濃い個別ボーナス** |

## 6. **島ごとに需要を変える**ことで、取捨選択を繰り返させる

- 「**こっちの島では〜を売る**」
- 「**そのためにあっちの島では〜を買う**」

この往復を、遊んでいる間ずっと繰り返させる。
