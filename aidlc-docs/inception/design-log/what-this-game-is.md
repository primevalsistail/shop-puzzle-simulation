# これはどういうゲームか

**PO が確認した内容。**やらせたいことの詳細は [what-players-should-do.md](what-players-should-do.md)。

---

## 1. ジャンル

**資源をやりくりして、再投資を繰り返す経営ゲーム。**
プロジェクト名は「在庫配置パズル型 店舗経営シミュレーション」で、
**配置パズルは升目という制約を作る装置**、本体は経営。

## 2. 時間を使うのは**加工だけ**

**朝と夜に区別はない。仕入れる行為そのものは時間を使わない。**

ゲーム内時間を消費する（`skipMinutes` を呼ぶ）のは
**`CraftingSystem.startCraft` だけ**。仕入れも配置も **0分**。

| 行為 | 時間 | いつでもできるか |
|---|---|---|
| 仕入れる | **0分** | いつでも |
| 並べる・動かす | **0分** | いつでも |
| **加工する** | **レシピの所要分** | いつでも。ただし**営業中にやると売る時間が消える** |
| 売る | 営業時間に自動 | 触らない。**結果が出るだけ** |

→ **作業時間は実質「加工の予算」。**営業時間に食い込ませると売上を失う（実測 **2.6円/分**・線形）。

⚠ **予算は 480分/日ではなく 240分。**作業帯は朝6:00-10:00 と 夜20:00-24:00 に分かれていて、
**`fitsInToday` が 24:00 跨ぎを禁じているので、夜と朝がつながっていない。**
**連続で使えるのは240分。**
⚠ **航海日は無い**（#74 で `atSea` ごと消えた）。

## 3. 資源

| 資源 | 量 | 性質 |
|---|---|---|
| **所持金** | 開始 5,000 | **目標と同じ通貨。**使えば目標が遠のく |
| **加工に使える時間** | **240分/日**（朝240 ／ 夜240。⚠ **跨げないので連続は240**） | **作業効率の強化で実質増やせる**（1回の所要が縮む） |
| 営業時間 | 600分/日 | 固定。プレイヤーは触らない |

## 4. 金で買う長期の強化は**4系統**

どれも「長期で見て得か」を判断して買うもの。

| 強化 | 効くもの |
|---|---|
| **棚を広げる** | 升目 6×5=30 → **13×10=130**（5段）。**費用はだんだん高くする**（PO指定） |
| **来客頻度** | 売上の機会が増える |
| **利益率** | 1個あたりの取り分が増える |
| **作業効率** | 加工1回の所要時間が縮む（`craft.ts` の手際） |

## 5. 勝利条件

**所持金1000万レン。**（累計売上ではない。2026-09-12 に 100万 → 1000万）
到達まで**ゲーム内で200日程度**（最短120日・理想160〜200日）。
**到達時点で最大拡張・レシピ全開放でなくてよい。**

## 6. 組み合わせボーナスは**強化ではない**

「特定の品をセットで売る」は**プレイヤーが金で買う強化ではなく、
並べ方によって得られるボーナス。**

→ **買うものではなく、気づいて並べるもの。**
　 いまの実装では層1（隣接規則 R1〜R6）と層2（名物コンビ・**既定は空**）がこれにあたる。

## 7. 判断の構造 — **2つの資源を、それぞれどこに配るか**

**金をどこへ**（短期 ↔ 長期）

```
今日の仕入れ  ←→  棚を広げる／来客頻度／利益率
（その日に返る）      （何十日も先に返る）
```

**加工の時間をどこへ**

```
240分を、どのレシピに割くか
```

そのうえで、**並べ方で組み合わせボーナスを取る**（金も時間も要らない）。

---

## 8. 決まっていること（補足）

強化は4系統とも**5段**。棚は 6×5 → 7×6 → 8×7 → 9×8 → 11×9 → **13×10**。
組み合わせボーナスは**「同じ棚に並べること」も含む**（隣接だけではない）。
「タグ」は**既存の軸**を使い、新しい属性は足さない。
