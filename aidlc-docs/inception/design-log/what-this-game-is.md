## 1. ジャンル

**資源をやりくりして、再投資を繰り返す経営ゲーム。**
プロジェクト名は「**在庫配置パズル型** 店舗経営シミュレーション」。

- **配置パズル**は、升目という**制約を作る装置**
- **経営シミュレーション**が本体で、**問われているのは「どこに金と時間を投じるか」**

⚠ ここが第1版で外した点。**「見立て」「組み合わせの妙」は世界観の説明であって、ゲームの骨格ではない。**

## 2. プレイヤーが繰り返す行為（ループ）

**1日ごとに、限られた資源をどこに投じるかを決める。**

```
朝（作業時間）  仕入れる／加工する
昼（営業時間）  売る ← ここは触らない。結果が出るだけ
夜（作業時間）  加工する
　　　　　　　　貯まった金を次に何へ回すか決める
```

PO の言葉（原文）:
- 「開店時間は販売を優先させた方がいい」
- 「作業時間で加工を行って利益を上げる」
- 「売り上げ増やすには拡張したほうが長期的に見て利益があるよね」
- 「**商品の購入、加工、拡張の取捨選択を鑑みつつ100万を目指す**」

## 3. 有限な資源は4つ

| 資源 | 量 | 増やせるか |
|---|---|---|
| **所持金** | 開始 5,000 | 売って増やす。**目標と同じ通貨** |
| **営業時間** | 600分/日（10:00-20:00） | 増やせない |
| **作業時間** | 480分/日（朝240＋夜240）＋航海日1,080分 | 増やせない |
| **升目** | 6×5=30 → 最大 14×10=140 | **金で買う** |

## 4. 判断＝**同じ1円をどこに投じるか**

投資先は3つあり、**リターンの形と速さが違う**。ここが取捨選択の本体。

| 投資先 | 何を使う | いつ返る | 何倍 |
|---|---|---|---|
| **購入** | 金 | **その日のうち** | 低い |
| **加工** | 金（材料）＋**作業時間** | その日〜数日 | 中 |
| **拡張** | 金（大きい） | **何十日も先** | 長期で大きい |

**「いま仕入れに全部回すか、我慢して棚を広げるか」** — これが繰り返し問われる判断。

⚠ **拡張の費用は目標と同じ通貨**なので、払えば目標が遠のく。**これは最初から良い判断になっている。**

## 5. 勝利条件

**所持金100万レン。**（累計売上ではない。#26）

## 6. 強化の系統（PO 提案・4つ）

1. **棚を広げる** — 升目が増える。**費用はだんだん高くする**（PO指定）
2. **来店客 or 購入されやすさ** — 売上機会が増える
3. **客が払う金額** — 単価が上がる
4. **セットで売る** — 特定の組み合わせで売上が増える

## 7. いま「取捨選択」になっていない理由（実測）

**3つとも「常に正解が1つ」なので、選ぶ余地がない。**

| | いまなぜ選択にならないか |
|---|---|
| **購入** | 買値＝売値の半分が**全品一律**。単価の高い品を999個買うのが常に正解 |
| **加工** | 作業時間に収めれば**営業時間を1分も食わない**ので、やらない理由がない |
| **拡張** | **まだ存在しない** |

さらに **1日645個も売れる**ので、**量で殴るのが最適**になっている。
PO の「**頻度面でも金額面でも売れすぎている**」はこれ。

## 8. 私が繰り返していた誤り

**「何日で100万に届くか」ばかり測っていた。**
到達日数はこのゲームの出力であって、**遊びの中身ではない。**
測るべきだったのは「**同じ1円を3つの投資先に回したとき、どれが得か**」で、
それが**日によって・場面によって入れ替わるか**（＝選択になっているか）。

## 9. 違っていそうなところ（PO に指してほしい）

- **1** ジャンルの言い方
- **2** ループ（1日の中の順序・触る場所）
- **3** 資源が4つで合っているか。足りないもの・数えなくていいものはあるか
- **4** 投資先が3つで合っているか。**リターンの速さの並び**（購入＜加工＜拡張）で合っているか
- **6** 強化4系統の理解
- **7** 「取捨選択になっていない理由」の診断
