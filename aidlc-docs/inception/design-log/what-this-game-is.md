## 1. ジャンル ✅（PO 確認済み）

**資源をやりくりして、再投資を繰り返す経営ゲーム。**
プロジェクト名は「在庫配置パズル型 店舗経営シミュレーション」で、
**配置パズルは升目という制約を作る装置**、本体は経営。

## 2. 時間を使うのは**加工だけ**

**訂正（PO #2）**: 朝と夜に区別はない。**仕入れる行為そのものは時間を使わない。**

コードでも裏が取れる — ゲーム内時間を消費する（`skipMinutes` を呼ぶ）のは
**`CraftingSystem.startCraft` だけ**。仕入れも配置も **0分**。

| 行為 | 時間 | いつでもできるか |
|---|---|---|
| 仕入れる | **0分** | いつでも |
| 並べる・動かす | **0分** | いつでも |
| **加工する** | **レシピの所要分** | いつでも。ただし**営業中にやると売る時間が消える** |
| 売る | 営業時間に自動 | 触らない。**結果が出るだけ** |

→ **作業時間480分/日（＋航海日1,080分）は、実質「加工の予算」。**
　 営業時間に食い込ませると売上を失うので、そこに収めるのが自然。

## 4. 金で買う長期の強化は**3系統**

**訂正（PO #3 #4）**: 升目だけでなく、**来客頻度も利益率も金で買う。**
どれも「長期で見て得か」を判断して買うもの。

| 強化 | 効くもの |
|---|---|
| **棚を広げる** | 升目 6×5=30 → 最大 14×10=140。**費用はだんだん高くする**（PO指定） |
| **来客頻度** | 売上の機会が増える |
| **利益率** | 1個あたりの取り分が増える |

## 5. 勝利条件 ✅（PO 確認済み）

**所持金100万レン。**（累計売上ではない）

## 6. 組み合わせボーナスは**強化ではない**

**訂正（PO #6）**: 「特定の品をセットで売る」は**プレイヤーが金で買う強化ではなく、
並べ方によって得られるボーナス。**

→ **買うものではなく、気づいて並べるもの。**
　 いまの実装では層1（隣接規則 R1〜R6）と層2（名物コンビ・**既定は空**）がこれにあたる。

## 7. 判断の構造 — **2つの資源を、それぞれどこに配るか**

**金をどこへ**（短期 ↔ 長期）

```
今日の仕入れ  ←→  棚を広げる／来客頻度／利益率
（その日に返る）      （何十日も先に返る）
```

**加工の時間をどこへ**

```
480分を、どのレシピに割くか
```

そのうえで、**並べ方で組み合わせボーナスを取る**（金も時間も要らない）。
