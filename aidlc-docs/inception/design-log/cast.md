# 設計ログ — 主人公以外の人物

設定は [worldbuilding/characters.md](../worldbuilding/characters.md)。
本書は**判断の経緯**を残す。設定書から外したが、後から蒸し返されたときに効くもの。

## 権限の持ち主を、伯母と別人にする

**キャラ案3件が独立に同じ結論に達した。**

一人にまとめると、船を渡してくれた相手が同時に巡回を課している相手になり、
「払えば荷を引き取る窓口」を敵役にしないための説明が余計に要る。

分けておくと、**巡回を課している側に顔がつくぶん、縛りが外れる終盤が締まる。**
また権限の持ち主は拡張の支払い窓口を兼ねるので、終盤だけでなく全編を通して払い続ける相手になる。

## 人物一式は案Bを採用（2026-09-06）

軸は「周囲が、主人公の『喜ばれたい』に何を返すか」。
案Bは「**淡々と取引する**」方向で、周囲は言葉で喜びを返さない。

採用理由は、主人公の充足が「売れたこと」で示される設計と正面から噛み合うこと。
喜びを声にする方向（案A）は、**飛ばせない会話が周期的に発生して配置パズルの手を止める**危険が最も高い。

### 猫のチュートリアル役を降格した

案B採用時、旧 characters.md の「猫が設定とシステムを説明する」と、
案Bの寡黙な猫が衝突した。**説明をノエラ側に移し、猫はきっかけ役に降格。**

猫を饒舌にしないのは作風の好みではなく、**確定事項の側からの要求**である。
饒舌な説明役は、覚える必要のある人物が主人公以外にもう一人増えることを意味し、
「覚えるべきは主人公だけ」に反する。
