# 「儲けは何で決まるべきか」— ペルソナ4人の意見（2026-09-15）

**やり方**: [profit-question-brief.md](profit-question-brief.md) だけを渡し、**4人別々に**答えさせた。
⚠ **コードは読ませていない。互いの意見も渡していない。**
⚠ **こちらの案も、実装で詰まっている事情も伏せた**（書くと全員そこへ寄るため）。

## ⚠ 4人とも「いまの決まり方は合っていない」

**揃ったのは症状ではなく原因のほう** —— **儲けの軸が1本しかない**。**理由は4人ばらばらだった。**

| | 言ったこと |
|---|---|
| **配置パズル好き** | ⚠ **「盤面に置く前に儲けは確定している。置き方は売れ行きの倍率をいじる飾りで、パズルの答えが盤面の外にある」** |
| **経営シム好き** | ⚠ **「仕入れ値が全品一律なのでどの品も利益率が同じ。目利きが判断でなくなる」**／「時間あたり最良の1品を見つけた瞬間に終わる」 |
| **やりこみ層** | ⚠ **「軸が1本しかない表は一度作れば終わり」**／「7段あるのに、深さそのものに値打ちが無い」 |
| **カジュアル層** | ⚠ **「`^0.6` は読めない。画面で確かめようがない計算で儲けが決まると、次の一手が選べない」** |

### ⚠ いちばん強い信号 —— 2人が独立に同じことを言った

**配置パズル好き**: 「**面白さは棚の形と隣接にあるのに、儲けがそこと繋がっていない**」
**やりこみ層**: 「**棚の形と隣接の効果は例外だらけで探す余地がある。面白さがここにあるのに、儲けがここと繋がっていないのが惜しい**」

⚠ **このゲームの看板（配置パズル）と、儲けの決まり方が切れている。**

## ⚠ 割れた点（どちらかを選ぶことになる）

### 1. 軸の数

| | |
|---|---|
| **増やせ**（3人） | **島との組み合わせ ／ 手に入れにくさ（供給量・入荷上限）／ 深さの分岐** |
| **増やすな**（カジュアル層） | ⚠ **「深さ1つで決めてほしい。掛け算より足し算がいい。考えることが2つ以上になると、考えるのをやめる」** |

### 2. 仕入れ値の一律 `売値 × 0.7` —— ⚠ **正面衝突**

| | |
|---|---|
| **経営シム好き** | ⚠ **「これが致命的。利益率が全品同じなら最適解は『一番高い品を棚いっぱい』の一手に収束する。島を巡る意味も 161種ある意味も 7段ある意味も消える」** |
| **カジュアル層** | ⚠ **「ここだけは合っている。覚えることが1つで済む。唯一、手が止まらない場所」** |

⚠ **`aidlc-state.md` の不変条件とも衝突する** ——
「**買値は全品同じ率。これだけで『転売は薄利／作るほうが儲かる／深く作るほど取り分が増える』が同時に満たされる。tier ごとに率を分けないこと**」。

### 3. 棚の広がり

**配置パズル好き**: ⚠ **「130区画は多すぎる。儲けが棚の面積に比例すると『広げる』がすべての答えになる」**
**経営シム好き**: 「拡張＝収入が素直に増えるのは再投資として気持ちいい。**ただしいまのままだとその気持ちよさしか残らない**」

## 4人が同時に受け入れられそうな1点

⚠ **「深さ（tier）」を儲けに直接効かせること。**

- **カジュアル層**: 「**深さ1つで決めてほしい。段は画面で数えられるので自分で確かめられる**」
- **やりこみ層**: 「**深さそのものに値打ちが無い。7段まである意味が数字に出ていない**」
- **経営シム好き**: 「**深さを投資として効かせてほしい**」
- **配置パズル好き**: **反対していない**（別の軸「1升目あたりいくら」を求めた）

⚠ **3人が明確に賛成し、1人が反対していない唯一の軸。**

---

## 具体的な提案として出たもの（そのまま記録）

- **配置パズル好き**: **「1升目あたりいくら」を儲けの見方にする。形と占有面積を分母に入れる。**
  **時間や深さは値打ちそのものではなく、入手の制限として効くのが自然**
- **経営シム好き**: **買値と売値を別々に島が決める**（一律をやめる）／**深い品ほど設備投資の見返りを大きく**
- **やりこみ層**: **同じ材料から複数の道があり、どの道が当たりかは島で変わる**（深さを「分岐」にする）
- **カジュアル層**: **材料費 ＋ 段ごとの上乗せ**（累乗ではなく足し算）／
  ⚠ **「一周したら目標のどれくらいまで来るのか、最初に分かるようにしてほしい」**
