# プレイヤーペルソナの意見（2026-09-12）

**やり方**: 4人のプレイヤーになりきらせ、方針6項目への率直な意見を出させた。
コードは読ませず、[what-players-should-do.md](what-players-should-do.md) と前提だけで判断させている。

---

## 全員が評価した点 — **島ごとの需要差**

**4人ともここだけは揃って面白いと言った。**「この島で売るためにあの島で買う」の往復。
**これがこのゲームの背骨。**

## 意見が割れた点

| | 賛成 | 反対 |
|---|---|---|
| **棚の拡張** | 経営シム好き（**再投資の主軸**） | 配置パズル好き（**パズルの寿命を削る**） |
| **200日** | やりこみ層 | カジュアル層（無理） |
| **ボーナスの例外1割** | やりこみ層（探索対象） | カジュアル層（**理解の放棄点**） |

⚠ 棚の拡張は、**一方にとっての中心が、他方にとっての終わり**になっている。

## 危ういと言われた点（重要な順）

### 1. 拡張がパズルを殺す

**30升 → 130升 で空間の希少性が消える。**
プロジェクト名が「**在庫配置パズル型**」なのに、**進行するほどパズルでなくなる。**

> 「棚を3〜4段拡張して『置きたいものが全部置ける』状態に達した日。そこでこのゲームは私にとって終わります」（配置パズル好き）

**提案されたこと**: 升の総量ではなく「1島1区画」「品ごとの排他」など、
**広くなっても詰める理由**を別に置く。

### 2. 仕入れ・配置が時間ゼロで、実質の資源が金だけ

判断が「買うか貯めるか」に一本化される。

> 「毎日『買えるだけ買って、全部並べて、余りを加工』が最適で、悩みが消える」（経営シム好き）

⚠ **加工だけが時間を食うなら、加工しない遊び方が最適解になる恐れ**も指摘された。

### 3. 200日の中身が示されていない

10日周期を20回。**10周目と19周目で何が違うのかが方針から読み取れない。**
**4人中3人がここで離脱を想像した。**

## 各ペルソナが「投げ出す瞬間」

| | いつ |
|---|---|
| 経営シム好き | **50日目**「毎日同じ手順で数字だけ増える」と気づいたとき |
| 配置パズル好き | **棚を3〜4段拡張して、置きたいものが全部置けた日** |
| カジュアル層 | **30日目**、進捗バーが3%だと分かったとき |
| やりこみ層 | **1周クリア直後**、2周目を始める理由が無いとき |
