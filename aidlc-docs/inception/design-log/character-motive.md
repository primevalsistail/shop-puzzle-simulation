# 設計ログ — 主人公の深層要求が決まらない件

外部検討を依頼した際の内部記録。**このファイルは外部に渡さない**（4方向と順位を見せると答え空間が汚染されるため）。

# 3. 経緯 — どこで行き詰まったか

## 試した4方向

| | 深層要求 |
|---|---|
| A | 何かを作ってみたい（作れる対象は商品・売り場の並び・店そのもの） |
| B | 自分の居場所がほしい |
| C | 人の役に立ちたい |
| D | お金が欲しい |

## レビュー結果（4人のプレイヤー視点、各1問）

| レビュアー | 問い | 順位 |
|---|---|---|
| 配置パズル好き | 主人公の設定が、品を納める手を止めていないか | D > A > C > B |
| 経営シム好き | 動機が金の使い道（売り場・航路）と噛み合うか | D > A > C > B |
| キャラ物語好き | この人と何十時間も船に居たいか | D > B > C > A |
| 初見カジュアル | 開始5分で「誰が・何をしたい話か」が取れるか | D > C > A > B |

**4人全員が D を1位に置いた。**主な理由：

- 動機が**ゲームの動詞（仕入れる・並べる・売る・買い取る）と1:1**で、開始5分に台詞1行で「誰が・何をしたい話か」が両方取れる唯一の案
- 満たすのに**会話が要らない**（確認手段が額という数字なので、設定が本編に会話を義務づけない）
- 金の使い道2つを本人の動機のまま欲しがる唯一の案

## しかし D は確定事項と両立しなかった（今回の核心）

**D だけ、深層要求と舟の値段が同じ単位（金）で書かれている。**
そのため彼女の判断そのものが「もっと良い舟を買えばいい」という問いを生成し続ける。
テンプレートはこの問いへの**反論を禁じている**ので、残る手は「この舟だけは例外」と彫ることになり、
**確定事項（この舟への思い入れ）が深層要求から導けず、接ぎ木になる。**

修正を3回試したが、いずれも**問題を解かずに置き場所を移動しただけ**だった。

| 試した修正 | 何が起きたか |
|---|---|
| (a) 総資産でなく「今日の差額」だけを見る動機にする | **同じ理屈で舟の買い取り自体も説明できなくなった**（買い取りは今日の差額を1レンも生まない） |
| (b) この舟だけ値がついていない（買い取りは「稼げたら」という条件で額が決まっていない） | 彼女の性質の**例外を1つ彫っただけ** |
| (c) 買っているのは船体でなく仕入れの順番 | 思い入れの対象が**航路に移り、この舟から離れた** |

**A・B・C ではこの問いはそもそも発生しない。**思い入れが金で計られていないので、比較の土俵に乗らない。

## 他3案の状態

- **A（作ってみたい）** — 思い入れが**唯一きれいに導けている**（「島ごとに光の入り方が違って、同じ並びが違って見える。10日ごとに見え方が変わるので、何度でも並べ直せる」＝例外を彫らずに済んでいる）。弱点は「**何をしたい話かが手癖のレベルで弱い**」（初見で目的が取れない）、「金を稼ぐ動機を本人が持たない」、「物に向かって喋っていて相棒として弱い」
- **B（居場所）** — 3人が最下位。**品を並べても動機が1ミリも進まない**（満たす手段が全部会話）。金の使い道2つのどちらにも当たらない
- **C（役に立ちたい）** — 「10日でまた同じ桟橋に戻るから、渡した結果をもう一度聞ける」が思い入れの中身。これが**航路の自由と正面衝突**する（ゲーム最大の買い物を主人公が喜べない）。加えて B と表層・開始5分で埋没していると判定された
