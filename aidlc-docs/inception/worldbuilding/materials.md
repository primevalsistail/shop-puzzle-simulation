### ★産地の規則の拡張（2026-09-06）

> **旬が付いているのは「生きもの」であって、そこから採れるものはすべて同じ島。**

竹（たけのこが育ったもの）／稲わら（米と同じ株）／蜜蝋（蜂蜜と同じ巣）／
羊の乳（羊毛と同じ羊）／トナカイの革（肉・角と同じ獣）は、この規則で産地が決まる。
**竹に旬が無くても、たけのこの旬が春だから竹は春。**規則を拡張せずに済んでいる。

**足さなかったもの**: 粘土（**旬が無く、海のものでもないので産地が決まらない。規則を壊す**）／
紅花（**藍と対にすると「青いほう／赤いほう」で品目が増え、色が品目数の軸になる。**
PO が禁じた水増し。→ #86。**足すなら、紅花から何を作るかを先に決めること**）。

### ★麻・藍・小麦を足した（2026-09-13 ／ #86）

元は「無くても成立している」として足していなかったが、
⚠ **それは「商品として扱わない」という判断であって、「世界に無い」ではなかった。**

**実害が出た** —— キャラクターデザインの依頼書が
**「染料が商品に無い → この世界では色が作れない」と読んで、存在しない制約を書いた**（→ `world.md` §8）。

| 品 | 産地 | 旬の理由 |
|---|---|---|
| 麻 | リナツィア（夏） | 丈が伸びきる真夏に刈り取る |
| 藍 | リナツィア（夏） | 葉がもっとも濃く茂る真夏に刈る |
| 小麦 | ノアキータ（秋） | 穂が黄金に実って刈り取る。島の性格「木の実と穀」（米・蕎麦の実と同じ） |

⚠ **規則は1つも足していない。**3品とも植物なので、**旬から産地が決まる既存の規則にそのまま乗る。**
合計は 50品 → **53品**（ハルヴェラ11／リナツィア11／ノアキータ13／ミフユリア11／なし7）。
**素材が増えたのはこれが初めて。**

⚠ **染料は1品だけ。**「藍の染料／紅花の染料」と分けない。
**染めた品も名前に色を持たせない**（`染めの麻布` ／ `麻の上着`）。**色を品目数の軸にしない**（PO 明示）。

## 決定の経緯（同じ議論を繰り返さないために）

| 決定 | 内容 |
|---|---|
| **ぶどうは秋** | 夏（強い陽で糖がのる）と秋（寒暖差で熟す）の両方が挙げた。**「一般的にどの季節のイメージか」で秋** |
| **鮭は残す** | 一度「遡上は季節現象なので、時期の来ない世界では起こらない」として落としたが、**常に秋の島では遡上の時期が常在する**ので落とす理由が消えた |
| **羊毛は春に残す** | 「冬毛が要らなくなる引き金が無い」という反論は**生育条件の話**なので対象外（island-goods.md §2）。**春の毛刈りは通じるイメージ** |
| **レモン・オリーブが移動** | 夏の島が「旬が夏でない」として落としたものを、**旬の島へ移した**。レモン→冬、オリーブ→秋 |
| **海水は採らない／塩を海の品に** | 「素材＝そのまま採れるもの」は体系の要件ではなかった（→ island-goods.md §6）。海水は仕入れる画も売る画も成立しない |
| **ミフユリアの魚を削った** | 元は11品中5品が海産物で、海の区分と系統が重なっていた。**魚をゼロにし**、陸（氷・トナカイ・うさぎ・えのきたけ・松・白樺）を島の顔にした |
| **海の非食品を増やした** | 元は7品中6品が魚介。流木・軽石・かもめの羽根を足し、食べもの3／それ以外4にした |
| **青魚を1品に絞った** | いわし・さば・あじは「群れで回遊する青い魚」として区別がつかない。いわしのみ |
| **たこを落とした** | 回遊せず沿岸の岩場に居着くので、「どの島のものでもない」という産地なしの理屈と矛盾する |
