# UI配色案

昼の光が入る売り場として、明るい生成りと灰緑を地に、状態の合図だけに強い色を使います。左一覧・右操作板・メッセージ欄は同じ地に統一します。

指定の39項目（複数色を一括指定する項目を含む）と、不足する「ボタン文字」「入力フォーカス枠」の2項目を定義します。組Fは指定どおり、個別色ではなくHSL範囲です。

| 追加：入力フォーカス枠 | `#234e78` | 入力中の数量欄の外枠 | 選択と同じ色で、現在の操作先を示す |

**明度の段。** 相対輝度は、画面の地 **0.725** → 売り場 **0.804** → 区画 **0.851** → 窓 **0.930**。広い売り場も明るく保ち、操作面を段階的に手前へ出します。幕を重ねた背後は操作対象から外します。

**文字の読みやすさ。** 幕を除くAの全地に対し、本文は最小 **8.68:1**、副文字は **4.82:1**。有効なボタン文字は最小 **5.43:1**、Eの行に副文字を載せても **4.68:1** です。弱文字はA上で最小 **3.31:1** のため、読む必要のある説明や購入できない理由には副文字を使います。

**状態の見分け。** Cの6色は、幕を除くAの全地に対して最小 **3.08:1** を確保します。相対輝度は、手放す **0.050** → 選択 **0.072** → 不可 **0.080** → 可 **0.124** → 僅少 **0.169** → ホバー **0.202**。ただし隣接する色を明度だけで確実に識別することはできないため、順に「捨てる表示」「二重枠」「×」「✓」「残数表示」「内枠」を併用します。選択・ホバーは在庫の印を消さず重ねます。

品の色板に直接状態線を重ねる場合は、間に `#faf7ee` の細い縁を挟みます。HSL範囲だけでは約160品の識別は保証できないため、品名・形の併用を前提にします。
