## 1. 前回の失敗（ここが一番大事）

第1版で出てきたのは、**ベージュのジャケット＋ベージュのスラックス＋革のローファー**でした。
**通勤着です。**船で商いをする人に見えません。

| 何が起きたか |
|---|
| **全身が同じベージュ**で、明度差がなく、のっぺりしていた |
| **肩から足首まで同じ幅**で、シルエットに起伏がなかった |
| **海・船・荷・商いを感じさせるものが一つも無かった** |

**表示サイズの制約（色数を絞る・柄を入れない）を最初に言ったので、情報量が消えました。**

**第2版では順番を変えています。**⚠ **魅力を先に、制約を後に。**

## 3. 世界

- 気候の違う**四つの島**と、それを結ぶ穏やかな海だけでできた世界。陸路が無く、人も荷も船で動く
- **魔法・異種族・戦争がない。**外洋という概念もない
- ⚠ **四季という観念がない**（春夏秋冬を指す装いや小物は存在しない）
- 調子は**明るく穏やか**。喪失・対立・敵役が主題になることはない
- 島名・人名・船名のほかに**固有名詞を持たない世界**。看板も旗も**文字も無い**

主人公は、気候の違う四島を**10日ごとに巡る店舟**で商いをしています。接岸すると船の横腹が開き、
荷を納めた**船倉がそのまま売り場**になる。客は桟橋に立ったまま買う。
**別の島で仕入れた品を、次の島へ持っていって売る人**です。

## 5. 服（⚠ 前回ここがビジネススーツになりました）

**船の上で荷を扱い、桟橋で客に品を売る人の服です。**

| 部位 | 指定 |
|---|---|
| **上着** | 腰までの**短い羽織り**。⚠ **テーラードジャケットにしない**（スーツ的な襟の仕立て・肩パッド・ボタンの列を作らない）。**厚手の綿か帆布。前は留めない。袖はまくれる** |
| **インナー** | シャツかカットソー。**襟元に差し色**が来る |
| **ズボン** | 細身だが動ける。⚠ **上着と明確に違う色にする。同系色で揃えない**（前回の最大の失敗） |
| **靴** | ⚠ **革のローファーにしない。**甲板で滑らない**短いブーツか編み上げ** |
| **こだわり** | ⚠ **襟元・髪留め・靴の3点を同じ1色で揃える。**ここ以外に飾りを足さない |

> **なぜ3点を同色で揃えるのか**: この人は服そのものではなく「**合わせ方**」にこだわります。
> **3点が揃っていること自体が、組み合わせを気にする性格の記号**になります。

### この段階の配色

**髪＝亜麻〜明るい金茶**（固定） ／ **上着＝生成り〜砂色** ／ **インナー＝生成り**
／ ⚠ **ズボン＝濃い茶**（上着とはっきり分ける） ／ **差し色＝赤茶**（襟元・髪留め・靴）

⚠ **上下を同系色にしないこと。**前回それで全身ベージュになりました。

## 9. Step 1 — 画風

⚠ **あなたが描くのは、このファイルを渡されたときに指定された1案だけです。**
**甲と乙の両方を描かないでください。**指定が無ければ**どちらを描くか訊いてください。**

（甲と乙は**別々の人に**依頼しています。⚠ **同じ人に続けて2枚描かせると、2枚目が1枚目に寄って
比較にならない** —— 前回それで失敗しました。）

**全身絵を1枚**ください。

### ポーズと表情（⚠ 前回の棒立ちを繰り返さない）

**品をひとつ手に取り、「これはどの島へ持っていこうか」と考えている瞬間。**

- 目線は手の品か、少し遠く
- ⚠ **片足に重心をかけ、立ち姿に傾きを作る**（気をつけの姿勢にしない）
- ⚠ **表情は穏やかだが、目に力がある。**「面白いものを見つけた」という顔
- 全身。背景は無地

### 画風の2案

| | 画風 |
|---|---|
| **甲** | **セル塗り**（テレビアニメのキャラクター表に近い）。**輪郭線は均一な細線。影は2値ではっきり。目に光を入れる。色は鮮やかめ** |
| **乙** | **絵本風**。**輪郭線は太さに強弱があり、手描きの揺れがある。色数は少なく、塗りは平坦。影はほとんど付けない。紙の質感** |

⚠ **指定された側の特徴を、はっきり出してください。**
**線の太さ・影の付け方・色数・目の描き方**が、もう一方と見分けられる絵になっていること。
