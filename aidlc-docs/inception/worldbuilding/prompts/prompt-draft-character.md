## 4案が揃ったら — レビューの前に衝突チェック（メインセッションの作業）

**「全案が同じものを選ばないこと」は、互いを見られないサブセッションには守れない。**
各セッションは自分の1案しか知らないので、この条件は原理的に自己判定できない。
だから**個別の持ち場や語を禁止して回るのではなく、メインセッションが突き合わせて検出し、差し戻す。**

4案の下記3項目を横並びにし、**2案以上が同じものを選んでいたら、その案だけ差し戻す。**

| 項目 | 衝突とみなす条件 |
|---|---|
| 一人称 | 同じ語（例: 2案が「自分」）。語が同じでも喋りの調子で明確に割れているなら可 |
| 船での役割 | 同じ持ち場 |
| 表層の書き出し | 同じ構文（例: 全案が「顔より先に◯◯を見る」）。**◯◯の差し替えは割れたことにならない** |

差し戻すときは、**衝突した相手の案の該当箇所だけ**を渡す（案の全文は渡さない。全文を渡すと寄る）。
指示は「この項目が他案と衝突している。**深層要求から導き直して別のものにするか、
その深層要求でなければ書けない理由に書き直すか、どちらかにせよ**」とする。
先に出したほうを残す必要はない。**導出が弱いほうを差し戻す。**

なお、案を1つに絞ったあとは衝突自体が消えるので、**選定に支障が出るほどの衝突でなければ
差し戻さずレビューへ進めてよい。**差し戻しは、比較の邪魔になる場合だけ行う。

# 既定値の禁止

**この世界の前提から誰でも出せる答えを書かないこと。** 判定はひとつ。

> **その答えを、他の3方向の担当者がそのまま書いても成立するなら、
> それは深層要求から導けていない。書き直すこと。**

理由を1行書かせるだけでは防げない。**理由のほうが4方向で共通してしまう**ためである。

## 使用禁止（1回目の実行で4案が揃って引いた既定値）

1回目は、互いを知らない4セッションが**一人称も、その理由も、船での役割も、
「開始5分で伝わること」も、ほぼ同一の答えに落ちた。**
（4案とも一人称「あたし」。理由も4案とも「わたしは遠慮がち／あたしは短くて速い」。
　船での役割も4案とも積み付け・受け渡し係。開始5分も3案が「もう手が動いている人」）


| 項目 | 禁止するもの |
|---|---|
| 一人称の理由 | 「わたし＝遠慮・鈍い／あたし＝短い・速い」という対比。**この理由は4方向すべてで書ける** |
| 表層の書き方 | 「口より先に手が動く」「返事より先に手が動く」「頼まれる前にもう始めている」——**所作の速さ**で表層を書くこと |
| 船での役割 | **禁止しない。**→「船での役割の扱い」を見ること（過去に4案とも積み付け・受け渡し係になった） |
| 開始5分 | 「もう手を動かしている人」系の一文 |

一人称は結果として「あたし」でもよいが、**その深層要求でなければ選べない理由**が要る。
候補を狭く見ないこと（あたし／わたし／私／うち／わたくし／自分／名前で自称 等）。
語尾・喋りの間合いのほうに差を出してもよい。

## 表層を「速さ」以外で書く手がかり
表層は行動の癖で書く。ただし癖＝手の速さではない。ほかに差の出る層がある。

- 何を先に見るか（人の顔／数字／並び／空いた場所）
- 断り方・引き受け方
- 一人のときと人前での差
- 黙る場面／喋りすぎる場面
- 直したくなるもの、放っておけるもの

## 船での役割を探す手がかり
定期船の乗員の持ち場は、荷の積み付け以外にもある。
world.md の範囲（島を10日ごとに巡る／人と荷を運ぶ／預かり荷がある）で考えられるもの:

桟橋での客あしらい、乗客の世話、賄い、帳面と運賃、荷札と行き先の照合、
接岸のときの綱さばき、甲板の見張り、島ごとの荷主とのやり取り など。

**新しい道具・作業・用語を発明しないこと。**深層要求から最も自然に出る持ち場を選ぶ。

### 船での役割の扱い
**特定の持ち場を禁止しない。**積み付け係でも受け渡し係でもよい。
個別に禁止すると、避けるためだけに深層要求から遠い持ち場へ飛び、**表層と役割が繋がらなくなる。**
（2回目の実行で実際にこれが起きた。「並べ替えたがり」が積み付けを避けて賄いに飛び、
　役割の理由が表層を飛ばして深層要求に直結した。1回目とは別の壊れ方をする）

代わりに、選んだ持ち場に**「既定値の禁止」の判定をそのまま適用すること。**

> その持ち場を、**その理由のまま**他の3方向の担当者が選んでも成立するなら、それは既定値である。
> 持ち場を変えるか、その深層要求でなければ書けない理由に書き直すこと。

**役割は表層から導くこと。**深層要求から役割へ直接飛ばないこと。
結果的に他案と持ち場が重なることはあってよい。**全案が同じ持ち場になるのは導出の失敗**だが、
それはメインセッションが突き合わせて検出し差し戻す。サブセッションは自分の導出だけを見ること。

# 世界観条件（主人公案が満たすこと）

- **確定事項**：21歳の女性／島を巡る定期船に乗っていた／舟に思い入れがあって引き取る
- **重い・暗い方向にしないこと。**喪失・自己犠牲・対立・敵役を動機にしない
- 名前は世界の音（ハルヴェラ／リナツィア／ノアキータ／ミフユリア／ペルラ／レン）に合っていること。暫定案は「ミラ・レンツィ」だが変えてよい

- 新しい固有名詞・設定用語を足さないこと（「取り合わせ」以外を作らない）
- 魔法・異種族・外洋・四島の外を出さないこと
- ストーリーをこの段階で書かないこと
