## 1. この絵がどこに出るか

**最終的には、店番をしている姿を2頭身に崩したものが、細い縦長の枠に出ます。**
**船縁の向こうに座っている構図で、下半身は見えません。**

そこから来る条件:

- ⚠ **特徴はすべて上半身に置いてください。**腰から下は画面に出ません
- ⚠ **2頭身に崩したとき、残せる特徴は3〜4個だけです。**
  **その3〜4個を、この段階で作ります**
- ⚠ **顔が主役です。**枠の中で顔が最も大きく、最も情報量の多い場所になります

**ただし、今回描くのは全身です。**上半身だけを先に描くことはできません
（上着の丈も、腰まわりも、頭身も、全身が決まらないと決まらないため）。
⚠ **全身を描いたうえで、特徴の置き場所を上半身に寄せてください。**

## 2. 主人公として立たせるために（⚠ ここが一番大事）

1. ⚠ **一目で「この人が主人公だ」と分かること。**
   **脇役が7人いて、全員この人より落ち着いた見た目です**
2. ⚠ **2頭身に崩しても残る特徴を3〜4個作ってください。**
   **髪のかたち／顔まわりの色／胸から上の小物** —— このあたりに作ります
3. ⚠ **輪郭に出っ張りを作ってください。**
   **人は小さな出っ張りにも視線を動かします**
4. ⚠ **顔まわりの描き込みを、他の場所より1段上げてください**
5. ⚠ **一番強い色を顔の近くに置いてください。**顔から離すと、視線がそちらへ逃げます
6. **21歳に見えること**

> ⚠ **無難さより魅力を優先してください。**
> **迷ったら、目立つほうを選んでください。**

## 3. この人が他の人と違う理由（⚠ ここが設計の核です）

**この世界は陸路が無く、船でしか動けません。**
**だから島の人は、自分の島で採れる素材の服しか日常着にできません。**

| 島 | その島で採れる繊維・革 | 島の人の装い |
|---|---|---|
| 温暖な島 | **羊毛** | 毛糸とフェルト。やわらかい |
| 実りの島 | **綿** | 木綿と帆布。しっかりした平織り |
| 雪の島 | **トナカイの革と角、うさぎの毛皮** | 革と毛皮。角を削った留め具 |

**島の人は1〜2素材で完結していて、装飾がなく、色数も少ない。**

> ⚠ **ノエラは、四島すべてを巡る唯一の人です。**
> **だから彼女だけが、四島の素材を同時に身につけられます。**
> **これが、他の誰とも違って見える理由です。**

**身につけるもの**:
**帆布**（実りの島の綿）＋**毛糸の編みもの**（温暖な島の羊毛）＋**革と角の留め具**（雪の島）
＋**かもめの羽根**（海）。

⚠ **素材も、作りも、留め具も、島の人と同じものです。**
**違うのは「何種類が同居しているか」だけ。**だから世界から浮きません。

⚠ **これは主人公のための例外ではありません。**
**四島すべてを回らないと作れない品が、この世界には実際にあります。**

### 目指す絵の調子

**道具を持って働く人の、日常的で親しみやすい絵。明るく柔らかい配色。構えていない佇まい。**

## 4. 世界

- 気候の違う**四つの島**と、それを結ぶ穏やかな海だけの世界。陸路が無く、人も荷も船で動く
- **魔法・異種族・戦争がない**
- ⚠ **四季という観念がない**（季節を指す装いや小物は存在しない）
- 調子は**明るく穏やか**。喪失・対立・敵役が主題にならない

主人公は**10日ごとに四島を巡る店舟**で商いをしています。接岸すると船の横腹が開き、
**船倉がそのまま売り場**になる。客は桟橋に立ったまま買う。
**別の島で仕入れた品を、次の島へ持っていって売る人**です。

## 6. 上半身の作り（⚠ ここに特徴を集めます）

| 部位 | 指定 |
|---|---|
| **髪** | ⚠ **高めの位置でひとつに結び、毛束は太く、毛先を跳ねさせる。**<br>**正面からも耳の横に髪の塊が見え、輪郭が出ること。**⚠ **左右対称を保つ**（後で反転して使います） |
| **上着** | **腰までの短い羽織り。木綿の帆布**（実りの島）。襟は無いか、小さく柔らかいもの。**前は留めず、袖はまくっている** |
| **インナー** | **木綿のシャツ**（実りの島） |
| **前掛け** | ⚠ **帆布の前掛けを腰に巻く。**<br>**四島すべての素材を使わないと作れない品**で、**商いをする人の記号**でもあります |
| **編みもの** | ⚠ **毛糸の編みものを、襟元か肩に**（温暖な島の羊毛）。<br>**帆布の硬さと、編み目のやわらかさが隣り合う。**⚠ **ここに一番強い色が来ます**（§7） |
| **留め具・帯** | **獣の角を削った留め具と、革の帯**（雪の島）。<br>⚠ **金属の留め具も世界にあります。**ノエラは角と革を使う、というだけです |
| **鞄** | ⚠ **革の肩掛け鞄を斜めに掛け、その帯に小さな木の荷札を数枚結ぶ。**<br>**帯が胸元を斜めに横切るので、輪郭に線が入ります。**<br>この人は**荷札と行き先を照合していた人**です |

⚠ **質感を描き分けてください。****帆布（平織りで硬い）／編みもの（毛糸の目）／革（なめした艶）／角（削った白）**
—— **4つの素材が同居していることが、この人が主人公である理由そのものです。**

⚠ **靴・ズボンは描きますが、特徴を置く場所としては使いません。**画面に出ないためです。
**目立たせるのは上半身。**下半身は落ち着かせてください。

## 7. 色

| | |
|---|---|
| **髪** | **亜麻〜明るい金茶**（固定） |
| **上着・前掛け** | ⚠ **明るい青みの灰〜くすんだ青**（面積が最大。**背景の濃紺よりはっきり明るく**） |
| **インナー・革・角** | **生成り／革の茶／角の白**（素材の地色） |
| **差し色** | ⚠ **朱色〜明るい赤。****襟元の編みものと髪留めの2箇所だけ**に置く |

⚠ **島の人は素材の地色しか持ちません。****彩度の高い色を持っているのは、この人だけです。**
**四島を巡るので、染める材料も手に入るためです。**

- ⚠ **髪・上着・差し色の色相を、3方向に散らしてください。**同系色でまとめないこと
- ⚠ **差し色は彩度の高い色を使ってください。**まわりと同じ明度帯に埋もれると、アクセントとして働きません
- ⚠ **差し色を顔から離さないこと。**襟元と髪留めは、どちらも顔のすぐそばです
- **色数は基調2色＋差し色1色**。面積の目安は **70 : 25 : 5**
- ⚠ **柄・細い縁取り・小さな模様は入れない**（縮小で消えます）

## 10. Step 1 — 全身立ち絵を1枚

⚠ **1枚だけです。**顔のアップも、画風の描き分けも、この段階では要りません。

- **品をひとつ手に取り、「これはどの島へ持っていこうか」と考えている瞬間**
- 目線は手の品か、少し遠く
- ⚠ **片足に重心をかけ、立ち姿に傾きを作る**（気をつけの姿勢にしない）
- ⚠ **腕を体から離す。**体の線に沿わせると、輪郭が潰れます
- ⚠ **表情は穏やかだが、目に力がある**
- 背景は無地。影は落とさない

⚠ **この1枚で「主人公に見えるか」が決まります。三面図はこの後です。**
