# 1. 前提（変更不可）

## 世界
- レンティアは、気候の違う**四つの島**と、それを結ぶ穏やかな海でできた世界。島同士は陸路で繋がらず、人も荷も船で動く
- 島の気候はそれぞれ変わらない。**採れるものが島ごとにまるで違う**

| 島 | 気候 |
|---|---|
| ハルヴェラ島 | 温暖 |
| リナツィア島 | 陽が強く、暑い |
| ノアキータ島 | 実りが絶えない |
| ミフユリア島 | 雪が絶えない |

- 通貨は世界じゅうで「レン」ひとつ
- 魔法・異種族・戦争はない。外洋や「四島の外」という概念を持たない
- **この世界に四季という観念はない。**「春島」のような呼び名も存在しない
- 調子は明るく穏やか。**喪失・自己犠牲・対立・敵役が主題になることはない**
- 設定用語は「**取り合わせ**」ひとつだけ（隣り合わせに納めると値が上がる品の組み合わせ）

## ゲームの作り
店舟〈ペルラ号〉で四島を10日ごとに移りながら商う。店の名前は船の名前と同じ。

- **店＝船倉。**接岸すると船の横腹が開き、荷を納めた船倉が**そのまま**売り場になる。客は桟橋に立ったまま買う
- 主人公がするのは品を納めることだけ。**造作の仕事は発生しない**（棚を組む・船を改造するといった工程は存在しない）
- **客は桟橋の不特定多数。個人ではなく類型。**名前と履歴のある常連を作らない

〈ペルラ号〉は**まだ定期航路の一隻**で、主人公にとっては借り物。縛りが二つある。

| 縛り | 内容 | 外れ方 |
|---|---|---|
| 移動 | 10日ごとに決められた順でしか島を回れない | 船倉をひと通り空けたあと、**舟を買い取ると航路が自分の裁量になる** |
| 広さ | 船倉は預かり荷に占められ、売り場は入口近くの一角だけ | 金を払って**預かり契約を一区画ぶん降りる**と、空いた区画がそのまま売り場になる |

- 稼いだ金は「売り場の広さ」と「航路を決める自由」の2つにしか化けない

## 主人公について確定していること
- **21歳の女性**
- 島を巡る**定期船に乗っていた**（船主は伯母。航路縮小で定期船が退役し、伯母も船を降りる）
- **舟を引き取る側。**買い取るまでは借り物
- 船に住みついている**猫**がいて、主人公と話す（猫が特別な存在であることは掘り下げない）

# 2. 確定した深層要求（変更不可）

> **「自分が持ってきたものが、その土地で喜ばれる瞬間を作り続けたい。」**

## 層の割り当て

| 層 | 内容 |
|---|---|
| **深層要求**（求めているもの） | 喜ばれること |
| **ゲーム上の信号**（それが起きたと分かる形） | 受け取られたこと＝**売れたこと** |

充足を読み取る手段は**売れたこと自体**なので、確かめに行く会話は要らない。
イベント会話は信号に厚みを足すために載る（**無くても動機は満たされる**）。

## 最重要 — 隣接する別方向へ滑らせないこと

「喜ばれたい」は「**人の役に立ちたい**」と紙一重。そちらへ寄せると、この案の意味が消える。
**区別は「移動」にある。**

| | 充足の条件 |
|---|---|
| 人の役に立ちたい | 相手が助かればよい。**どこから来た品かは関係ない** |
| **この案** | **自分が別の土地から持ってきた**ものであること。**その場で**起きること |

**「人の役に立ちたい」人には舟が要らない。この人には要る。**
下の層をすべて、この差を通して導くこと。

# 3. 依頼（サブセッション向け）

> **上の深層要求と、**別途割り当てられた**表層から、人物を1案だけ起こしてほしい。**

## 順序（厳守）

> **判断の癖（中層） → 性格（表層） → 船での役割 → 一人称・喋り方 → 外見・名前**

**表層は割り当てられているが、いきなりそこから書き始めないこと。**
先に**判断の癖**を深層要求から書き、**そこから割り当てられた表層へ繋ぐ**こと。
継ぎ目はこの中層に出る。ここを飛ばすと、表層と深層要求を繋ぐためだけの理由が発明される。

- **深層要求のほうを、割り当てられた表層に合わせて読み替えないこと**（深層要求は変更不可）
- **船での役割は「表層」から導くこと。**深層要求から役割へ直接飛ばないこと

## 割り当てられた表層が導けない場合

**無理に繋がないこと。**
「この深層要求からこの表層は導けない」と判断したら、**そう書いて、理由を3行で述べてよい。**
その場合でも、判断の癖までは書くこと。**断った理由のほうが、強引に繋いだ案より情報になる。**

## 自由枠を割り当てられた場合

下記5候補を**使わず**、自分で表層を名付けること。

> 陽気 ／ 物静か ／ 勝ち気 ／ おっとり ／ 飄々としている

過去の実行では、採用された表層の3/4がリストにない自分で名付けたものだった。
リストは粒度が粗く、深層要求に忠実にやると自然と外れる。

## 船での役割を探す手がかり

定期船の乗員の持ち場は、荷の積み付け以外にもある。
桟橋での客あしらい、乗客の世話、賄い、帳面と運賃、荷札と行き先の照合、接岸のときの綱さばき、
甲板の見張り、島ごとの荷主とのやり取り など。

**特定の持ち場を禁止しない。新しい道具・作業・用語を発明しないこと。**

# 4. 既定値の禁止

判定はひとつ。

> **その答えを、別の深層要求の担当者がそのまま書いても成立するなら、それは導けていない。**

理由を1行書くだけでは防げない。**理由のほうが複数方向で共通してしまう**ため。
過去の実行では、互いを知らない4セッションが**一人称も、その理由も、船での役割も、
「開始5分で伝わること」も、ほぼ同一の答えに落ちた。**

| 項目 | 禁止するもの |
|---|---|
| 一人称の理由 | 「わたし＝遠慮がち／あたし＝短くて速い」という対比。**この理由はどの方向でも書ける** |
| 表層の書き方 | 「口より先に手が動く」「返事より先に手が動く」「頼まれる前にもう始めている」——**所作の速さで表層を書くこと** |
| 開始5分 | 「もう手を動かしている人」系の一文 |

**表層は行動の癖で書く。ただし癖＝手の速さではない。**差の出る層はほかにある。

- 何を先に見るか（人の顔／数字／並び／空いた場所）
- 断り方・引き受け方
- 一人のときと人前での差
- 黙る場面／喋りすぎる場面
- 直したくなるもの、放っておけるもの

一人称は候補を狭く見ないこと（あたし／わたし／私／うち／わたくし／自分／名前で自称 等）。
語尾・喋りの間合いのほうに差を出してもよい。

---

# 5. 禁止事項

- **四季・季節名を出さないこと**
- 新しい固有名詞・設定用語を足さないこと（「取り合わせ」以外を作らない）
- 魔法・異種族・外洋・四島の外を出さないこと
- **重い・暗い方向にしないこと。**喪失・自己犠牲・対立・敵役を動機にしない
- 造作の仕事・新しい道具・新しい作業を発明しないこと
- **ストーリーを書かないこと。**人物の設定だけを出す
- 名前は世界の音（ハルヴェラ／リナツィア／ノアキータ／ミフユリア／ペルラ／レン）に合っていること。暫定案は「ミラ・レンツィ」だが変えてよい
