# メインセッション

サブセッションを4つ開き、**〈ペルラ号〉の「はじまりの場面」「終わりの場面」「案内の6段の狙い」の案**を
テンプレートに沿って出させてください。各サブセッションには

- `aidlc-docs/inception/worldbuilding/world.md`
- `aidlc-docs/inception/worldbuilding/characters.md`
- `aidlc-docs/inception/worldbuilding/char.md`

を読ませ、以下の方向と出力先を明示すること。

⚠ **いまゲームに入っている場面の文面は渡さないこと。**渡すと直す作業になり、作り直しにならない。

（軸は「**商船を買うことが、ノエラにとって何の達成なのか**」。
　**はじまりの場面・終わりの場面・案内の狙いを、この一本から導かせる。**担当方向から外れないこと）

- A: **自分で行き先を決められるようになる**
     いまは定期の一隻に乗ったままで、回る順は決まっている。商船はその順から出ること
     → aidlc-docs/inception/worldbuilding/story/story-a.md
- B: **渡されたものを、渡された以上にして返す**
     叔母テレナから受け取った舟。その相手にもう一度見せられるところまで持っていくこと
     → aidlc-docs/inception/worldbuilding/story/story-b.md
- C: **入口の一角が、舟まるごとの店になる**
     始まりの売り場は入口の一角だけで、船倉はよその預かり荷で埋まっている。それを全部自分の店にすること
     → aidlc-docs/inception/worldbuilding/story/story-c.md
- D: **縮んだ航路を、もう一度つなぎ直す**
     航路が縮んで島のあいだが遠くなった世界で、自分の船がその隙間を埋めること
     → aidlc-docs/inception/worldbuilding/story/story-d.md

**はじまりの場面の段の数・終わりの場面の中身・案内の6段の狙いは、すべて軸から導くこと。**
案ごとに違ってよく、結果的に他案と重なってもよい。**場面を先に書いて軸を後付けしないこと。**

その後、別のサブセッションを4つ開き、**上記4ファイルすべてを読ませて**、
以下のレビュアーに4案を比較させたうえで簡潔にレビューさせてください。

- 配置パズル好き → aidlc-docs/inception/worldbuilding/story/review-story-puzzle.md
- 経営シム好き　 → aidlc-docs/inception/worldbuilding/story/review-story-sim.md
- キャラ物語好き → aidlc-docs/inception/worldbuilding/story/review-story-chara.md
- 初見カジュアル → aidlc-docs/inception/worldbuilding/story/review-story-casual.md

レビューが揃ったら結果をまとめて提示してください。**1案を選ぶのはユーザです。**

# サブセッション

貴方は優秀なゲーム脚本家です。
渡された資料を前提に、指示された方向で**3つの場面の設計**を組んでください。
出力先は指示されたパスとし、**ファイル名を自分で決めないこと。**

- 資料に**確定と書かれていることを変更しない**。埋めるのは場面の側だけ
- **下の「場面の条件」に反する案は出さない**
- **台詞は、テンプレートの指定した行数に収めること**

# レビューセッション

貴方は割り当てられた立場のプレイヤーです。
渡された4ファイルすべてを読み、4案を比較したうえでレビューし、
**割り当てられた1問にだけ**簡潔に答えてください。出力先は指示されたパスとします。

**変えられないもの**（ノエラの年齢・性別・外見、叔母から舟を受け取るという始まり、
目標が 1,000万レンであること、島が4つで10日ごとに動くこと、遊びの仕組み）
**は問わせないこと。**前提をレビューに掛けても、使えない指摘しか返らない。

# 場面の条件（案が満たすこと）

## 世界の縛り（資料にもあるが、読み落とす前提で二重に書く）

- **通貨は「レン」ひとつ。**島は**ハルヴェラ・リナツィア・ノアキータ・ミフユリア**の4つ
- **四季という観念がない。**季節の名前を出さない
- **異種族はいない。戦争はない。**武器そのものは在ってよいが、軍のための装備は出さない
- **魔法はある。ただし仕組みも出どころも説明しない**（猫がしゃべる程度に留める）
- **明るく、穏やか。**喪失・自己犠牲・対立・敵役が主題にならないこと
- **外洋や、この四島の外という概念を持たない**
- **新しい造語を作らない。**すでにある言葉で書く

## 人物の縛り

| | |
|---|---|
| **ノエラ・キア**（主人公・21歳・女性） | 見立てを声に出す癖がある。一人称は「自分」。定期船で荷札と行き先の照合をしていた |
| **テレナ・キア**（叔母・48歳） | **褒めも感想も足さず、事実だけを渡す。**航路が縮んだので自分は船を降りた。**敵ではない** |
| **ネム**（猫） | **必要なことしか言わない。**観察好きで、自分のペースを崩さない |
| **イゼル**（航路・荷預かり係・47歳） | 几帳面で公平。**断る人ではなく、払えば預かり荷を降ろす窓口。敵役にしない** |

**使える顔絵は `noela` `terena` `nem` `izel` `rene` `sadi` `korna` `orv` `baren` の9つ。**
**新しい人物を出さないこと**（絵が無い）。

## 書き方の縛り

- **はじまりの場面・終わりの場面の台詞は、1行が全角29字まで。**折り返しは自分で `\n` を入れる
- **案内の台詞は、1行が全角24字まで**
- **画面に出てこない言葉を使わない。**`グリッド` `¥` `クリック` `ドラッグ` `ボタン` は使わない
- **はじまりの場面では、操作の説明をしない。**操作は案内の担当

## 必ず答えること（2つ）

1. **舟を渡されただけの人が、1,000万レンぶん働き続ける理由は、はじまりの場面のどの段に置かれているか。**
   ——これが置かれていない案は、遊んでいる途中で「なぜ続けるのか」が消える
2. **はじまりの場面を飛ばした人は、①〜③をどこで拾えるか。**
   ——飛ばす口は画面に在る。飛ばした人が詰まる案は採れない

# レビュアー4人と、それぞれの問い

「面白いか」を聞くと全員「いいと思います」で終わる。**1人1問に限定する。**

| レビュアー | 問い |
|---|---|
| **配置パズル好き**（Backpack Hero / Unpacking / Save Room 系） | **場面が邪魔になっていないか。**読まされる量に見合うものが返ってきているか |
| **経営シム好き**（効率重視） | **場面が、数字の目標（1,000万レン）を意味のあるものにしているか。**それともただの区切りか |
| **キャラ物語好き**（Recettear / あつ森 系） | **終わりの場面で、ノエラが喜んでいるのが伝わるか。**はじまりで仕込んだものが、そこで返っているか |
| **初見・カジュアル** | **説明なしで意味が取れるか。**案内の6段を読んで、何をすればいいか分かるか |
