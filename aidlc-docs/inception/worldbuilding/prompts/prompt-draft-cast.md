# 主人公以外の人物を起こす — 検討依頼

店舟を舞台にした配置パズル＋経営シムの、**主人公以外の人物一式**（伯母・権限の持ち主・猫・
行商人・各島の商人4人・客の類型）を起こしてほしい。

**このファイルだけで判断できるように書いてある。他の資料やファイルを読む必要はない。**

---

# 0. 進め方

**サブセッションを4つ開ける環境なら、**4つ開いて §3 の方向 A〜D を1つずつ割り当て、
**互いの案を読ませずに**1セッション1案を書かせること。そのあと別に4つ開いて §7 のレビューを書かせる。

**サブセッションを開けない環境なら、**A→B→C→D の順に4案を続けて書き、そのあとで §7 の
レビュー4件を書くこと。**先に書いた案に引きずられないよう、方向ごとに導出をやり直すこと。**

**出力はファイルに書かず、下記の見出しでチャットに出すこと**（ユーザが保存する）。

```
## 案A / ## 案B / ## 案C / ## 案D
## レビュー（配置パズル好き）/（経営シム好き）/（キャラ物語好き）/（初見カジュアル）
```

**選定はユーザが行う。**どれが良いかの推薦は最後に1〜2行で足すに留め、案を絞らないこと。

---

# 1. 前提 — 世界（変更不可）

レンティアは、気候の違う**四つの島**と、それを結ぶ穏やかな海でできた世界。
島同士は陸路で繋がらず、人も荷も船で動く。

| 島 | 気候 |
|---|---|
| ハルヴェラ島 | 温暖 |
| リナツィア島 | 陽が強く、暑い |
| ノアキータ島 | 実りが絶えない |
| ミフユリア島 | 雪が絶えない |

- 島の気候はそれぞれ変わらない。**採れるものが島ごとにまるで違う**
- 通貨は世界じゅうで「レン」ひとつ
- 魔法・異種族・戦争はない。外洋や「四島の外」という概念を持たない
- **この世界に四季という観念はない。**「春島」のような呼び名も存在しない
- 調子は明るく穏やか。**喪失・自己犠牲・対立・敵役が主題になることはない**
- 設定用語は「**取り合わせ**」ひとつだけ（隣り合わせに納めると値が上がる品の組み合わせ）

## ゲームの作り

店舟〈ペルラ号〉で四島を10日ごとに移りながら商う。店の名前は船の名前と同じ。

- **店＝船倉。**接岸すると船の横腹が開き、荷を納めた船倉が**そのまま**売り場になる。客は桟橋に立ったまま買う
- **どんな商品でも手に入る理由＝気候の違う島を順に巡るから。**ひと巡りで世界の素材がひと通り船倉に納まる
- 主人公がするのは品を納めることだけ。**造作の仕事は発生しない**（棚を組む・船を改造する工程は存在しない）

〈ペルラ号〉は**まだ定期航路の一隻**で、主人公にとっては借り物。縛りが二つある。

| 縛り | 内容 | 外れ方 |
|---|---|---|
| 移動 | 10日ごとに決められた順でしか島を回れない | 船倉をひと通り空けたあと、**舟を買い取ると航路が自分の裁量になる** |
| 広さ | 船倉は預かり荷に占められ、売り場は入口近くの一角だけ | 金を払って**預かり契約を一区画ぶん降りる**と、空いた区画がそのまま売り場になる |

稼いだ金は「売り場の広さ」と「航路を決める自由」の2つにしか化けない。

# 2. 前提 — 主人公（確定・作り直さないこと）

**ノエラ・キア**（のえら・きあ）／21歳・女性。

## 深層要求
> **「自分が持ってきたものが、その土地で喜ばれる瞬間を作り続けたい。」**

| 層 | 内容 |
|---|---|
| 深層要求（求めているもの） | 喜ばれること |
| **ゲーム上の信号**（それが起きたと分かる形） | 受け取られたこと＝**売れたこと** |

## 人物
- **判断の癖**：迷ったときは「この品は、どの土地へ持っていくと一番“持ってきた甲斐”が出るか」を考える。
  目先の売れやすさだけでなく、品と土地の組み合わせがしっくり来ることを大事にする
- **性格（表層）＝見立て好き**：品を見ると、値段より先に「どこへ持っていったら映えるか」を考える。
  人に強く勧めるというより、いくつか比べてから「自分ならこっちかな」と、自分なりの収まりのよさを決めたがる
- **一人称は「自分」**：「自分は、こっちかな。これ、あそこに持っていったほうが面白そう」
- **定期船での持ち場**：荷札と行き先の照合。どの荷がどこへ向かうのかを見比べ続ける仕事を苦にせず、
  「これはここへ行くのか」と行き先の違いそのものを面白がっていた
- **外見**：肩より少し長い髪を、その日の服との収まりを見ながら低くまとめたり片側へ流したりする。
  船上で動きやすい短めの上着と細身のズボン。襟元や髪留め、靴との合わせ方に少しこだわりがある
- **開始5分で伝わること**：品を見るたびに「これはどの島へ持っていったら一番喜ばれるだろう」と
  考えてしまう、組み合わせを見立てるのが好きな人

## char.md に既に書かれていること（**噛み合わせること**）
- **伯母との関係**：伯母が経験で決めることに対して「どうしてそっち？」と理由を知りたがる。
  答えを聞けば素直に納得するが、自分でも別の組み合わせを考えてみる
- **猫との距離**：猫の意見もひとつの見立てとして普通に聞くが、
  「それもあり。でも自分はこっちかな」と最後は自分で決める
- **舟を引き取る理由**：別の島の品をその土地へ持っていく営みを、自分で続けるため

## 会話イベントの扱い（**この案の合否に直結する**）
主人公の充足は「**品を仕入れる → 舟で移動する → 並べる → 売れる**」の通常ループだけで満たされる。
「よそから持ってきたものが、ここでは喜ばれた」は**売れたこと自体が示す**ので、確かめに行く必要がない。

**ただし「会話が不要」という意味ではない。**桟橋の客の一言、猫との掛け合い、
伯母や行商人との折々のやり取りは、**人物を出すために必要**であり歓迎する。

> **判定：その会話を飛ばしたとき、主人公の動機が満たされないままになるか。**
> なるなら**義務**（不可・配置パズルの手が周期的に止まる）、ならないなら**任意**（可）。

# 3. 依頼 — 軸と4方向

> **軸は「周囲が、主人公の『喜ばれたい』に何を返すか」。**
> 1本の軸として、**6役すべてに一貫して適用すること。**

- **A: 喜びを声にする**
  客も商人も猫も、受け取ったことを言葉で返す。充足の信号が厚くなる方向。
  **この方向は「飛ばせない会話」が最も生まれやすい。**必答2で正面から潰すこと。
- **B: 淡々と取引する**
  反応は売れたという事実に任せ、人は世界の手触りに徹する。言葉で喜びを返さない方向。
  **寂しくなりすぎないこと。**人物が居る意味が消えると案として成立しない。
- **C: 見立てを競う**
  主人公の「どこへ持っていくか」に、周囲が別の見立てをぶつける方向。
  **対立にしないこと。**この世界に敵役はいない。
- **D: 来歴を映す**
  定期船時代の主人公を知っている人が多く、いまの主人公の変化が周りの反応に映る方向。
  **過去を語らせないこと。**思い出話で説明するのではなく、扱いの違いで見せる。

**各人物の「主人公に返すもの」は、担当方向から導くこと。**
人物を先に決めて、あとから返し方を貼り付けないこと。

**名前と外見だけは軸から導かない。**これらは確定事項「覚えるべきは主人公だけ」から導く。
名前を一つも覚えていなくてもプレイに支障が出ないこと。

# 4. 各人物の確定事項（変更不可）

**覚えるべきは主人公だけ。** それ以外は世界の色付けであり、**名前を思い出せなくてもプレイに支障が出ない。**

| 人物 | 決めること | 縛り |
|---|---|---|
| **伯母**（船の元の持ち主） | 名前・外見・船を主人公に渡す理由 | 定期船の船主だったが航路縮小で船を降りた。**敵ではない** |
| **権限の持ち主** | 役割名・外見・払う側から見た印象 | 航路と預かり荷を差配する。**伯母とは別人。敵役にしない。**断る人ではなく、払えば荷を引き取る窓口。画面上は「航路を決める人」のような**役割名で通じること** |
| **猫** | 名前・外見・喋り方 | 船に住みついていて主人公と話す。**特別な存在であることを掘り下げない。**世界に不思議を増やさない |
| **行商人** | 名前・外見・扱う品の傾向 | 1日1回ほど船に来て売る。**取扱いは最大10種類・各最大10個。**行商人だけで品揃えが完成すると、島を巡る必要がなくなり世界の前提が崩れる |
| **各島の商人**（4人） | 名前・外見・島ごとの扱い品の方向 | 寄港中の仕入れ相手。**島の気候から導く。**品目リストまでは詰めない |
| **客の類型** | 3〜5種の類型 | 桟橋の不特定多数。**個人を作らない。特定の常連に物語を駆動させない** |

## 禁止事項

- **四季・季節名を出さないこと**
- 新しい固有名詞・設定用語を足さないこと（「取り合わせ」以外を作らない）
- 魔法・異種族・外洋・四島の外を出さないこと
- **重い・暗い方向にしないこと。**喪失・自己犠牲・対立・敵役を動機にしない
- 造作の仕事・新しい道具・新しい作業を発明しないこと
- **ストーリーを書かないこと。**人物の設定だけを出す
- **主人公を作り直さないこと**
- 名前は世界の音（ハルヴェラ／リナツィア／ノアキータ／ミフユリア／ペルラ／レン／ノエラ）に合っていること

---

# 5. 必ず答えること（2つ）

1. **名前を一つも覚えないまま遊べるか。**
   確定事項の中心がここ。答えられない案は、覚えることを要求している。
2. **会話を飛ばしても、主人公の動機は満たされるか。**
   主人公の充足は「売れたこと」で示される設計。周囲の会話が**飛ばせない**と、
   配置パズルの手が周期的に止まる。**会話があること自体は歓迎だが、無くても動機が満たされること。**

## 4案を書き終えたら — 自分で衝突チェック

下記3項目を横並びにし、**2案以上が同じものを選んでいたら、その案を書き直すこと。**

| 項目 | 衝突とみなす条件 |
|---|---|
| 伯母が船を渡す理由 | 同じ理由。言い回しの差し替えは割れたことにならない |
| 猫の喋り方 | 同じ調子（例: 全案が「〜だにゃ」系、全案が達観した年寄り口調） |
| 客の類型 | 3種以上が同じ切り口（例: 全案が「急ぎの人／目利き／冷やかし」） |

書き直すときは、**担当方向から導き直して別のものにするか、
その方向でなければ書けない理由に書き直すか、どちらか**にすること。

# 7. レビュー — 4人、それぞれ1問

4案すべてを見比べたうえで、**下記4人ぶんを別々に書くこと。**

「魅力的か」を聞くと全員「いいと思います」で終わるので、**1人1問に限定する。**
**変えられないものは問わせないこと**（§1 の世界の確定事項／§2 の主人公／ゲーム機構／
覚えさせない前提／行商人の10種×10個の上限）。

| レビュアー | 問い |
|---|---|
| **配置パズル好き**（Backpack Hero / Unpacking / Save Room 系） | この人物群が**品を納める手を止めていないか**。読まされる量は許容範囲か |
| **経営シム好き**（効率重視） | 権限の持ち主・行商人・各島の商人が、**支払い先と仕入れ先として機能しているか**。ノイズか |
| **キャラ・物語目当て**（Recettear / あつ森 系） | この人物群は**主人公ノエラを食っていないか**。かつ、覚えさせない前提のまま**世界が寂しくなっていないか** |
| **初見・カジュアル** | **名前を一つも覚えずに意味が取れるか。**誰のところへ何をしに行けばいいか分かるか |

各レビュアーは、案ごとの判定に加えて**最後に4案の順位**を付けること。1人あたり10〜15行。
