# ボタンの絵 — 8個の依頼

店舟で四つの島を巡り、船倉を売り場にして商うゲームを作っています。
**画面右下の操作板に並ぶボタンの絵**を、**8個**描いてください。

**どの環境でも同じ見た目になる、描き起こしの絵**が要ります。

---

## 1. 8個の中身

**上の5個は正方形の小さなボタンに1つずつ入ります。**
**下の3個は、横長のボタンの中で、文字の左に並びます。**

| | 何をするボタンか | 絵の中身の案 |
|---|---|---|
| 1 | **いまの状態を残す** | 帳面に書き留める、紙をはさむ |
| 2 | **残した状態を呼び出す** | 綴じた帳面をひらく |
| 3 | **売り場の並べ方を型として保存し、あとで当てる** | 升目の入った板、仕切りのある箱 |
| 4 | **設定** | 歯車、調節つまみ |
| 5 | **遊び方の案内** | 疑問の印、開いた栞 |
| 6 | **取引に行く**（仕入れ・船倉の区画を買う・納品） | 手提げの買い物かご、天秤 |
| 7 | **工房で品を作る** | 木槌、作業台 |
| 8 | **時間を進める** | 右向きの三角 |

**案はあくまで案です。**より分かりやすいものがあれば、そちらで構いません。

---

## 2. 画風

**絵本風。輪郭線は太さに強弱があり、手描きの揺れがある。色数は少なく、塗りは平坦。影はほとんど付けない。**

**すでに納品いただいた人物の絵と同じ画風でそろえてください。**

- **輪郭線は太め。**縮めて使うので、細い線は消えます
- **かたちは正面から、まっすぐ。**斜めから見た角度や奥行きは付けません
- **1個につき、ものは1つ。**小さな飾りを添えるより、ひとつのかたちを大きく取ってください

## 3. 配色

**ボタンの地は、淡い黄土色（`#ddc9a3`）・低彩度の砂色（`#d5d0c5`）・淡い藤色（`#cdbed6`）の3色です。**
**絵はその上に乗るので、どの地の上でも読める濃さで、かたちを作ってください。**
**濃い灰緑（`#303a36`）から茶（`#493d38`）のあたりが、この画面のいちばん濃い色です。**

---

## 4. 大きさと納品

- **カンバスは 8個とも 256 × 256 px。**こちらで縮めて使います
- **絵は中央に置き、周囲に 16px ほどの余白**を空けてください
- **PNG、背景は透過。1枚に1個**

**ファイル名は次のとおりにしてください。**（この名前でそのまま組み込みます）

| | ファイル名 |
|---|---|
| 1 いまの状態を残す | `save.png` |
| 2 残した状態を呼び出す | `load.png` |
| 3 売り場の型 | `preset.png` |
| 4 設定 | `options.png` |
| 5 遊び方の案内 | `help.png` |
| 6 取引に行く | `trade.png` |
| 7 工房で品を作る | `craft.png` |
| 8 時間を進める | `advance.png` |

---

## 5. 判断に使う目安

**縮めて 36px にしたとき、次の2つが成り立っていること。**

1. **何をするボタンか、絵だけで見当が付く**
2. **8個が並んだとき、互いに見分けがつく**（かたちの輪郭が似ていない）
