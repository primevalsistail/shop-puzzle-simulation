# 画面の配色を決めてください

気候の違う四つの島を、店舟で巡って商うゲームを作っています。
**画面の配色を、役割ごとに定義してほしい**という依頼です。

いまは色が一点物で 150 以上あり、役割と色が対応していません。
**少ない色数で、役割の分かる組を作り直したい**というのが目的です。

この紙だけで決められるように書いてあります。他の資料は要りません。

---

# 1. 色に関わる世界観

## 舞台

- 気候の違う**四つの島**と、それを結ぶ**穏やかな海**でできた世界。人も荷も船で動く
- 島の気候は**温暖 ／ 陽が強く暑い ／ 実りが絶えない ／ 雪が絶えない** の4つ。
  **四季という観念はなく、季節の名前も出ません**
- 通貨はひとつ。素材は**布・革・木・金属・ガラス・染料**といった身近なもの
- **調子は明るく、穏やか。**失うこと・争うこと・敵役が主題になることはありません

## ここが一番効きます — 画面が映しているのは「昼の、光の入る売り場」

**店は船倉そのものです。**接岸すると船の横腹が開き、荷を納めた船倉が**そのまま**売り場になる。
**客は桟橋に立ったまま買います。**つまり**片側が外に開いていて、昼の光が入っている場所**です。

**店が開いているのは 10:00〜20:00。**主人公が動き出すのは朝6時。
**プレイヤーが見ている時間のほとんどが日中**です。

→ **画面全体を、日中の明るさで組んでください。**

## 絵の画風（確定。ここに載せる器を作ることになります）

**絵本風。輪郭線は太さに強弱があり、手描きの揺れがある。色数は少なく、塗りは平坦。影はほとんど付けない。紙の質感。**

人物の絵はこの画風で、画面の3か所に入ります（顔絵1か所、立ち姿2か所）。

## 彩度の役割分担（世界観から来ています）

**島に暮らす人たちは、布・革・木・生成りといった素材の地色をまとっています。**
**彩度の高い色を持っているのは主人公だけ**で、そこに目が行くように作ってあります。

→ **画面の地と枠は彩度を抑え、鮮やかな色は「状態を知らせる数か所」に絞ってください。**
　 そこが空いていると、人物の絵と、知らせたい合図の両方が立ちます。

## 世界に足さないもの

- **魔法は存在しますが、画面には出しません。**光る色・紋様で魔法を示すことはしません
- 現実の国家・政党・信仰を想起させる配色の組み合わせは使いません

# 3. 定義してほしい色

**4つの組に分けています。**組の中で明度の段が付いていること、組をまたいで役割が混ざらないことを大事にしてください。

## 組A — 地（画面の面。ここが全体の印象を決めます）

| 役割 | どこに出るか |
|---|---|
| **画面の地** | いちばん奥。ほかの区画の隙間から見える |
| **区画の地** | 左の一覧、右の操作板、下のメッセージ欄。**3つとも同じ地でよいか、段を付けるかも含めて提案してください** |
| **売り場の地** | 中央の、品を並べる升目の下地。**画面でいちばん広い面**です |
| **窓の地** | 買い物や確認の窓を開いたときの面 |
| **覆いの幕** | 窓を開いたとき、背後を覆う半透明の膜（**不透明度も一緒に**） |

## 組B — 線と文字

| 役割 | どこに出るか |
|---|---|
| **枠線（強）** | 区画や窓の縁 |
| **枠線（弱）** | 区切りの横線、升目の格子 |
| **文字（本文）** | 品名、説明、ボタンの字 |
| **文字（副）** | 個数・単位・注記など、本文に添える小さい字 |
| **文字（弱）** | いま押せないもの、選べないもの |
| **文字（強調）** | 所持金の数字。**画面でいちばん大きい字**です |

## 組C — 状態の色（ここに鮮やかな色を置きます）

**升目の縁や行の地に乗って、一目で状態を知らせます。**

| 役割 | 何を知らせるか |
|---|---|
| **できる／整っている** | 買える、納品できる、ここに置ける |
| **残りわずか** | 並べた品の在庫が少ない |
| **尽きた／置けない** | 在庫ゼロ、そこには置けない |
| **選んでいる** | いま選んでいる行や升 |
| **指が乗っている** | カーソルが乗っているところ |
| **手放す** | 品を捨てる場所 |

⚠ **色みだけで分けず、明度でも差が付くようにしてください。**色の見え方には個人差があります。

## 組D — ボタン（4つの役。それぞれ **通常 ／ 指が乗った時 ／ 押せない時** の3色）

| ボタン | 何をする |
|---|---|
| **進める** | 時間を進める。**画面でいちばん大きく、いちばん押される**ボタン |
| **取引** | 品を仕入れる、納める、店を広げる。**お金が動く** |
| **工房** | 材料から品を作る。**手を動かす** |
| **戻る／取り消す** | 窓を閉じる、やめる |

**役ごとに色みを変えてください。**押す前に、何をするボタンか分かるようにしたいところです。

## 組E — 一覧と入力まわり

| 役割 | どこに出るか |
|---|---|
| **行の地：この島で採れる** | 仕入れの一覧で、**いま居る島の産**（安く買える行） |
| **行の地：どこでも買える** | 島によらず買える行 |
| **行の地：まだ買えない** | **この先の島**でしか買えない行。上の2つのどちらとも見分けが付くこと |
| **絞り込み：入 ／ 切** | 品の種類で絞るボタンと、画面上部のタブ。**地と文字の2色ずつ** |
| **入力欄** | 数量を打ち込む欄。**地・文字・枠の3色**（ここだけ作りが違うので別に要ります） |
| **スクロールつまみ** | メッセージ欄の右端。**動かせることが分かる色** |

## 組F — 品の色板（範囲の指定だけ）

品ごとに小さな色板が付いていて、**一覧に十数枚、升目に数十枚が同時に並びます。**
食料・飲物・衣類・道具などがあり、**全部で 160 種類ほど**です。

個々の色は決めなくて構いません。
**この色板が収まるべき彩度と明度の帯**を、**HSL の上下限の数字で**決めてください。組Aの地の上に並べたとき、
**品どうしが見分けられて、なおかつ組Cの合図がその上で目立つ**ことが条件です。

# 4. 返してほしい形

**表1つ**にしてください。

| 役割名 | 16進（`#rrggbb`） | どこに出るか | なぜこの色か（1行） |

⚠ **すべて `#rrggbb` の6桁で書いてください。**色名や、言葉での言い換えは添えるだけにしてください。
⚠ **ボタンは4つの役それぞれに、通常・指が乗った時・押せない時の3行**を立ててください。
⚠ **覆いの幕は、16進と一緒に不透明度（0〜1の数字）**も書いてください。

**併せて次の3つ**を、それぞれ数行で。

1. **明度の段**をどう作ったか（組Aの面が奥から手前へどう並ぶか）
2. **地と文字の組み合わせ**で、読みやすさが足りているかの確認
3. **組Cの6色が、組Aのどの地の上でも見分けられるか**の確認

# 5. 今回決めないこと

- **一日の時間帯による色の変化。**朝も昼も夜も、同じ色で通します
- **島ごとの色。**4島を色で描き分けることは、いまはしません
- **人物の絵の配色。**別に決まっています

**この3つを足したくなったら、決める前に知らせてください。**
