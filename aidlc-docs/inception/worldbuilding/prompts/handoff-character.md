# 主人公の深層要求 — 検討依頼

店舟を舞台にした配置パズル＋経営シムを作っている。
**主人公の深層要求**（何が満たされないと落ち着かないか）が決まらないので、検討をお願いしたい。

このファイルだけで判断できるように書いてある。他の資料は要らない。

---

# 1. 前提（変更不可）

## 世界
- レンティアは、気候の違う**四つの島**と、それを結ぶ穏やかな海でできた世界。島同士は陸路で繋がらず、人も荷も船で動く
- 島の気候はそれぞれ変わらない。採れるものが島ごとにまるで違う

| 島 | 気候 |
|---|---|
| ハルヴェラ島 | 温暖 |
| リナツィア島 | 陽が強く、暑い |
| ノアキータ島 | 実りが絶えない |
| ミフユリア島 | 雪が絶えない |

- 通貨は世界じゅうで「レン」ひとつ
- 魔法・異種族・戦争はない。外洋や「四島の外」という概念を持たない
- **この世界に四季という観念はない。**「春島」のような呼び名も存在しない
- 調子は明るく穏やか。**喪失・自己犠牲・対立・敵役が主題になることはない**
- 設定用語は「**取り合わせ**」ひとつだけ（隣り合わせに納めると値が上がる品の組み合わせ）

## ゲームの作り
店舟〈ペルラ号〉で四島を10日ごとに移りながら商う。店の名前は船の名前と同じ。

- **店＝船倉。**接岸すると船の横腹が開き、荷を納めた船倉が**そのまま**売り場になる。客は桟橋に立ったまま買う
- **どんな商品でも手に入る理由＝気候の違う島を順に巡るから。**ひと巡りすれば世界の素材がひと通り船倉に納まる。この一点だけで全商品の入手を説明している
- 主人公がするのは品を納めることだけ。**造作の仕事は発生しない**（棚を組む・船を改造するといった工程は存在しない）

〈ペルラ号〉は**まだ定期航路の一隻**で、主人公にとっては借り物。ここから縛りが二つ出る。

| 縛り | 内容 | 外れ方 |
|---|---|---|
| 移動 | 10日ごとに決められた順でしか島を回れない | 船倉をひと通り空けたあと、**舟を買い取ると航路が自分の裁量になる** |
| 広さ | 船倉は預かり荷に占められ、売り場は入口近くの一角だけ | 金を払って**預かり契約を一区画ぶん降りる**と、空いた区画がそのまま売り場になる |

- 船体は大きくしない。広くなるのは船倉が空くから
- 預かり荷は他人のもので、自分でどけることはできない。金の払い先は荷を差配している「権限の持ち主」（敵役ではなく、払えば引き取る窓口）
- **稼いだ金は「売り場の広さ」と「航路を決める自由」の2つにしか化けない**

## 主人公について確定していること
- **21歳の女性**
- 島を巡る**定期船に乗っていた**（船主は伯母。航路縮小で定期船が退役し、伯母も船を降りる）
- **舟を引き取る側。**買い取るまでは借り物

**なぜこの人がこの舟を持つことになったのかは未決。**思い入れでも、成り行きでも、別の理由でもよい。

---

# 2. 依頼

> **上の前提を満たす「主人公の深層要求」を提案してほしい。**

決めたいのは深層要求だけ。性格・船での役割・一人称・外見・名前はそのあとの作業なので、今回は要らない。

## 満たすべき条件（5つ同時）

1. **なぜこの人がこの舟を持つことになったのかが、プレイヤーに分かること。**その深層要求から自然に出ること
2. **開始5分で「誰が・何をしたい話か」が、説明なしで取れること**
3. **稼いだ金の2つの出口（売り場の広さ／航路を決める自由）を、本人が自分の動機のまま欲しがること**
4. **達成して終わらないこと。**買い取ったあとも店は続く。ただし主人公に「閉められない理由」を台詞で語らせて正当化しない。**動機の性質そのもので解くこと**
5. **動機の充足が、会話に依存しないこと。**（→下の「条件5の補足」を必ず読むこと）

## 条件5の補足 — 「会話が不要」という意味ではない

**会話イベントそのものは禁止ではない。歓迎する。**
このゲームにはメッセージウィンドウとキャラストリップが既に実装されており、イベント会話は計画済み。
桟橋の客の一言、猫との掛け合い、折々のやり取りは、**人物を出すために必要**。

禁じたいのは**「飛ばせない会話が周期的に発生すること」**だけ。

| | 性質 | 判定 |
|---|---|---|
| **義務の会話** | 動機の充足がそこでしか起きない。毎巡り必ず発生し、飛ばせない | **避ける。**配置パズルの手が止まる |
| **任意の会話** | 動機は通常のゲームループで満たされる。会話はその上に載る | **あってよい。むしろ要る** |

> **判定：その会話を飛ばしたとき、主人公の動機が満たされないままになるか。**
> なるなら義務（不可）、ならないなら任意（可）。

## 条件1の補足

「舟への思い入れ」で書いてもよいが、**必須ではない。**成り行きで持つことになった、でも構わない。
**設定で守りに入らないこと**（「なぜ別の舟にしないのか」といった反論を先回りして書かない）。
思い入れで書く場合のみ、その中身は**船体の性能や機能ではなく、この舟でしか起きないこと**にすること。

# 3. 禁止事項

- **四季・季節名を出さないこと**
- 新しい固有名詞・設定用語を足さないこと（「取り合わせ」以外を作らない）
- 魔法・異種族・外洋・四島の外を出さないこと
- **重い・暗い方向にしないこと。**喪失・自己犠牲・対立・敵役を動機にしない
- 造作の仕事・新しい道具・新しい作業を発明しないこと
- ストーリーを書かないこと（人物の設定だけ）
- 名前を出す場合、世界の音（ハルヴェラ／リナツィア／ノアキータ／ミフユリア／ペルラ／レン）に合っていること

判定はひとつ。

> **別の深層要求の担当者がそのまま書いても成立する答えなら、それはその深層要求から導けていない。**

---

# 4. 出力してほしい形

深層要求の案を **1〜3案**。1案につき以下。長文は要らない。

1. **深層要求**（1行）
2. **条件1〜5をどう満たすか**（各1〜2行）。特に **1と2を同時に満たす筋道**を明示すること

最後に、**条件1と2の引っ張り合いをどう崩したか**を短く。
