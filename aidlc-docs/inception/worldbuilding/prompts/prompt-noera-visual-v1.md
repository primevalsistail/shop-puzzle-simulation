## 1. 世界（これで全部。足さない）

- 気候の違う**四つの島**と、それを結ぶ穏やかな海だけでできた世界。島同士は陸路で繋がらず、人も荷も船で動く
- **魔法・異種族・戦争がない。**外洋や「四島の外」という概念もない
- ⚠ **四季という観念がない。**春夏秋冬を指す装いや小物は存在しない
- 調子は**明るく穏やか**。喪失・自己犠牲・対立・敵役が主題になることはない
- 島名・人名・船名のほかに**固有名詞を持たない世界**。看板も旗も文字もない

主人公は、気候の違う四島を**10日ごとに巡る店舟**で商いをしている。接岸すると船の横腹が開き、
荷を納めた**船倉がそのまま売り場**になる。客は桟橋に立ったまま買う。

## 2. 人物（確定事項。変えない）

| 項目 | 内容 |

| 名前・年齢 | **ノエラ・キア。21歳・女性** |

| 体つき | **鍛えた体つきにしない。ただし華奢にもしない。**船上で立ち回る人 |
| 性格 | **見立て好き。**品を見ると値段より先に「どこへ持っていったら映えるか」を考える。 人に強く勧めず、**一歩引いて見比べてから決める** |

## 4. 絵を決めている実際の制約

⚠ **この絵は最終的に 110×305 ピクセルの細い枠に表示されます。**背景は**濃紺 `#1a2a3a`**。

**縮小後に残るのは、頭の形・髪の塊・肩の線・色面だけです。**顔の描き込みは残りません。

そこから来る条件:

1. ⚠ **髪と上着の主色を、濃紺・濃緑・黒にしない**（背景に沈んで輪郭が消える）
2. ⚠ **基調2色＋差し色1色まで。**色数を増やさない
3. ⚠ **シルエットで人物が分かること。**顔に頼らない
4. ⚠ **左右反転しても破綻しないこと**（左向きを反転で作る可能性がある）

## 8. Step 3 — 三面図

**選ばれた画風＋配色**で、**正面・側面（右向き）・背面**の3面。

- ⚠ **3面とも同じ身長線・同じ目線の高さに揃える**
- **直立・腕は体側・手は開いたまま・持ち物なし**
- **表情は正面のみ、平常時1つ。**表情差分は作らない
- **髪は3面とも同じ形**（うなじで低くひとつ）
- **服は1着だけ。**重ね着・脱ぎ着・差分を作らない
- **背景は無地。影を落とさない**
