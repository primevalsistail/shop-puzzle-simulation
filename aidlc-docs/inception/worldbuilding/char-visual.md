## 1. 確定（`char.md` / `world.md` から。議論しない）

| 項目 | 内容 | 出典 |
|---|---|---|
| 年齢・性別 | **21歳・女性** | `world.md` §4 |
| 体つき | **荷役ではない。**定期船で荷札と行き先を照合する持ち場だった。**鍛えた体つきにしない**が、船上で立ち回る人なので華奢にもしない | `char.md`「船での役割」 |
| 髪の長さ | **肩より少し長い** | `char.md`「外見」 |
| 上半身 | **船上で動きやすい短めの上着** | 同上 |
| 下半身 | **細身のズボン** | 同上 |
| こだわりの置き場所 | **襟元・髪留め・靴**の3点。⚠ **ここ以外に飾りを足さない** | 同上（「襟元や髪留め、靴との合わせ方には少しこだわりがあり」） |
| 全体の印象 | **高価なものを着ていない。実用的なのに、どこか可愛くまとまっている** | 同上 |
| 表情の質 | 穏やか。**押し出さない。**一歩引いて見比べる人 | `char.md`「一人称・喋り方」 |

### こだわり3点が差し色である理由

char.md は**服そのもの**ではなく「**合わせ方**」にこだわると書いている。
だから高価な服でも派手な服でもなく、**基調は地味なまま、襟元・髪留め・靴に同じ1色を置く**形になる。
**3点が同じ色で揃っていること**が「組み合わせを気にする人」の記号になり、
表層の**見立て好き**（`char.md`）がそのまま外見に出る。

⚠ **色を3点でバラバラにしないこと。**バラバラは「こだわり」ではなく「無頓着」に見える。

## 2. 世界の縛りから来る禁止事項

⚠ **依頼文に明記する。**書かないと画像生成の既定値（ファンタジー風の少女）が出る。

| 禁止 | 理由 |
|---|---|
| **武器・魔法具・魔法陣・光る意匠** | 魔法・戦争が無い世界（`world.md` §1） |
| **衣服の紋章・ロゴ・文字・数字** | 固有名詞を持たない世界（`world.md` §7）。**看板も旗も無い** |
| **季節記号**（マフラー・厚手のコート・薄着の夏服など、季節を指す装い） | **四季という観念が無い**（`world.md`）。⚠ **10日ごとに温暖・酷暑・豊穣・雪の島を回るので、季節物は世界の前提と衝突する** |
| **すさんだ／重い意匠**（傷・血・暗い目つき・破れた服） | 喪失・対立・敵役が主題にならない（`world.md`） |
| **船乗りの制服・階級章** | 主人公は借り物の舟を預かった個人であり、組織に属していない（`world.md` §5） |
| **工具・エプロン・作業用の道具** | ⚠ **造作の仕事が発生しない**（`world.md` §2）。棚を組む人ではない |
| **過度な露出／媚びた仕草** | 調子が「明るく、穏やか」（`world.md`）。**開始5分で伝えるのは「見立てるのが好きな人」**（`char.md`） |

## 3. 実装から来る条件（出典＝コード）

| 条件 | 数値 | 出典 |
|---|---|---|
| 画面 | **1280×720 固定** | `GameEngine.ts` |
| キャラ帯 | 左端 **980**、幅 **110**、高さ **610**。**店番は上半分＝ 110×305** | `src/ui/layout.ts:20-22` |
| 店番エリアの地色 | **`0x1a2a3a`（濃紺）**／枠線 `0x2a4a6a` | `src/ui/CharacterStrip.ts` |
| 来店客エリアの地色 | `0x1a3a2a`（濃緑）。**50px 間隔で縦に並ぶ** | 同上 |

### そこから導かれる条件

1. ⚠ **髪と上着の主色を、濃紺・濃緑・黒にしない。**地色に沈んで輪郭が消える
2. **色数を絞る。**基調2色＋差し色1色。**110px 幅では柄・細い縁取り・小さな模様は消える**
3. ⚠ **シルエットで識別できること。**顔の描き込みに頼らない。
   縮小後に残るのは**頭の形・髪の塊・肩の線・色面**だけ
4. ⚠ **左右反転しても破綻しないこと。**SD やスプライトで左向きを作る可能性がある

## 4. 髪色 —— 空いている帯は1つしかない

**他7人の髪色は `characters.md` で既に割り当て済み。**

| 人物 | 髪 |
|---|---|
| 伯母 テレナ | 濃い灰色・短い |
| 航路・荷預かり係 | 黒・横に撫でつけ |
| 行商人 バレン | 栗色・癖毛 |
| レネ（ハルヴェラ） | 長い黒髪 |
| サディ（リナツィア） | 短い赤茶 |
| コルナ（ノアキータ） | 焦茶の巻き髪 |
| フィエラ（ミフユリア） | 白に近い・肩で切る |

埋まっているのは **黒／濃い灰／栗／赤茶／焦茶／白に近い**。
**濃紺の地色に沈まず、かつこの6色と被らない帯は「明るい金茶〜亜麻」しか残っていない。**

しかもこれは**「覚えるべきは主人公だけ」**（`world.md` §6）と噛み合う。
他7人が濃色に寄っているなかで**主人公だけが明るい塊**になり、110px に縮小しても一目で分かる。

→ **main の推奨は「亜麻〜明るい金茶」。**PO 判断 Q3 で確認する。

## 6. 三面図の出力仕様（技術判断。main が決めた）

| 項目 | 仕様 | 理由 |
|---|---|---|
| 面 | **正面・側面（右向き）・背面**の3面 | 側面が無いと上着の丈と髪の厚みが決まらない |
| 位置合わせ | **3面とも同じ身長線・同じ目線の高さに揃える** | 照合に使う図なので、ずれていると基準にならない |
| ポーズ | **直立。腕は体側。手は開いたまま。持ち物なし** | ⚠ **SD と全差分の基準になる。**癖のある姿勢を基準にすると派生のたびに癖が増幅する |
| 表情 | **正面のみ、平常時1つ。**差分は作らない | 何枚要るかは #24 が決まるまで確定しない |
| 髪 | **基準形（Q2）に固定。3面とも同じ** | 同上 |
| 服 | **1着だけ。**脱ぎ着・重ね着・差分を作らない | 四季が無い世界（§2） |
| 背景 | **無地。影を落とさない** | 切り抜きと照合のため |
| 納品 | **各面を個別ファイル／PNG／短辺 1024px 以上** | 表示は 110×305 だが **#10（解像度）が未決。**⚠ **縮小はできるが拡大はできない** |
