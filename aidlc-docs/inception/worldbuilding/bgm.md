## 1. 8曲の一覧

**1日は 朝 → 昼 → 夜 の3つに分かれていて、昼だけ島ごとに変わる。**

| # | 曲 | 鳴るところ | 等倍での長さ | どんな曲を探すか |
|---|---|---|---|---|
| 1 | **タイトル** | タイトル画面 ＋ はじまりの場面 | 押すまで（不定） | **静か。これから始まる感じ。**主張しすぎない |
| 2 | **朝** | 6:00〜10:00（店を開ける前の支度） | **24秒** | **起き抜け。**音数が少なく、動き出す前の落ち着き。⚠ **頭8秒で「朝だ」と分かること** |
| 3 | **昼・ハルヴェラ**（温暖） | 10:00〜20:00・この島に居る10日 | **60秒** | **基準の島。**いちばん癖がなく、長く聞ける |
| 4 | **昼・リナツィア**（暑い） | 同上 | **60秒** | **陽が強い。**乾いた音、明るい |
| 5 | **昼・ノアキータ**（実り） | 同上 | **60秒** | **豊か。**厚みがあって、いちばん賑やか |
| 6 | **昼・ミフユリア**（雪） | 同上 | **60秒** | **雪が絶えない。**音数が少なく、澄んでいる |
| 7 | **夜** | 20:00〜24:00（店を閉めたあとの手仕事） | **24秒** | **店じまい。**朝と同じ静かさだが、こちらは終わりの側 |
| 8 | **エンディング** | 商船（1,000万レン）を買った幕 | 60秒前後 | **借り物の舟が自分の店になった。**⚠ **1回しか鳴らない** |

⚠ **24:00 から 6:00（睡眠）には曲が要らない。**時計がそこに留まらず、**24:00 に達した瞬間 6:00 へ飛ぶ**（`TimeManager`）。

⚠ **昼の4曲は、同じ人が作った4曲に聞こえること。**
バラバラの出どころから選ぶと、**島が変わるたびに別のゲームになる。**
**同じ配布元の同じシリーズから4本取る**のがいちばん確実。

⚠ **そのうえで、4曲はテンポと楽器ではっきり別物であること**（ペルソナ評価）。
**同じ手つきで、聞き分けられる4曲。**どちらか片方だけだと、
**「別のゲーム」になるか、「10日ごとに替わったことに気づかない」かのどちらかに倒れる。**

## 2. 素材に要る条件

- **ループできること。**⚠ **繋ぎ目で音が切れる素材を選ばない**（60秒を何十回も繰り返す）
- ⚠ **昼の4曲は 2分以上**（ペルソナ評価。**曲数より、ここの長さのほうが効く** ——
  **30秒ループだと、等倍では同じ30秒を18分間ぶっ通しで聞くことになる**）
- ⚠ **朝と夜は「24秒のループ」として選ぶ。****2分の曲の頭24秒**ではない。
  **等倍でも24秒しか鳴らない**ので、**立ち上がりに8秒かける曲だと盛り上がる前に昼になる**
- **1曲 1〜2MB 目安**（`ogg` ＋ `m4a` の2本。ogg だけだと Safari で鳴らない）
- ⚠ **商用利用可のもの**（PO 判断 2026-09-15）。**クレジット表記が要るものは可。**
  ⚠ **「個人利用のみ」は選ばない** —— 後で公開・販売することになったら**8曲すべて差し替え**になる
- ⚠ **配布元を出す場所が要る。**→ §4 の「表記の置き場」
- ⚠ **歌声の入っていないもの。**この世界の言葉が決まっていないので、歌詞が入ると世界の外の言葉が混ざる

## 3. 曲の替わりかた

**決定 2026-09-15**（PO が[ペルソナ4人に検討させた](../design-log/bgm-persona-review.md)結果）。

| いつ | どうする |
|---|---|
| **朝 → 昼 → 夜** | **1秒ほどかけて前の曲から次へ。**⚠ **等倍のときだけ**（下の「速さ」） |
| **速さが 3倍・10倍のとき** | ⚠ **朝と夜の曲を出さない。その島の昼の曲で通す** |
| **島が変わる朝** | **昼の曲が別の島のものに替わる。**板が開く演出（0.4秒）と同じ朝 |
| **できごとの窓が出たとき** | ⚠ **止めない。**窓は選択肢があるときだけ出て、すぐ閉じる |
| ⚠ **時計が止まっているとき** | → [questions-bgm.md](../../sessions/questions-bgm.md) の Question 6（**PO 判断待ち**）。⚠ **遊んでいる時間の大半がここ** |
| **クリア後（自由航行）** | ⚠ **島の曲のまま。**居る場所は島なので専用曲は要らない |

### ⚠ 速さを見るのは「区分が始まる瞬間」だけ

⚠ **速さは1日の中で何度も変わる。****4人とも、朝と昼と夜で別々の速さにすると答えた**
（向きは人によって逆で、**朝を等倍にして昼を飛ばす**人と、**朝夜を飛ばして昼を等倍**にする人がいた）。
→ ⚠ **「3倍で遊んでいる日」という単位は存在しない。**速さで曲を決める書き方をするなら、
**日ではなく区分ごとに見るしかない。**

- ⚠ **朝・昼・夜が始まる瞬間の速さだけを見て、その区分の曲を決める**
- ⚠ **区分の途中で速さを変えても、鳴っている曲は替えない。**次の区分の頭から効く
- ⚠ **昼の曲は再生位置を保つ。**朝夜の曲が**その上に乗り降りするだけ**で、
  **頭から鳴らし直さない**

**この3つが無いと A は選ばない、と3人が別々に書いた。**
**自分が押したせいで曲が切れると「操作が音楽を壊した」と感じる**（やりこみ層）、
**3回起きたら音を切る**（経営シム好き）。

### ⚠ この決定には反対が1人いる（記録）

**やりこみ層は「3倍までは朝夜を鳴らし、10倍だけ昼で通す」を推した。**
理由は **「速くするのはまさに朝と夜なので、A だと8曲のうち2曲を誰も聴かない場所に置くことになる」。**
**A を選んだカジュアル層も、同じ心配を「上達が罰になる」と書いている。**

→ ⚠ **朝と夜の曲が効くのは、序盤と、等倍に落とした日だけ。**そこに賭ける曲を選ぶこと。
→ ⚠ **後で「朝夜の曲が聞かれない」が実際に問題になったら、最初に戻る場所がここ。**

⚠ **速さを変えても曲の速さは変えない。**速さは「眺めるか流すか」の選択であって、
**世界の時間が速くなったわけではない。**

## 4. 置き場と、実装のときの決まり

- **原本は `audio/`、`public/audio/` は写し。**⚠ **絵と同じ形**（原本 `art/button-icons/` → `public/art/icon/`）。**逆をしない**
- **設定（⚙️）に「音楽を鳴らす」を1行足す。**⚠ **音量つまみは作らない**（いまの設定に**つまみという部品が無い**）
- **表記の置き場**: **設定（⚙️）の面のいちばん下に、配布元を並べる。**
  ⚠ **タイトル画面には出さない**（タイトルは題名と顔と3つのボタンで収まっており、字を足すと窮屈になる）。
  ⚠ **効果音（#124）も同じ場所に足せる形にしておく**
- ⚠ **ブラウザは、プレイヤーが1回押すまで音を鳴らさない。**
  **タイトル画面のボタンが最初の一押し**なので、**タイトルを開いた直後は無音で、押した瞬間から鳴り始める。不具合ではない**
