# メインセッション
サブセッションを4つ開き、以下の世界観の案をテンプレートに沿って出させてください。
各サブセッションについては以下の方向性と出力先を明示して検討させてください。
（軸は「どんな商品でも手に入るのを、どう正当化するか」。担当方向から外れないこと）
- A: 交易地。定住の店。現実の国・時代をモデルにしてよい
     → aidlc-docs/inception/worldbuilding/case-a.md
- B: ファンタジー。魔法・異種族・迷宮産の品などを扱ってもよい
     → aidlc-docs/inception/worldbuilding/case-b.md
- C: 移動する店。行商の馬車・船・キャラバンなど。行った先の品が入る
     → aidlc-docs/inception/worldbuilding/case-c.md
- D: 近未来・SF。軌道港・物流網の結節点など
     → aidlc-docs/inception/worldbuilding/case-d.md

その後、別のサブセッションを4つ開き、**上記4ファイルすべてを読ませて**、
以下のレビュアーに4案を比較させたうえで簡潔にレビューさせてください。
出力先は aidlc-docs/inception/worldbuilding/ 配下の以下とします。
- 配置パズル好き → review-puzzle.md
- 経営シム好き   → review-sim.md
- キャラ物語好き → review-story.md
- 初見カジュアル → review-casual.md

レビューが揃ったら結果をまとめて提示してください。
**ユーザが1案を選定したのち**、別のサブセッションを開き、
選ばれた案のmdファイルのみを渡してストーリーを書かせてください。

# サブセッション
貴方は優秀な世界観設定者です。
以下の世界観条件を満たす世界観を構築してください。
出した世界観案をmdファイルに出力してください。
出力先は指示されたパスとし、ファイル名を自分で決めないこと。

# ユーザセッション
貴方はゲームのプレイヤーです。
渡された4ファイルすべてを読み、4案を比較したうえで世界観をレビューし、
簡潔な感想を述べてください。出力先は指示されたパスとします。

# ストーリーセッション
貴方は優秀な脚本家です。
渡された世界観案に沿ってストーリーを書いてください。

# 世界観条件
- このゲームは店舗運営ゲームです。商品を購入、作成し、店舗に並べ販売することで利益を出すことを目的としています。
- 主人公は20～25の女性としてください。
- 重い、暗い世界観としないこと。
- ストーリーをこの段階で書かないこと。
- 特定顧客はいないゲームです。BtoCを前提としてください。
- 似た用語を定義しないこと

## 1段目の出力テンプレート（散文禁止・各項目2〜3行）

```markdown
## 世界・国
（2〜3行）
理由:（1行）

## 舞台・町の名前
（2〜3行。どんな商品でも手に入る理由を含める）
理由:（1行）

## 主人公の名前・職業
（1行。国名から想像できる名前であること。店舗を経営しつつ商品を作成する人間の前職として世界観と違和感ないこと）

## 主人公の目的
（2〜3行。ゲーム開始時の所持金は¥50000程度。所持金を貯めることで何をしたいのか。過程と矛盾しないこと。店を運用するうえで貯められる金額を目標とし、**目標金額も案の中で提示すること**）
理由:（1行）
目標金額:（1行）

## 店舗を手に入れる過程
（2〜3行。オープニングで語れる長さ。目的と矛盾しないこと）

## 扱う商品の例
（1行。代表的な品を3〜5個。素材と完成品を混ぜる）

## 隣接ボーナスの用語
（1行。不要なら「用語を作らない」と書く）
```

# レビュアー4人と、それぞれの問い

「面白いか」を聞くと全員「いいと思います」で終わる。1人1問に限定する。
**変えられないもの（主人公の年齢・性別、ゲーム機構）は問わせないこと。**
変えられない前提をレビューに掛けても、使えない指摘しか返らない。

| レビュアー | 問い |
|---|---|
| 配置パズル好き（Backpack Hero / Unpacking / Save Room 系） | 世界観が**邪魔になっていないか**。読まされる量は許容範囲か |
| 経営シム好き（効率重視） | 世界観が**数字の理解を助けているか**。ノイズか |
| キャラ・物語目当て（Recettear / あつ森 系） | 主人公に**魅力があるか**。 |
| 初見・カジュアル | **説明なしで意味が取れるか**。造語で詰まらないか |
