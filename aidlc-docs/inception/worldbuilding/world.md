# 世界観 — 気候の違う島を巡る店舟

**この文書が世界観の単一の情報源。**
検討の経緯（4案の比較と4観点のプレイヤーレビュー）は12章に要約済みで、元資料は削除した。

> **注意**: 以前ストーリーを書いたが、**キャラクターより先に書いてしまったため削除した。**
> 主人公の性格をそこから起こすと汚染されるので、**この文書には当時の記述を一切含めていない。**
> 主人公は本書の情報だけから起こすこと。

---

## 1. 世界

レンティアは、気候の違う四つの島と、それを結ぶ穏やかな海でできた世界。
島同士は陸路で繋がらず、人も荷も船で動くのが当たり前になっている。

- 島の気候はそれぞれ変わらない。花の絶えない島も、雪の絶えない島もあり、採れるものがまるで揃わない
- 通貨は世界じゅうで「レン」ひとつ。**両替の概念を作らないため**
- 魔法・異種族・戦争はない。外洋やこの四島の外という概念も持たない

### 四季について（重要）
**この世界に四季という観念はなく、「春島」のような呼び名も存在しない。**
名前の音と島の気候から、プレイヤーが勝手に季節を感じ取るだけ。作中でも画面でも季節名を出さないこと。

| 島 | 気候・産物の方向 |
|---|---|
| ハルヴェラ島 | 花が絶えない。ぶどう |
| リナツィア島 | 陽が強い。織物 |
| ノアキータ島 | 実りの季。材木 |
| ミフユリア島 | 雪が絶えない。消費地 |

※産物の割り当ては暫定。確定は [Issue #3](https://github.com/primevalsistail/shop-puzzle-simulation/issues/3)

## 2. 舞台と店

舞台は、四島を10日ごとに移りながら商う**店舟〈ペルラ号〉**。

- **店＝船倉。** 接岸すると船の横腹が開き、船倉に組んだ棚がそのまま売り場になる
- 客は桟橋に立ったまま買う。**船に乗り込ませない**
- 島ごとに採れるものが違うので、ひと巡りすればこの世界の品がひと通り棚に並ぶ
- 店の名前は船の名前と同じ。**覚える固有名詞を増やさないため**

### 「どんな商品でも手に入る」の正当化
**気候の違う島を順に巡るから。** この一点だけで全商品の入手を説明する。
この前提を崩す要素を足さないこと（→ 6章の行商人の制約）。

---

## 3. 二つの縛りと、その外れ方

借り物の〈ペルラ号〉は**まだ定期航路の一隻**。ここから縛りが二つ出る。

| 縛り | 内容 | プレイヤーへの見え方 |
|---|---|---|
| 移動 | 10日ごとに決められた順でしか島を回れない | 行き先を選べない |
| 広さ | 船倉は預かり荷に占められ、売り場は入口近くの一角だけ | 棚が狭い（6×5から開始） |

- 稼いだ金で**船倉を片付ける**と売り場が広がる（船体は大きくしない）
- **舟を買い取ると、二つの縛りが同時に外れる**。航路も船倉も自分の裁量になる
- 買うのは船体ではなく**航路を自分で決める自由**

## 4. 主人公

**唯一、プレイヤーに覚えてもらう人物。**

### 確定していること
- 23歳の女性
- 島を巡る定期船で**船員の食事をこしらえていた元船乗り**（仕入れと加工の両方ができる前職）
- 舟を引き取る側。**この舟に思い入れがあって引き取る**
- 名前は「ミラ・レンツィ」（変更可。世界の音に合っていることが条件）

### 未決 — ここを起こすのが次の作業
- **性格。** 抽象的な美点（「魅力がある」等）ではなく、**書き手が場面を書ける行動レベル**で定義すること
- 一人称
- 外見

### 性格を起こすときの手がかり
- 100万レン貯まった時点で「もっと良い舟を買えばいい」と言われる。**この舟でなければならない理由**が要る
- プレイヤーレビュー（キャラ物語観点）が求めたのは **「この人が店を閉められない理由」**
- 前職と「作って売る」行為が結びついていて、手つきが想像できること

## 5. 目的

借り物の〈ペルラ号〉を買い取り、自分の店として造り替えること。

- 開始所持金 **50,000レン**（棚を組んで初荷を積めば消える額）
- **目標 1,000,000レン**（舟の買い取りと、店として造り替える改装）
- 判定は**所持金**。累計売上ではない（→ [Issue #7](https://github.com/primevalsistail/shop-puzzle-simulation/issues/7)）
- 稼いだ金は「売り場の広さ」と「航路を決める自由」に変わる。**日々の営業と目的が一直線につながる**

### 店を手に入れる過程（オープニングで語る長さ）
乗っていた定期船が航路縮小で退役し、船主だった伯母も船を降りる。
使い道のなくなった小型の荷舟を「稼げたら買い取る」という口約束ひとつで預かる。
ただし舟はまだ定期航路の一隻で、10日ごとに動く決まりと、預かり荷で埋まった船倉がついてくる。

## 6. 必要な登場人物

**プレイヤーが覚えるべきは主人公だけ。** それ以外は世界の色付けであり、記憶に脳を割かせない。
名前と外見は与えるが、覚えていなくてもプレイに支障が出ないこと。

| 役割 | 要件 |
|---|---|
| **船の元の持ち主** | 主人公と関係がある。敵ではない。**船を渡す理由が必要** |
| **権限の持ち主** | 航路や複数の船に対する権限を持つ。「誰から自由を買うのか」の答え。元の持ち主と同一でも可（未決） |
| **チュートリアル役 — 猫** | 船に住みつく猫。人間にしないのは、船が10日ごとに動くため常に同行できるのが船上の者だけだから。**猫が特別な存在であることを設定として掘り下げない** |
| **行商人** | 1日1回ほど船に来て売る。名前・外見が必要 |
| **各島の商人** | 寄港中の仕入れ相手。島ごとに扱う品が違う。名前・外見が必要 |
| **船大工** | 船倉を片付け売り場を広げる工事の請負。拡張の支払い窓口 |
| **客** | 桟橋の不特定多数。**個人ではなく類型**として扱う。特定の常連に物語を駆動させない |

### 行商人の実装制約（必須）
**取扱いは最大10種類・各最大10個まで。**
行商人が何でもいくらでも供給すると、巡る必要がなくなり2章の前提が崩れる。
要件の本体は数字ではなく、**行商人だけでは品揃えが完成しないこと**（→ [Issue #9](https://github.com/primevalsistail/shop-puzzle-simulation/issues/9)）。

## 7. 用語

**設定用語は「取り合わせ」ひとつだけ。** 隣り合わせに並べると値が上がる品の組み合わせ。

- 他に造語を作らないこと。島名・人名・船名以外の固有名詞を増やさない
- 「響き」から変更した経緯は [item-system.md](../design-log/item-system.md) §2 #10・§3

---

## 8. 扱う商品

現行実装は13品・5レシピ。素材と完成品を混ぜて棚に並べる。

- 素材: 小麦粉・トマト・ぶどう・布・木材・りんご・ミルク・ボトル
- 加工品: パン・ワイン・トマトソース・本・サンドイッチ
- **tier は加工の深さ**（`tier = 1 + max(材料のtier)`）
- 棚の見た目が単調にならないよう、形と色が散る品を選ぶこと（食品だけに寄せない）

## 9. ゲーム機構の前提

世界観はこれに合わせる。**機構を増やす方向の設定を作らないこと。**

| | |
|---|---|
| 中心の遊び | 仕入れる／作る → 棚に並べる → 客が買う → 利益を出す |
| 棚 | グリッド配置。**開始 6×5**。隣接する品に相性ボーナス |
| 加工 | 時間がかかる。その間は店を閉める |
| 客 | 特定顧客なし。BtoC。不特定多数が来店 |
| 画面に並ぶ品 | 最大60品程度 |

---

## 10. 守るべき制約

- **重い・暗い世界観にしない。** 喪失・自己犠牲・対立・敵役を主題にしない
- **似た用語を定義しない。** 説明が要る名前は負け
- **初見で意味が取れること。** 知らないと詰まる語を1画面に固めない
- **特定顧客に依存しない。** BtoC が前提
- 設定が品名や棚に染み出さないこと（「霧の階のミルク」のような命名をしない）

## 11. プレイヤーレビューからの示唆

4観点のプレイヤーレビューで繰り返し出た点。

| 観点 | 要求 |
|---|---|
| 配置パズル | 世界観が置く楽しさの邪魔をしないこと。読まされる量、覚える固有名詞を最小に |
| 経営シム | **「なぜこの品はここで安いのか」が設定から逆算できること。** 目標金額の根拠が分解されていること |
| キャラ物語 | **「この人が店を閉められない理由」**があること |
| 初見カジュアル | 説明なしで意味が取れること。通貨のスケールが直感で掴めること |

## 12. 却下した案と理由

世界観は4案を作り、4観点のプレイヤーレビューで比較して案Cを採った。

| 却下案 | 内容 | 却下理由 |
|---|---|---|
| **A 自由港** | 19世紀の関税のない港町。定住の店 | 世界の成立理由が「関税」の知識に依存する。鑑札・見本蔵・仲買と難語が最多（初見4位）。「関税なし」は一律の安さしか説明せず、品ごとの値差が読めない（シム4位） |
| **B 迷宮の門前町** | 階層ごとに気候が違う迷宮の産物 | 遊ぶ前に通る固有名詞が最多。「霧の階のミルク」のように**設定が品名に染み出す**（パズル4位）。前職紹介が機能説明に読め人物像が浮かばない（物語4位） |
| **D 積み替え港** | 軌道港の物流結節点。半端荷が流れる | 総合1位だったが、安さの理由が「日替わりの余り荷」で事前に読めない。**主人公を店に縛る事情がなく**、今日やめても誰も困らない（物語3位） |

### 得られた原則
- **通貨表記の分かりやすさが一番効く。** 造語通貨は毎回「これは高いのか」で止まる
- **設定が品名や棚に染み出すと配置の邪魔になる。** 設定の長さより染み出しが問題
- **初見が詰まる語を1画面に固めない。** 実例: 自由港・鑑札・見本蔵・仲買（案A）、店舟・賄い・二層甲板・相積み（案C初版）。いずれも本文から除去済み
- **隣接用語は操作と字面が繋がっていること。** 初見での通りやすさは 積み合わせ ＞ 取り合わせ ＞ 共鳴 ＞ 相積み。ただし「積み合わせ」は実在の物流用語（積合わせ輸送）と衝突するため避け、「取り合わせ」を採用
- **主人公が店を閉められない理由が要る。** DとBに欠けていた
