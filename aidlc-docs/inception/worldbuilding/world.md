# 世界観 — 気候の違う島を巡る店舟

## 1. 世界

レンティアは、気候の違う四つの島と、それを結ぶ穏やかな海でできた世界。
島同士は陸路で繋がらず、人も荷も船で動くのが当たり前になっている。

- 島の気候はそれぞれ変わらない。実りの絶えない島も、雪の絶えない島もあり、採れるものがまるで揃わない
- 通貨は世界じゅうで「レン」ひとつ
- ⚠ **異種族はいない。戦争はない。****ただし武器そのものは在ってよい**
  （〇 剣・槍・斧 ／ × 銃・地雷 → [island-goods.md §0-A](island-goods.md)）。→ 下の「魔法の扱い」
- ⚠ **魔法はある**（PO 判断 2026-09-13）。**掘り下げない。**→ 下の「魔法の扱い」
- 外洋や、この四島の外という概念を持たない

### 四季がない
**この世界に四季という観念はなく、「春島」のような呼び名も存在しない。**
名前の音と島の気候から、勝手に季節を感じ取るだけ。作中でも画面でも季節名は出さない。

| 島 | 気候 |
|---|---|
| ハルヴェラ島 | 温暖 |
| リナツィア島 | 陽が強く、暑い |
| ノアキータ島 | 実りが絶えない |
| ミフユリア島 | 雪が絶えない |

### 魔法の扱い（PO 判断 2026-09-13）

**ある。**⚠ **`characters.md` の猫（ネム）がしゃべる以上、「魔法は無い」とは書けない。**
**2026-09-13 まで、この文書は「魔法・異種族・戦争はない」と書いていて、正面から矛盾していた。**

**そのうえで縛る。**

- ⚠ **掘り下げない。**仕組み・出どころ・使い手を説明しない。**世界に不思議を増やさない**
- ⚠ **異種族は入れない**（世界が複雑化する）
- ⚠ **戦争は無いまま。****武器そのものは在ってよい**が、
  **軍のための装備・量産される武具・それらを想起させるものは出さない**
- ⚠ **魔法を価値の出どころにしない。**
  商品の売値は**材料と加工から機械的に決まる** ——
  **売値 ＝ 材料費 ＋ 加工利益 ／ 加工利益 ＝ 5.6 × (所要分 ÷ 出力数)^0.6 × 贅沢さ係数**
  （日用0.9／上等1.1／贅沢1.7。**式は [`derive.ts`](../../../src/taxonomy/derive.ts) が正**）。
  → **値打ちの出どころは「材料」「所要分」「贅沢さ」の3つ。**
  ⚠ **「魔法だから高い」という4つ目を作らない。**→ [island-goods.md §0-C](island-goods.md)

### この世界の調子
明るく、穏やか。**喪失・自己犠牲・対立・敵役が主題になることはない。**

## 2. 店舟〈ペルラ号〉

四島を10日ごとに移りながら商う店舟。店の名前は船の名前と同じ。

- **店＝船倉。** 接岸すると船の横腹が開き、荷を納めた船倉が**そのまま**売り場になる
- 客は桟橋に立ったまま買う

### どんな商品でも手に入る理由
**気候の違う島を順に巡るから。** ひと巡りすればこの世界の素材がひと通り船倉に納まる。
この一点だけで全商品の入手を説明し、前提を崩す要素を足さない。

---

## 3. ペルラ号にかかっている縛り

〈ペルラ号〉は**まだ定期航路の一隻**で、主人公にとっては借り物。ここから縛りが二つ出る。

| 縛り | 内容 |
|---|---|
| 移動 | 10日ごとに決められた順でしか島を回れない |
| 広さ | 船倉は預かり荷に占められ、売り場は入口近くの一角だけ |

### 縛りの外れ方
船体は大きくしない。**広くなるのは、船倉が空くから。**

- 荷は主人公のものではなく**預かりもの**なので、自分でどけることはできない
- 払う金は労賃ではなく、**預かり契約を一区画ぶん降りるための金**。支払い先は預かり荷を差配している**権限の持ち主**
- 空いた区画がそのまま売り場になり、**広さの縛りが少しずつ外れる**
- 船倉をひと通り空けたあと、舟を買い取ると**移動の縛りが外れる**。航路が自分の裁量になる
- 主人公がするのは品を納めることだけ。**造作の仕事は発生しない**

## 4. 主人公

### 確定していること
- 21歳の女性
- 島を巡る定期船に乗っていた
- **舟を引き取る側。**買い取るまでは借り物で、買い取ると航路が自分の裁量になる

### 決定済み — 詳細は [char.md](char.md)

| 項目 | 決定 |
|---|---|
| 名前 | **ノエラ・キア** |
| 深層要求 | 自分が持ってきたものが、その土地で**喜ばれる瞬間を作り続けたい** |
| 判断の癖 | どの土地へ持っていくと一番「持ってきた甲斐」が出るかで決める |
| 性格（表層） | **見立て好き** |
| 船での役割 | 荷札と行き先の照合 |
| 一人称 | 自分 |
| なぜこの舟を持つことになったのか | 別の島の品をその土地へ持っていく営みを、自分で続けるため |

外見・伯母との関係・猫との距離・開始5分で伝わることも char.md に記載。

### 満たすべき条件
**プレイヤーに次の2つが伝わること。**

- **なぜこの人がこの舟を持つことになったのか**
- **このゲームで何を目指す話か**

手段は問わない。舟への思い入れで書いてもよいし、別の理由でもよい。
**思い入れで書く場合のみ**、その中身は船体の性能や機能ではなく、この舟でしか起きないことにすること。

買い取ったあとも店は続く（運用継続）。これはゲームの作りの話であり、
**主人公に「閉められない理由」を語らせて正当化しない。**
動機は深層要求のほうに置き、達成して終わる性質のものにしないこと。

## 5. 主人公の目的

借り物の〈ペルラ号〉を買い取り、自分の店にすること。
稼いだ金は**売り場の広さ**と**航路を決める自由**に変わる。

### 店を手に入れる過程
舟はまだ定期航路の一隻で、主人公はまだ買い取っていない。
10日ごとに動く決まりと、預かり荷で埋まった船倉がついてくる。

乗っていた定期船が航路縮小で退役し、船主だった伯母も船を降りる。
使い道のなくなった小型〜中型の荷舟を「稼げたら買い取る」という口約束ひとつで預かる。
**引き取るのは、別の島の品をその土地へ持っていく営みを自分で続けるため**（→ [char.md](char.md)）。

## 6. 主人公以外の人物

**覚えるべきは主人公だけ。** それ以外は世界の色付けであり、名前を思い出せなくてもプレイに支障が出ない。

**確定済み。名前・外見・応対・縛りは [characters.md](characters.md) を参照。**

| 役割 | 決定 | この世界での立ち位置 |
|---|---|---|
| 船の元の持ち主 | 伯母 **テレナ・キア** | 定期船の船主だったが、航路縮小で船を降りた。敵ではない |
| 権限の持ち主 | **「航路・荷預かり係」** | 航路と預かり荷を差配する。**伯母とは別人。**払えば荷を引き取る窓口 |
| 猫 | **ネム** | 船に住みついていて、主人公と話す。**特別な存在であることは掘り下げない** |
| 行商人 | **バレン** | 1日1回ほど船に来て売る。**行商人だけでは品揃えが完成しない** |
| 各島の商人（4人） | **レネ／サディ／コルナ／フィエラ** | 寄港中の仕入れ相手。島ごとに扱う品が違う |
| 客 | **4類型** | 桟橋の不特定多数。**個人ではなく類型。**常連が物語を動かすことはない |

## 7. 言葉

**設定用語は「取り合わせ」ひとつだけ。** 隣り合わせに納めると値が上がる品の組み合わせ。
島名・人名・船名のほかに、固有名詞を持たない世界。

---

## 8. 読み違えを防ぐ（⚠ 実際に踏んだもの）

### 商品リストと世界は別

⚠ **アイテム体系に無い ＝ 世界に存在しない、ではない。**
[materials.md](materials.md) ／ [crafted-goods.md](crafted-goods.md) は
**商品として扱うものの一覧**であって、**世界の全目録ではない。**

⚠ **2026-09-13 に踏んだ**: 染料が商品に無いことから「**この世界では色が作れない**」と推論し、
**存在しない制約をキャラクターの依頼書に書いた。**
**麻・小麦・染料は至極一般的な品で、扱わない理由は無い**（PO 判断）
→ [Issue #86](https://github.com/primevalsistail/shop-puzzle-simulation/issues/86)

### 禁止しているのは「プレイヤーが全く想像できない何か」であって、特定の物ではない

§7 は**造語・独自概念を増やさない**という制作方針。
⚠ **実在する一般的な物**（麻・小麦・染料・ボタン・文字・前掛け）**を排除する意味ではない。**

### 固有名詞を持たない ≠ 文字が無い

⚠ **同じ混同を2箇所で踏んだ。**§7 から「文字を持たない世界」と読み、
依頼書に「**荷札に文字を書くな**」と書いた。**荷札は字があってこそ荷札である。**

### 現実の政治・宗教に抵触するものは、絶対に出さない

**宗教的シンボル、実在の国家・政党・信仰の意匠、およびそれらを想起させるもの。**
⚠ **これは他のどの判断にも優先する**（PO 判断 2026-09-13）。
