# 音の置き場（原本）

**BGM 8曲の原本**（#14）。仕様は [bgm.md](../bgm.md)、選んだ経緯は [bgm-candidates.md](../bgm-candidates.md)。

⚠ **ここが原本。`public/audio/` は写し。**（**絵と同じ向き。逆をしない**）
⚠ **原本は `ogg` だけ。**`m4a` は `ogg` から作る派生物なので、**`public/audio/` にしか置かない。**

**配布元は[音楽の卵](https://ontama-m.com/)1つ。8曲すべて同じ作者。**
**落としたのは各曲の `ogg(L)`**（切れ目のない自然ループ版）。**加工していない。**

**長さを測り直すときは、必ずここのファイルを測ること。**

## 差し替えるとき

1. **ここに `ogg` を置く**
2. `public/audio/` へ写し、**`m4a` を作る**
   （`ffmpeg -i x.ogg -c:a aac -b:a 128k x.m4a`。**ogg だけだと Safari で鳴らない**）
3. **ファイル名は変えない。**`src/audio/bgm.ts` が名前で引いている

⚠ **ミフユリア（雪）だけ、仕様どおりに埋まっていない。**
`bgm.md` は「音数が少なく、澄んでいる」だが、入れたのは**軽やかで陽気な北欧風。**
**雪に聞こえなければ「泉のほとりで」（2:55／`ogg(L)` は未計測）へ差し替える。**
