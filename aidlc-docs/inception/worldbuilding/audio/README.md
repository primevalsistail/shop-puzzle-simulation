# 音の置き場（原本）

**BGM 8曲**（#14）と**効果音 12音**（#124）の原本。
仕様は [bgm.md](../bgm.md)、選んだ経緯は [bgm-candidates.md](../bgm-candidates.md) ／
[se-candidates.md](../se-candidates.md)。

⚠ **ここが原本。`public/audio/` は写し。**（**絵と同じ向き。逆をしない**）
⚠ **原本に `m4a` は置かない。**`ogg` から作る派生物なので、**`public/audio/` にしか置かない。**
⚠ **効果音は配布元が違う**（[効果音ラボ](https://soundeffect-lab.info/)）。**規約もこのファイルの下半分が別。**

## BGM 8曲 —— [音楽の卵](https://ontama-m.com/)

**配布元は[音楽の卵](https://ontama-m.com/)1つ。8曲すべて同じ作者。**
**落としたのは各曲の `ogg(L)`**（切れ目のない自然ループ版）。**加工していない。**

| ファイル | 曲名 | 長さ | 鳴るところ |
|---|---|---|---|
| `title.ogg` | 高台 | 2:32 | タイトル画面 ＋ はじまりの場面 |
| `morning.ogg` | レント牧場 | 1:50 | 6:00〜10:00 |
| `day-halvela.ogg` | 日向の街 | 1:36 | 10:00〜20:00・ハルヴェラ |
| `day-linatsia.ogg` | 風と水のステラヴィーネ | 1:26 | 10:00〜20:00・リナツィア |
| `day-noakita.ogg` | 僕らの街 | 1:05 | 10:00〜20:00・ノアキータ |
| `day-mifuyuria.ogg` | ピズベリーの香り | 1:14 | 10:00〜20:00・ミフユリア |
| `night.ogg` | 地下の歌声 | 1:47 | 20:00〜24:00 |
| `ending.ogg` | 明日からもずっと | 1:01 | 商船を買った幕（**1回だけ**） |

⚠ **長さは `ogg(L)` の実測値。****`mp3` は別物**（イントロ・アウトロが付いていて 10〜70秒長い）。
**長さを測り直すときは、必ずここのファイルを測ること。**

## BGM を差し替えるとき

1. **ここに `ogg` を置く**
2. `public/audio/` へ写し、**`m4a` を作る**
   （`ffmpeg -i x.ogg -c:a aac -b:a 128k x.m4a`。**ogg だけだと Safari で鳴らない**）
3. **ファイル名は変えない。**`src/audio/bgm.ts` が名前で引いている

⚠ **ミフユリア（雪）だけ、仕様どおりに埋まっていない。**
`bgm.md` は「音数が少なく、澄んでいる」だが、入れたのは**軽やかで陽気な北欧風。**
**雪に聞こえなければ「泉のほとりで」（2:55／`ogg(L)` は未計測）へ差し替える。**

## BGM の規約（[原文](https://ontama-m.com/ongaku.html)）

**商用可・個人法人問わず無料。使用報告・著作権表示の義務なし**（**それでも設定の面に出す**）。
**ループ化・カット・形式変更は明示的に許可。**

⚠ **直リンク禁止**（だからここに落として置いてある）。
⚠ **曲単体での配布・販売は禁止**（ゲームに入れるのは可）。
⚠ **自作としての発表・無断改変は禁止。**
⚠ **YouTube のコンテンツ ID 登録は禁止**（配信するときだけ関係）。

# 効果音 12音 —— [効果音ラボ](https://soundeffect-lab.info/)

**12音すべて同じ配布元。加工していない。**
**鳴る場所は13箇所**（⚠ **`button` だけ2箇所から鳴る**）。**どこで鳴るかは
[se-candidates.md](../se-candidates.md) の表が正。**

⚠ **形式は `mp3` だけ。**`ogg` も `m4a` も作らない ——
**`mp3` はどのブラウザでも鳴る**（BGM が2形式なのは `ogg` が Safari で鳴らないから）。

| ファイル | 元の音 | 長さ | 鳴るところ |
|---|---|---|---|

## 効果音を差し替えるとき

1. **ここに `mp3` を置く**
2. `public/audio/` へ写す。⚠ **`m4a` も `ogg` も作らない**
3. **ファイル名は変えない。**`src/audio/se.ts` の `SeKey` が名前で引いている
