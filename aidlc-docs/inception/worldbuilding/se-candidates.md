## なぜ効果音ラボか

**BGM（音楽の卵）で通した条件を、そのまま満たせる配布元だから。**

| 条件 | 効果音ラボ | 音楽の卵（BGM・比較用） |
|---|---|---|
| 商用利用 | **○ 個人・法人・公的機関問わず無料** | ○ |
| クレジット表記 | **○ 義務なし**（任意） | ○ 義務なし |
| 使用報告・許可取り | **不要** | 不要 |
| 加工 | **○ 可**（⚠ **改変版の再配布は不可**） | ○ 可 |
| ゲームへの組み込み | **○ 明示的に可**（規約が「アプリの操作音」を再配布に当たらないと名指ししている） | ○ |

⚠ **同じ禁止が2つある。**BGM で踏まないようにしたのと同じなので、**同じやりかたで足りる。**

- **直リンク禁止** → **落として `worldbuilding/audio/` に置く**（BGM と同じ向き）
- **素材単体の再配布禁止** → ゲームに入れるのは可

⚠ **効果音ラボ固有の禁止**（BGM には無かったもの）

- **AI の学習データにしない**
- **効果音を紹介する動画を作らない**（抽出できてしまうため）
- **効果音を含む楽曲の Content ID 登録・音商標登録をしない**

### 落とした案

| **魔王魂** | **クレジット表記が原則必須。**BGM は「義務は無いが任意で出す」で揃えたので、**義務のあるものを混ぜると条件が2種類になる** |
| **OtoLogic** | **CC BY**（表記必須）。同上。⚠ **規約ページが 403 で読めず、確認できていない** |

## 形式 —— ⚠ **BGM と違って mp3 だけ**

**効果音ラボの配布は mp3 のみ。**BGM は `ogg` ＋ `m4a` の2つを置いているが、
**効果音は mp3 1つで足りる** —— **mp3 はどのブラウザでも鳴る**（Safari を含む）。
`bgm.ts` の `bgmPaths()` が2つ返しているのは **ogg が Safari で鳴らないから**で、
**mp3 にはその問題が無い。**

→ **`m4a` を作る手順（`ffmpeg`）は効果音には要らない。**

## 候補 13音

**「押した音」と「勝手に起きた音」で分けてあります。**
⚠ **勝手に起きた音だけ、0.5秒に1回まで間引きます**（Q2 = B）。**速さ（1・3・10倍）は見ません。**

### 押した音 —— **鳴る回数をプレイヤーが決める**

| どこ | 候補 | 配布元の説明 | 替え |
|---|---|---|---|
| ボタン・タブを押した | `decision31` | 決定ボタンを押す31「カチッ」 | `decision52`「ポン」 |
| 棚に置けた | `peta1` | ペタッ（スタンプをつく時などに） | `decision52`「ポン」 |
| **置けない** | `beep1` | ビープ音1「選択不可項目を押した時のエラー音」 | `cancel1`「ヒッ」 |
| つかむ・動かす | `cursor2` | カーソル移動2「カシャ」 | `cursor1`「クセの少ない電子音」 |
| 捨てる | `cancel9` | キャンセル9「ザッ」 | `cancel1`「ヒッ」 |
| 納品・強化が決まった | `decision4` | 決定ボタンを押す4「成功音にも使える」 | `success1`「ゲーム等で何かが成功した時」 |
| できごとの窓が開く | `menu4` | メニューを開く4「ウインドウが開く」 | —— |
| できごとの窓が閉じる | `cancel1` | キャンセル1「ヒッ」 | —— |
| **商船を買った**（⚠ **1回だけ**） | `trumpet1` | ラッパのファンファーレ「喜びの演出に」 | `levelup1`「テッテレー」 |

### 勝手に起きた音 —— ⚠ **0.5秒に1回まで間引く**（Q2 = B）

| どこ | 候補 | 配布元の説明 | 替え |
|---|---|---|---|
| **客が買った** | `money-drop1` | お金を落とす1「硬貨一枚」 | `clearing1`「レジスターで精算」 |
| 加工が仕上がった | `shine3` | きらきら輝く3「鉄琴で演奏」 | `correct3`「ハープ」／`item-get1`「アイテムを入手1・お金」 |
| **寄港の朝、板が開く** | `slidingdoor-open2` | 引き戸を開ける2「玄関の古めかしい戸」 | `slidingdoor-open3`「土蔵の戸」 |

⚠ **`slidingdoor-open1`（お風呂の戸）は選んでいません。**店を開ける音として `2` のほうが近いという判断です。
⚠ **板が開くのは 0.4秒**（[`PortShutter.ts`](../../../src/ui/PortShutter.ts) `PORT_SHUTTER_MS`）。
**音がそれより長ければ、板が開き切ったあとも鳴り続けます。**長さは未計測です。

### 「客が買った」に硬貨1枚を推す理由

**`clearing1`（レジ）のほうが意味は近いが、長い。**
**売れるのは1日に何度も起きる**ので、**短い音でないと次の売却に重なります。**
**`money-drop1` は硬貨1枚ぶん**なので、連続しても潰れにくいと見ています（⚠ **未計測・未聴取**）。

### 楽器の選びかた

**BGM 8曲がオカリナ・笛と弦・オルゴール・ピアノ・ストリングス**です。
そこへ電子音を重ねると浮くので、**「仕上がった」「決まった」のような長めの音は生楽器系**から採りました
（`shine3` = 鉄琴、`correct3` = ハープ）。
**「押した」は短く、音楽と重ならないので電子音のままでかまいません。**
