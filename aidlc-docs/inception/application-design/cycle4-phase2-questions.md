## Question 1 — 面の本数 N ★最重要

PR-3 に従って**規則を先に列挙**したところ、Phase 1 で候補に挙げていた面のうち2本に
**参照する規則が1つも書けませんでした**（→ [草案 §3](cycle4-phase2-axes.md)）。

- **客層**（子供向け等）— characters.md の確定「客の類型は**取引行動で分ける**」により、
  客側に照合相手が居ない。**中身の無い箱**になる
- **保存**（生鮮等）— Phase 1 で問いごと取り下げた「傷むか」を名前を変えて入れ直すことになる。
  時間劣化の機構が無いので `生鮮` の**定義文が書けない**

代わりに、客の類型4種が実際に参照できる面として **消耗（使い切る／残る）** を立てました。

A) **N = 2（贅沢さ・消耗）を採用する**（推奨。軸は 3 + 2 = 5 本で確定）
B) N = 1（贅沢さのみ）。回転率の差は贅沢さだけで作る（消耗も落とす）
C) N = 3。**保存**を残す。＝ 鮮度・時間劣化の機構を入れると決め、Phase 1 に戻って問いを立て直す
D) N = 3。**客層**を残す。＝ 客の類型を属性で分けるよう characters.md の確定を変える
E) Other (please describe after [Answer]: tag below)

[Answer]: 鮮度は面倒。客層はいる

## Question 2 — 主種類の値

草案は **6値**（食料・飲みもの・衣類・道具・飾りもの・香りもの）。
`原料` は置きませんでした（「用途の不在」で切っており、§3 で却下した「書物」と切り方が混ざるため）。
そのぶん **木材は `道具`、布は `衣類`、小麦粉は `食料`** に寄せています。
残る未決は **`本` の置き場所**です。

A) **6値のまま。`本` は `道具`（手に持って使うもの）**（推奨。値を増やさない）
B) **7値。`読みもの` を足す**（本・巻物・地図。動詞「読む」で切るので一貫性は保てるが、品数が少ないと過疎箱）
C) **`原料` を置く**（木材・布・小麦粉・ガラス）。切り方の不一致は許容する
D) **4値に減らす**（食料・飲みもの・衣類・道具）。飾りもの・香りものは実物が揃う Phase 3 まで立てない
E) Other (please describe after [Answer]: tag below)

[Answer]: D…道具に当たるものが多そう…そこは今後分割でいいか…

## Question 3 — 贅沢さに順序を持たせるか

`日用` < `上等` < `贅沢` という**順序**を認めると、条件式に `贅沢さ >= 上等` が書けます。

A) **順序を持たせる**（推奨。「上等以上」で1行にできる。tier と同じ扱いになり条件言語が単純）
B) **順序を持たせない**（`==` と `!=` だけ。値を後から足しても既存の規則が壊れない）
C) Other (please describe after [Answer]: tag below)

[Answer]: A

## Question 4 — 取り合わせの効き目の種類

現行コードは「売れやすさ」と「値段」の2つ。草案は R5（同じ島の産を並べると人が寄る）のために
**`集客`（桟橋に来る客の数）** を足しています。これは**新しい機構**です。

A) **3種類（売れやすさ・値段・集客）を採用する**（推奨。「島の棚」が作れる。産地の面が取り合わせにも効く）
B) **2種類のまま**（売れやすさ・値段）。R5 は「売れやすさ」で表現し、機構を増やさない
C) Other (please describe after [Answer]: tag below)

[Answer]: A、商品ごとのボーナスと店全体のボーナスみたいなのがあってもいいかも

## Question 5 — 状態述語に `産地距離` を入れるか

`産地距離(この品)` は、Phase 1 §5 で **「有力案・Phase 3 で検証」** とした
「産地から遠い島で売るほど高く売れる」を書くための述語です。
Phase 2 で条件言語に入れておくか、採用が決まってから足すかの選択です。

A) **いま入れる**（推奨。条件言語をここで確定できる。使わなければ規則を書かないだけで害がない）
B) **入れない**。Phase 3 で距離倍率の採用が決まってから足す（条件言語は後から拡張する前提にする）
C) Other (please describe after [Answer]: tag below)

[Answer]: B。どの島で売れるかはあってもいいけど、それは距離に依存しない
