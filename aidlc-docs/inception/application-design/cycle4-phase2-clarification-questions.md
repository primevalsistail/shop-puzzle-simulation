## FQ1 — 客層に「照合する相手」をどう作るか ★

客層の面が意味を持つには、**客の側にも対応する区別が要ります**。
いまの [characters.md](../worldbuilding/characters.md) の客は4類型で、**取引行動で分かれています**
（迷わず買う／見比べて買う／端から見る／まとめて買う）。**`子供` `職人` という属性を持っていません。**
そのため品に `子供向け` と書いても、照合する相手が居ません。解き方は4つあります。

A) **客の類型に「好む客層」を持たせる** — 類型の**分け方**は取引行動のまま変えず、
   各類型が別データとして「どの客層の品を好むか」を持つ。characters.md の縛りは
   「分け方」の話なので、文言は変えずに済む。**最小の変更**
B) **客の類型を増やす** — 取引行動の4類型に、客層に対応する類型を足す（または掛ける）。
   characters.md の「客の類型4種」の確定を**変更**することになる
C) **島ごとに客層の需要が違うとする**（推奨） — 客の類型は一切触らない。
   「ハルヴェラの桟橋には子供向けが売れる」のように**島が客層の需要を持つ**。
   **FQ4「どの島で売れるか」と同じ機構で片付く**ので、新しい仕掛けが増えない
D) **客層は客が参照しない。品同士の規則だけが使う** — 「同じ客層の品を並べると売れやすい
   （売り場に筋が通る）」など、取り合わせと入荷解禁だけが参照する
E) Other (please describe after [Answer]: tag below)

[Answer]: C（FQ0=A の選択に含まれる。客のモデルには触れない）
　**※ FQ2=A により「客層の面」自体が無くなった。**残るのは「島が需要を持つ」という形だけで、
　　島の需要規則が参照するのは 主種類・tier・産地・贅沢さ・消耗 になる（→ FQ5）

### 検討 — 規則側（客が商品を買いやすい）に置くべき

| 根拠 | 内容 |
|---|---|
| §2#9 の確定 | 「アイテムは**事実**だけを持ち、**意味づけは規則側**に置く」。「誰に売れやすいか」は意味づけ |

| 値が外部に依存する | `子供向け` は「子供という客が世界に居る」ことに依存する値。登場人物が変わると品の属性が変わる。`贅沢さ` `消耗` `tier` にはこの依存がない |

| | 客の種類を1つ増やす | 品を1つ増やす |
|---|---|---|
| 品側に `客層` を置く | **既存の全品を見直して付け直す** | 客層を1つ書く |
| 規則側に条件式を置く | **条件式を1本書くだけ**。既存品は0行 | **0行**（既存の全客の好みが自動で決まる） |

> INV-5 はまさにこの壊れ方を防ぐために置いた条件である。

### ただし — 規則側だけでは書けないこと

足りないと分かったとき足すべきは、**客の名前を値にした面ではなく、品自体の事実である面**。

### 選択肢

A) **面を足さない。N = 2（贅沢さ・消耗）**（推奨）

B) **品自体の事実である面を1本足す**（客の名前を値にしない）。例:
   **「使う場面」** — `台所` / `仕事場` / `身の回り` / `遊び`
   ※ 食料・飲みものが `台所` に偏る恐れがあり、切れ味は Phase 3 で確認が要る
C) **`客層` の面をそのまま置く** — `子供向け` / `職人向け` / `船乗り向け` / `なし`。
   直感的で書きやすいが、上表の「客を増やすと既存の全品を見直す」を受け入れることになる

## FQ3 — 面「消耗（使い切る／残る）」は残しますか

> **⚠ FQ2=A を受けて前提が変わった。**客層の面が無くなったので、面は **贅沢さ ＋ 消耗** の最大2本。

消耗は「同じ品を繰り返し買うか」を決める軸で、**回転率の差**を作るために置いたものです。
FQ2=A により「誰が買うか」が規則側へ移ったので、**品側で回転率を動かせる軸は贅沢さと消耗の2つだけ**になりました。

A) **残す。N = 2**（贅沢さ・消耗）→ 軸は 3 + 2 = **5本**（推奨。`贅沢さ × 消耗` の6通りで回転率を作る）
B) **落とす。N = 1**（贅沢さのみ）→ 軸は4本。回転率は贅沢さの3通りだけで作る
   ※ Phase 1 §5 の警告「`利益/時間` が一律になると結局同じになる」に対して弾が1つ減る
C) Other (please describe after [Answer]: tag below)

[Answer]: B（2026-09-06 会話で回答）
　**理由（ユーザー）**: 客について「**同じ客**」という判定をそもそもしない。
　→ 消耗の根拠だった「同じ客が繰り返し買う」は**この世界に存在しない事象**だった。
　　characters.md「個人を作らない」と整合する。草案の C4「同じ品をまとめて買う客」も
　　同一人物の再来店ではなく、1回の取引での複数個購入である。
　**結果**: **N = 1。軸は 3 + 1 = 4本**（主種類・tier・産地・贅沢さ）
　**申し送り（Phase 3）**: 品ごとの戦略差は、残る4つ（利益・時間・場所・現在地）で作る。
　　回転率は贅沢さ3値のみが担うため、**Phase 4 の「最適戦略が一致していないか」検査の重要度が上がる**
