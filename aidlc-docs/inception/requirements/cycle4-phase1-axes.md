## 1. 仕分けの型

§2#9「アイテムは事実だけを持ち、意味づけは規則側に置く」に従い、問いを3つに仕分ける。
**軸になるのは (a) だけ。** (b)(c) は軸を参照するだけで、軸を増やさない。

| | 誰が答えるか |
|---|---|
| **(a) 軸** | アイテムが事実として持つ |
| **(b) 規則** | 条件式が軸を参照して答える（取り合わせ・客の好み・入荷解禁） |
| **(c) 導出** | 別データから計算する（→ INV-3） |

## 3. 決着した割り当て（D1〜D4）

### D1 — 要素は面（facet）に分ける ✅
§6 の暫定 `要素: ['生鮮', '子供向け']` は、**保存性**と**客層**という別々の問いを1軸に混ぜており
**INV-2b に抵触する**（「書物」を落としたのと同じ形）。

**決定**: 面に分ける。**条件式の書き方は全軸で共通のまま**（§2#7・§2#8 を維持）。

```ts
// 混ぜたまま（却下）            // 面に分ける（採用）
要素: ['生鮮','子供向け','贅沢']   保存: '生鮮'      // 必ず1つ
                                  客層: '子供向け'   // 必ず1つ。無い品は 'なし'
                                  価格感: '贅沢'
```

- 付け忘れ・重複・両立しない組み合わせが**書いた時点で落ちる**のが利点
- 「なし」は**明示的な値**として書く。空欄は型エラー
- **どの面を必須にするか（0..N を許すか）は Phase 2 で決める**

### D2 — 産地は独立の面として持つ ✅
world.md §2「気候の違う島を順に巡るから全素材が揃う」を成立させる情報の置き場所。

**決定**: `産地: 'ノアキータ'`。**値に「なし」を含む**（どこでも手に入る品）。

- 島は world.md で4つに確定していて増減しないため、気候で間接的に持つ利点が効かない。読んで分かる方を採る
- **産地なしの品を置くこと自体に意味がある**:
  - 島の個性は**コントラスト**で立つ。どこでも買える品があって初めて特産品が特別に見える
  - 材料が遠い島にしか無いときの「何もできない時間」を、「稼げるが甲斐は薄い時間」に変える
  - 距離倍率で常に 1.0倍 ＝ 薄利。産地ありの品が厚利になる
- **上限が要る**: 産地なしが多すぎると島を巡る理由が消える（バレンの10種10個と同じ失敗）。数値は Phase 3
- **どの島に何が並ぶかという値は Phase 3。** world.md §8 の未決は Cycle 4 の前提ではない、という起票時の判断を維持

### D3 — 価格は積み上げ式 ✅
→ §5 に詳述。tier1 のみ手書き、tier2以上は材料から導出。

### D4 — placeable は廃止 ✅
**全品売れる**と決めたため、軸にしない。§6 の暫定 `placeable: true // 素材は false` は取り下げ。

副次的な利得: 全品が「**今売るか、材料にするか**」の選択になる。
§5 の指摘「3ルートがプレイヤーに見えていない」に対し、ルートの選択が全品に発生する。

## 4. 軸の本数（Phase 1 の成果物）

| 分類 | 内訳 | 本数 |
|---|---|---|
| **規則が参照する軸** | 主種類 ／ tier ／ 産地 ／ 要素の面 N本 | **3 + N** |
| 規則が参照しない属性 | かたち・大きさ ／ 表示（色・アイコン・名前）／ 価格（導出） | 3 |

**N は Phase 2 で確定する。** 候補は 保存 ／ 客層 ／ 価格感 で、**2〜4本**と見ている。

## 5. Phase 2 / Phase 3 への申し送り

Phase 1 の議論中に決まった、軸ではない事項。**Phase 2・3 で使う。**

### 価格の構造（積み上げ式）

```
tier1（レシピなし）: 売値 = 基準値 × 面の倍率（価格感）× 品ごとの補正
tier2以上          : 売値 = (Σ 材料の売値) × 加工倍率
```

- 加工倍率 > 1 である限り **INV-6 が構造的に満たされる**
- 手書きは tier1 だけ。新レシピを足すと売値が自動で付く（INV-5 に強い）
- §3 の確定「価格は tier の**結果**であって定義ではない」に忠実（tier を価格に直接使わない）
- 「商品ごとのイメージ（高い・安い）」は**価格感の面**が吸収する
- 深いレシピで値が膨らむ（倍率1.5を5段で 7.6倍）。§4-E の運用5〜6段なら許容。**数値は Phase 3**

### 薄利多売／厚利少売は価格の問題ではない
**利幅 × 売れる速さ**の組み合わせ。価格は「いくらか」にしか答えない（INV-2a）。
売れる速さは Q8 の客の好み規則が出す。**価格をシステマチックに決めても両方作れる。**

> §5 の「本は 2.5倍・10分で最悪」は価格の問題ではなく、**利幅と所要時間の組**の問題。
> 加工倍率を所要時間に紐づければ構造的に直る。

### ⚠ 必ず守ること — 加工倍率を所要時間だけから決めない
時間だけから決めると `利益/時間` が全品一定になり、**「何を買ってどう売っても結局同じ」になる。**
**面（贅沢／日用）による回転率の差を必ず併せて入れること。**

### 品ごとに最適戦略を変えるための独立な量（5つ）

| 量 | どこから来るか |
|---|---|
| 利益 | 積み上げ式価格 |
| 時間 | 加工中は店が閉まる（機会損失） |
| 場所 | かたち・大きさの軸 |
| 回転率 | 客の好み規則（客層・価格感の面） |
| 今どこにいるか | 産地 × 距離倍率 |

`利益/時間`・`利益/面積`・`利益/資金` の順位が品ごとに入れ替われば、一律の最適解は存在しない。
**制約が2つ以上（場所と時間）あり、品ごとに消費比率が違うこと** — これが在庫配置パズルの本体。

想定される差異の例:

| 品 | 最適な戦略 | 理由 |
|---|---|---|
| りんご（小さい・売れやすい） | 買って売る | 場所効率がよく回転が速い |
| パン（材料が小さい） | 材料を買って作る | 小麦粉は船倉を食わずに買いだめできる |
| ワイン（時間が長い・贅沢） | 遠い島まで運んで売る | 距離倍率と価格感で単価が伸びる。回転は遅くてよい |

### 中間品の解禁（Q10 の適用範囲を広げる）
tier が深いほど下ごしらえが連鎖して積み上がる。これを緩めるため、
**作るしかなかった品が、条件を満たすと買えるようになる。**

- **新しい機構ではない。** 既にある入荷解禁規則の対象に tier2以上を含めるだけ。軸は増えない
- **解禁条件**: **その品を自分で100個売った**（数値は Phase 3）
  - char.md の深層要求「自分が持ってきたものが、その土地で**喜ばれる瞬間**」に対応。
    測るのは自分の手間（作った数）ではなく**客が買った回数**
  - 「売り続けたから島の商人が置くようになった」と読める。品ごとに解禁されるのでプレイヤーの選択が反映される
- **成立条件2つ**:
  - **(a) 買う方が高い** — 仕入れ値 = 材料費 × 加工倍率 × 割増。作れば安く、買えば高い（**時間を金で買う**）
  - **(b) 解禁される品を全部にしない** — 全部買えるとクラフトループ（§1 の当初の意図）が痩せる。上限は Phase 3
- **条件言語への影響**: 解禁条件を書くには、条件式が**ゲーム状態への述語**も持つ必要がある。

```
アイテムの軸への述語 : tier >= 4 | 価格感 == '贅沢'
ゲーム状態への述語   : 累計販売数(この品) >= 100
```

  INV-4 は維持される（どちらも ID を書かない）。**2種類の述語を持つことは Phase 2 で形にする**

### 検討したが採らなかったもの
- **「他の島でも割高（1.0/1.1/1.2/1.3）で買えるようにする」** — 採らない。
  characters.md:92 が行商人バレンを「最大10種類・各最大10個」に縛った理由
  （これを超えると島を巡る必要がなくなる）と正面から矛盾する。3割の差では 40日かけて巡る動機が作れず、
  「今買わないと次は40日後」という船倉配置の判断も消える。
  **詰みの回避はバレンの10種10個の枠と、産地なしの品が担う**
- **同じ数字の使い道を反転させる案（有力・Phase 3 で検証）**:
  **産地から遠い島で売るほど高く売れる。** char.md の「どの土地へ持っていくと一番持ってきた甲斐が出るか」
  がそのまま最適化問題になり、島を巡る理由が価格の中に入る

- 新品30個について**最適戦略が一致していないか**（「結局同じ」の検出）
